# /enroll

Load bao-kao skill to search official enrollment data, perform cross-validation analysis, and provide practical recommendations.

## Usage

```
/enroll <query>
```

## Features

The bao-kao skill will:
1. Search official data from Ministry of Education, provincial education examination authorities, and university websites
2. Download score distribution tables, admission cutoff scores, enrollment plans, and employment quality reports
3. Perform cross-validation analysis
4. Provide practical recommendations in Zhang Xuefeng style (direct, colloquial, opinionated)

## Examples

**Gaokao (college entrance exam) queries:**
```
/enroll Beijing gaokao 580 score what schools
/enroll Computer Science employment prospects
/enroll Beijing University of Technology historical cutoff scores
```

**Postgraduate queries:**
```
/enroll Peking University Law Master enrollment
/enroll Computer Science postgraduate admission ratio
/enroll Tsinghua University employment quality report
```

**Score distribution queries:**
```
/enroll Beijing 2024 score distribution table
/enroll 580 score ranking in Beijing
```

## Notes

- Only use official data sources (Ministry of Education, provincial exam authorities, university websites)
- All data sources are documented
- Risks and pitfalls are clearly explained
- Zhang Xuefeng style expression (direct, colloquial, opinionated)
- No hidden issues, no exaggerated prospects
