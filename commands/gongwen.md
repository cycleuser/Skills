Load the official-document-writer skill and help write: $ARGUMENTS

**Usage**: `/gongwen <type> <topic>`

**Supported types**:
- `/gongwen notice <topic>` - Write a notice (通知)
- `/gongwen report <topic>` - Write a report (报告)
- `/gongwen request <topic>` - Write a request (请示)
- `/gongwen reply <topic>` - Write a reply (批复)
- `/gongwen letter <topic>` - Write a letter (函)
- `/gongwen minutes <topic>` - Write meeting minutes (纪要)
- `/gongwen check <document>` - Check document compliance

**Examples**:
- `/gongwen notice Notice on strengthening safety production`
- `/gongwen report 2023 Annual Work Summary Report`

Follow GB/T 9704-2012 standard with proper document structure and formatting.
