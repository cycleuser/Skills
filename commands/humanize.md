Load the humanizer skill and convert AI-generated text into natural human language.

**Usage**: `/humanize [options] <text>`

**Options**:
- `--style formal` - Formal humanization
- `--style casual` - Casual humanization
- `--target <number>` - Target AIGC rate (default 30%)
- `--demo` - Demo mode

**Examples**:
- `/humanize This is text that needs processing`
- `/humanize --style formal This article discusses...`

**Process**:
Style detection → AI feature analysis → Strategy selection → Iterative rewriting → Output report

Preserve meaning, reduce AI features, make text more natural.
