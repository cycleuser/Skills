Load the humanizer skill. Measure first, rewrite with the five-pass protocol, then re-measure and report the before/after numbers.

**Usage**: `/humanize [options] <text|file>`

**Options**:
- `--style casual|formal` — casual or formal register (default auto)
- `--mode light|full` — polish only, or full rewrite (default from the lint score)
- `--lang zh|en` — force language when the text is mixed
- `--profile prose|tech|academic` — threshold profile
- `check` — lint only, no rewrite
- `diff` — show before/after metrics

**Examples**:
- `/humanize This paragraph was generated by a model.`
- `/humanize --style formal --profile academic The proposed method ...`
- `/humanize check draft.md`

**Process**:
1. Detect language and register → 2. run `scripts/humanize_lint.py` → 3. pick mode → 4. five passes (preserve / skeleton / syntax / lexicon / evidence / layout) → 5. re-lint until under threshold → 6. deliver text + change summary + metrics

**Hard rules**: never touch numbers, terminology, citations, code, or direct quotes; never invent facts; mark gaps as `(TODO: ...)`.

**Note**: the score is a heuristic self-check, not an AI-detection verdict, and must not be used as evidence of authorship.
