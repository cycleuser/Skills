# /write

Load brief-write skill to create or rewrite text in user's blog writing style.

## Usage

```
/write <topic or text>
```

## Features

The brief-write skill will:
1. Analyze the input topic or text
2. Determine creation type (technical tutorial, technical explanation, personal story, opinion discussion)
3. Inject core spirit (honest, sincere sharing, rational pragmatic, strong empathy, critical spirit)
4. Apply language style (direct and concise, colloquial, specific details)
5. Avoid AI writing patterns (no bold labels, no list stacking, no academic tone)
6. Self-check with resemblance criteria, recreate if score below 7

## Examples

**Creation example:**
```
/write How to setup local AI programming environment
```

**Rewriting example:**
```
/write This article will comprehensively introduce the core principles of optimizers...
```

## Notes

- Created content automatically avoids "obviously AI" writing patterns
- Maintains colloquial, direct, concise, honest and sincere style
- No bold label formatting, no list stacking, no academic tone
