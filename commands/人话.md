# 人话 (Humanizer) 命令

对人话技能的调用入口，用于将AI生成的文本改写为更自然的人类语言。

## 使用方式

```bash
/人话 <文本或文件路径>
/人话 --style formal <文本>     # 书面化人化
/人话 --style casual <文本>     # 口语化人化
/人话 --target <目标AI率> <文本>
/人话 --demo                    # 演示模式
```

## 执行流程

```
1. 接收输入 → 获取用户提供的文本或文件
2. 风格识别 → 判断口语化或书面化
3. AI检测 → 分析文本的AI特征，计算AIGC率
4. 策略选择 → 根据检测结果选择改写策略
5. 迭代改写 → 多轮改写直至达到目标
6. 输出结果 → 展示改写前后对比和报告
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| --style | auto | 改写风格: auto/formal/casual |
| --target | 30 | 目标AIGC率(%) |
| --max-iter | 10 | 最大迭代次数 |
| --demo | false | 生成演示样本 |

## 书面化人化 (--style formal)

**适用场景:** 论文、报告、评论文章、专业文档

**核心策略:**
1. **取舍聚焦** — 不追求全面，聚焦核心问题
2. **立场表达** — 敢于表达判断，有明确观点
3. **深度分析** — 提出问题，剖析本质
4. **证据支撑** — 引用具体数据、案例、研究
5. **思考痕迹** — 展现推理过程，承认不确定性

**示例:**
```
输入 (AI率 94%):
可持续发展战略是当今世界面临的重要议题，具有深远的
现实意义和历史意义。从环境保护的角度来看，可持续发展
强调在满足当代人需求的同时，不损害后代人满足其需求的
能力。从经济发展的角度分析...综上所述...

输出 (AI率 23%):
"可持续发展"自1987年布伦特兰报告提出以来，已成全球
共识。但共识之下，实践却举步维艰。

环境保护的诉求不难理解——在代际公平的伦理框架下，
当代人不应透支未来的生存资源。问题在于，这一诉求
与既有的经济增长模式存在结构性冲突。

我认为，可持续发展的困境，归根结底是激励机制的错配。
当短期收益私有化、长期成本社会化成为常态，任何基于
道德呼吁的改革都难以奏效。
```

## 口语化人化 (--style casual)

**适用场景:** 博客、评论、社交媒体、非正式文章

**核心策略:**
1. **结构打散** — 删除总起总结，打乱顺序
2. **口语化** — 替换书面词汇，加入语气词
3. **个人化** — 加入个人经历和感受
4. **不完美化** — 长短句变化，思维跳跃

**示例:**
```
输入 (AI率 91%):
本产品是一款智能学习助手，旨在帮助用户提高学习效率。
产品具有以下核心功能：智能学习计划制定、个性化内容
推荐...

输出 (AI率 24%):
这App主打帮人学得更高效，功能嘛差不多就是那些：制定
计划、推题、记进度、答疑。

说真的，现在这类软件太多了。它家主打的是AI个性化推荐，
根据你的学习情况推内容。听起来挺好，但我用下来感觉...
就那样吧。
```

## 执行步骤

### Step 1: 风格识别

自动判断或使用指定风格:
- 分析词汇正式度
- 分析句式复杂度
- 判断文本场景

### Step 2: AI特征检测

调用 humanizer 技能的 AI特征识别规则:

```
结构特征分析:
- 段落均匀度
- 列表模式
- 过渡词频率

语言特征分析:
- AI高频词匹配
- 句式模式识别
- 空洞表达检测

内容特征分析:
- 观点立场
- 分析深度
- 证据支撑
- 思考痕迹
```

### Step 3: 策略选择

根据检测结果和风格，选择改写策略:

```
书面化策略:
├── AI率 > 70%: 取舍聚焦 + 立场表达 + 深度分析
├── AI率 50-70%: 证据补充 + 思考痕迹
└── AI率 30-50%: 细节打磨

口语化策略:
├── AI率 > 70%: 结构打散 + 口语化 + 个人化
├── AI率 50-70%: 不完美化 + 情绪注入
└── AI率 30-50%: 细节补充
```

### Step 4: 迭代改写

执行迭代优化循环:

```
while not converged:
    1. 应用当前策略改写文本
    2. 检测新的AIGC率
    3. 评估改写效果
    4. 检查质量指标
    5. 调整策略
    6. 检查收敛条件
```

### Step 5: 输出结果

生成包含以下内容的报告:
- 原文AI率 vs 改写后AI率
- 迭代过程摘要
- 主要修改点
- 改写后文本
- 质量评估

## 示例用法

### 示例1: 书面化人化

```
用户: /人话 --style formal
人工智能技术在各领域得到广泛应用，产生了深远的
影响。在医疗领域，AI辅助诊断系统提高了诊断效率；
在教育领域...

---

【AI特征检测】
综合AI率: 93%
主要特征: 典型AI书面语、空洞列举、无立场判断

【迭代1】策略: 取舍聚焦 + 立场表达
AI率: 93% → 58%

【迭代2】策略: 深度分析 + 证据补充
AI率: 58% → 31%

【迭代3】策略: 思考痕迹
AI率: 31% → 22%

✓ 达标！

【改写后文本】
AI的社会渗透程度，因应用场景而异，其影响机制也随之
呈现出显著差异。简单地宣称AI"产生深远影响"，无助于
理解其实际作用方式。

医疗领域的AI应用，核心价值在于降低诊断的边际成本。
但需要区分的是：影像识别类应用已经具备临床实用性，
而综合诊断类应用仍处于辅助阶段。

我认为，AI技术的社会影响，需要通过更细致的机制分析
来理解，而非泛泛地谈论"革命性变革"。
```

### 示例2: 口语化人化

```
用户: /人话 --style casual
远程办公是近年来兴起的工作模式。从效率角度看，远程
办公减少了通勤时间...

---

【AI特征检测】
综合AI率: 89%
主要特征: "从...角度看"结构、无个人视角

【迭代1】策略: 结构打散 + 口语化
AI率: 89% → 48%

【迭代2】策略: 个人化 + 不完美化
AI率: 48% → 25%

✓ 达标！

【改写后文本】
远程办公这事儿，这两年讨论挺多的。

先说效率。居家那会儿我感觉是高了——主要是省了通勤
时间。但也有人觉得效率变低了，说在家容易分心。这个嘛，
我觉得看人。

反正我是挺喜欢的，虽然有弊端。
```

### 示例3: 演示模式

```
用户: /人话 --demo

【生成高AIGC率示例文本】
[生成一段典型AI文本]

【检测】AI率: 96%

【迭代演示】
迭代1: AI率 96% → 62%
迭代2: AI率 62% → 38%
迭代3: AI率 38% → 24%

【最终结果】
[人化处理后文本]

【修改要点】
1. 删除AI套话结构
2. 加入明确立场
3. 补充具体分析
4. 展现思考过程
```

## 注意事项

1. **保持语义**: 改写不改变原文的主要意思
2. **风格统一**: 全文风格保持一致
3. **适度原则**: 不是AI率越低越好，30%以下通常足够
4. **人工审核**: 最终结果建议人工确认
