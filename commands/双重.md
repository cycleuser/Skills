# 双重 — 对抗式规划

加载 **shuang-chong** 技能，启动5角色3轮对抗式交叉批判辩论。

## 用法

```
/双重 <任务描述>
/adversarial <task description>
```

## 工作流

1. **第一轮**: 5个角色独立分析，各产出3-7条发现
2. **第二轮**: 每个角色攻击其他4个角色的发现
3. **第三轮**: 受攻击角色 DEFEND/REFINE/CONCEDE
4. **第四阶段**: 蒸馏存活洞察 → 硬约束/决策/风险/未决问题
5. **第五阶段**: 生成可执行计划

## 示例

```
/双重 设计一个容错分布式消息队列
/双重 status
/双重 plan
/adversarial Design a fault-tolerant distributed message queue
```

## 5个对抗角色

| 角色 | 定位 | 攻击方向 |
|------|------|----------|
| 实用主义者 | 简单性守卫 | 过设计、范围蔓延 |
| 集成测试者 | 不完整之敌 | 边界情况、跨模块交互 |
| 研究者 | 证据索取者 | 无据主张、浅层分析 |
| 架构师 | 坏架构之敌 | 泄露抽象、隐藏耦合 |
| 创意挑战者 | 正统思维之敌 | 替代方案、问题重构 |
