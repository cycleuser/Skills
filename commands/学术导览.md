# /学术导览

加载 academic-guide 技能，执行四步学术导览流程：搜论文 → 找站点 → 存记录 → 验引用。

## 使用方式

```
/学术导览 <领域名称>
```

## 四步流程

### 第一步：找博士论文
搜索和这个领域相关的博士论文，优先找近三年内的。整理出论文标题、作者、学校、年份、下载链接。标注免费(🆓)、机构访问(🏫)、完全封闭(🔒)。对🏫论文追加搜索预印本(arXiv/ResearchGate/作者主页)。

### 第二步：整理专业站点
搜索领域内公认的专业网站、论坛、数据库，排除百科类站点。记录站点名称、URL、简介、更新频率、访问方式。

### 第三步：搜索记录
每次搜索保留时间戳(ISO 8601)、搜索引擎名称、关键词、结果数、访问链接。所有记录写入 /tmp/academic-guide/{timestamp}/。

### 第四步：验证引用
将最终报告中的所有URL逐条打开验证，标注 ✅可访问 / ⚠️有限制 / ❌不可访问。失效链接尝试Wayback Machine替代，无法替代的从报告移除。

## 输出

最终报告保存到 /tmp/academic-guide/{YYYYMMDD-HHmmss}/final-report.md，包含：
- 一、博士论文列表
- 二、专业站点列表
- 三、搜索记录
- 四、引用验证报告
- 五、参考文献(每条链接已验证)
- 六、入门建议

## 详细规则

完整规则文件位于 ~/.config/opencode/skills/academic-guide/rules/ :
- dissertation-search.md — 博士论文搜索细则
- professional-sites.md — 专业站点整理细则
- search-records.md — 搜索记录保全细则
- citation-verification.md — 引用验证细则(最重要)
- output-format.md — 输出格式规范
- anti-aigc.md — 反AIGC检测规则

执行任务时务必先读取上述规则文件。
