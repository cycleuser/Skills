# /导览 站点

找站点子命令：搜索指定学术领域的专业网站、论坛、数据库。

## 使用方式

```
/导览 站点 <领域名称>
```

## 流程

1. 搜索引擎 + 论文反向发现 + 学术社区探索 三种方式交叉搜索
2. 排除通用百科类站点(Wikipedia、百度百科等)
3. 站点分类：预印本/论文库、文献数据库、论坛/社区、代码/数据平台、学会/组织、期刊/会议
4. 每条记录：站点名、URL、简介、更新频率、访问方式
