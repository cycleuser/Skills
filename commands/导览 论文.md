# /导览 论文

搜论文子命令：搜索指定学术领域的近三年博士论文。

## 使用方式

```
/导览 论文 <领域名称>
```

## 流程

1. 搜索多个数据库：Google Scholar, NDLTD, OATD, ProQuest, CNKI
2. 每条论文记录：标题、作者、学校、年份、下载链接
3. 标注获取方式：🆓免费 / 🏫机构 / 🔒封闭
4. 🏫论文：追加搜索arXiv、ResearchGate、作者个人主页找预印本
5. 输出格式见 dissertation-search.md
