# /导览 验证

验证引用子命令：对已有报告中的所有URL逐条打开验证。

## 使用方式

```
/导览 验证 <报告文件路径>
```

## 流程

1. 从报告中提取所有URL
2. 逐条webfetch打开验证
3. HTTP 200 → 检查页面内容是否匹配引用描述
4. 标注状态：✅已验证 / ⚠️有限制 / ❌不可访问
5. ❌链接尝试Wayback Machine https://web.archive.org/web/*/<url>
6. 无法替代的标记🔴已移除
7. 输出验证报告
