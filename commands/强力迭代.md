Load the power-iterate skill and start autonomous iteration on: $ARGUMENTS

**用法**: `/强力迭代 <任务> [选项]`

**示例**:
- `/强力迭代 构建REST API --time 60`
- `/强力迭代 开发完整功能 --budget large`

**预算选项**:
- `--time <分钟>`: 时间限制 (默认: 30)
- `--tokens <数量>`: Token限制 (默认: 100000)
- `--budget <级别>`: 预设预算 (tiny/small/medium/large/xlarge)

**特点**: 自主执行，无需确认，持续工作直到预算耗尽。
