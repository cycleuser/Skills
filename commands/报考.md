# /报考

加载报考技能，从官网搜索所有公开数据，进行交叉对比分析，给出实用建议。

## 使用方式

```
/报考 <查询内容>
```

## 功能说明

报考技能会：
1. 从教育部系统、省教育考试院、高校官网搜索公开数据
2. 下载一分一段表、录取分数线、招生计划、就业质量报告
3. 进行交叉对比分析
4. 用资深报考顾问风格给出实用建议（直接、接地气、有观点）

## 示例

**高考查询示例：**
```
/报考 北京 高考 580分 能报什么学校
/报考 计算机科学与技术专业就业前景
/报考 某大学历年分数线
```

**考研查询示例：**
```
/报考 某大学 法学硕士招生情况
/报考 计算机专业考研报录比
/报考 某大学就业质量报告
```

**一分一段表查询：**
```
/报考 北京 2024年一分一段表
/报考 580分在北京排名多少
```

## 注意事项

- 只使用官方数据源（教育部、省教育考试院、高校官网）
- 所有数据标注来源
- 分析时说明风险和坑点
- 用资深报考顾问风格表达（直接、接地气、有观点）
- 不隐瞒问题，不夸大前景
