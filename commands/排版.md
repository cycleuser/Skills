---
description: 排版 - 出版社级书籍排版，Markdown 章节目录 → PDF/DOCX，过 11 项硬门禁
agent: build
---

Load the pai-ban skill and typeset: $ARGUMENTS

**用法**: `/排版 <目录>`

**支持子命令**:
- `/排版 <目录>` - 从 Markdown 章节目录构建 PDF（默认同时出 DOCX，并自动跑验收）
- `/排版 init <目录>` - 在书稿目录脚手架 pai-ban.toml 配置 + assets 副本
- `/排版 check <pdf|目录>` - 跑硬排版门禁，输出 pass/fail 表
- `/排版 preview <目录>` - 编译 2–3 章样张并渲染页面 PNG，供人工/视觉复核
- `/排版 spec` - 打印权威设计规格

**示例**:
- `/排版 ~/books/llmap` - 构建整本书（中文）
- `/排版 init ~/books/llmap` - 初始化书稿配置
- `/排版 check ~/books/llmap/build/pai-ban/zh/<title>.pdf` - 单独跑验收

核心原则：版式是声明式配置 + 固定流水线 + 硬门禁验收，可复现、零宽容（零越界、零缺字形、零 LaTeX 错误、零 Overfull ≥1pt）。依赖 TeX Live（xeCJK/listings/booktabs/fancyhdr/microtype/hyperref），缺宏包明确报错不静默降级。PDF 为权威产物，DOCX 为可编辑副本。
