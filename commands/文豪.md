Load the literary-ghostwriter skill and create a work in the specified author's style.

## 支持的作家

| 命令 | 作家 | 风格要点 |
|-----|------|---------|
| `/文豪 莎士比亚` | William Shakespeare | 诗意语言、戏剧冲突、独白 |
| `/文豪 茨维格` | Stefan Zweig | 心理细腻、优雅叙事、命运感 |
| `/文豪 卡尔维诺` | Italo Calvino | 轻逸精确、奇幻寓言、结构实验 |
| `/文豪 鲁迅` | 鲁迅 | 简洁犀利、冷峻批判、白描 |
| `/文豪 老舍` | 老舍 | 京味儿语言、幽默讽刺、口语化 |
| `/文豪 金庸` | 金庸 | 文白相间、章回体、侠义精神 |
| `/文豪 古龙` | 古龙 | 极简诗意、短句为主、悬念反转 |

## 使用示例

```bash
/文豪 鲁迅 写一个关于校园欺凌的故事
/文豪 老舍 写一个北京胡同里的故事
/文豪 金庸 写一个年轻侠客初入江湖的故事
/文豪 古龙 写一个孤独刀客的故事
```

## 创作要求

1. **风格纯正**: 必须准确把握作家风格特征
2. **语言地道**: 中英双语都要母语级水平
3. **主题契合**: 根据选题灵活运用风格
4. **有始有终**: 完整的故事或文章
