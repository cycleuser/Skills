Load the research-figure skill and run the sketch-to-SVG pipeline: $ARGUMENTS

**用法/Usage**: `/画图 <草图路径或描述> [输出路径]` or `/fig <sketch> [out]`

**子命令**:
- `/画图 <草图路径> [输出]` — 全流程：读草图→布局JSON→SVG→校验→精修
- `/画图 from-json <layout.json> [输出]` — 由布局JSON生成SVG
- `/画图 from-text "<描述>" [输出]` — 无草图，按文字描述生成
- `/画图 validate <file.svg>` — 只校验已有SVG的重叠/溢出/裁切
- `/画图 template` — 查看网格化SVG模板用法
- `/fig from-json <layout.json> [out]` — 英文别名

**核心流程**:
1. 视觉模型读取草图 → 结构化布局 JSON（DeepSeek 纯文本模型需可读图模型）
2. 网格单元放置盒子（构造上无重叠）
3. 生成 SVG：显式 viewBox、命名锚点箭头、自动换行/缩字（最小9pt）、Wong 色盲安全配色
4. `python3 scripts/validate_svg.py figure.svg` 必须 0 失败
5. 渲染 PNG + 视觉复核，问题回填迭代，直至 0 失败

**交付**: SVG + PNG 预览，附校验报告。
