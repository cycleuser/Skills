# /简写

加载简写技能，按用户博客写作风格创作或改写文本。

## 使用方式

```
/简写 <主题或文本>
```

## 功能说明

简写技能会：
1. 分析输入的主题或文本
2. 判断创作类型（技术教程、技术解释、个人故事、观点讨论）
3. 注入精神内核（诚实坦率、真诚分享、理性务实、强烈共情、批判精神）
4. 应用语言风格（直接简洁、口语化、具体细节）
5. 避免AI写作禁忌（无粗体标签、无列表堆砌、无学术腔调）
6. 按神似评判标准自检，低于7分则重新创作

## 示例

**创作示例：**
```
/简写 如何搭建本地AI编程环境
```

**改写示例：**
```
/简写 本文将全面介绍优化器的核心原理...
```

## 注意事项

- 创作内容会自动避免"一眼AI"的写作模式
- 保持口语化、直接简洁、真诚坦率的风格
- 不使用粗体标签格式，不堆砌列表，不用学术腔调
