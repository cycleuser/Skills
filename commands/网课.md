# 网课助手

网课鼠标保持技能。自动控制鼠标微移，防止网课平台因鼠标离开/静止而暂停视频。

## 用法

- `/网课` — 启动默认模式（每30秒微移鼠标）
- `/网课 start [间隔秒]` — 自定义间隔启动
- `/网课 stop` — 停止
- `/网课 click` — 点击模式
- `/网课 tampermonkey` — 生成油猴脚本

## 快速使用

```bash
python3 ~/.config/opencode/skills/wang-ke/scripts/mouse_keeper.py --interval 30
```

停止：Ctrl+C 或 鼠标移到屏幕角落
