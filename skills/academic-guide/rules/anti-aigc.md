# 反AIGC检测规则 (Anti-AIGC Rules for Academic Guide)

学术导览报告容易被识别为AI生成的主要原因：泛泛而谈的领域介绍、无具体数据的描述、模板化的句式结构。以下规则针对这些问题。

## 禁止句式 / Forbidden Phrases

以下表述在任何情况下不得出现在导览报告中，因为它们"AI味"太重，且不提供实际信息：

### 禁止的泛泛介绍
- "近年来，{领域}受到越来越多的关注"
- "{领域}是一个快速发展的研究领域"
- "该领域涉及多个学科交叉"
- "研究者们致力于探索..."
- "未来发展方向包括..."
- "该领域具有广阔的应用前景"
- "这对...具有重要意义"

### 替代方案
```
禁止: "近年来，计算语言学受到越来越多的关注"
替代: "ACL年会的投稿量从2019年的2,900篇增长至2024年的5,200篇 [1]"

禁止: "该领域具有广阔的应用前景"
替代: "NLP在医疗领域的市场规模2023年达到39亿美元，主要应用包括病历结构化、药物不良反应监测 [2]"

禁止: "这是一个快速发展的研究领域"
替代: "arXiv cs.CL分类下2024年日均新增论文18篇 [3]"
```

## 数据密度要求

- 报告中每一段至少包含一个可验证的数据点（数字、URL、引用编号）
- "快速导读"章节信息密度最高，每句话应有来源
- 站点简介不用"该网站是领域内的重要资源"，改用"收录论文3.2万篇，日均用户1.2万"

## 报告语调

- 中性、客观、基于事实
- 用"根据[来源]，..."而非"据了解"、"众所周知"
- 不替用户做价值判断（如"推荐这个站点因为..." → 改为罗列客观指标让用户自己判断）
- 承认信息的局限性："以下站点基于{日期}的搜索结果整理，可能未收录新成立或知名度较低的优质资源"

## 模板检查

反AIGC检测的一个关键指标是是否存在明显的模板套用痕迹。以下措施确保报告看起来不是填空模板：

1. **各节长度不必均匀** — 论文很多的领域，Phase 1 可以很长；站点很少的领域，Phase 2 可以很短加说明
2. **快速导读不要公式化** — 不是所有领域都要介绍"三大方向"、"两类方法"，有的领域只有一个核心问题
3. **入门建议要有立场** — 不写"建议从基础开始逐步深入学习"，写"该领域的标准入门路径是：XXX的论文[1] + YYY的公开课[2]，预计需要3个月"
4. **承认不知道** — 搜索不到的就说搜索不到，不要用"该方面资料较少"搪塞，写"搜索{数据库}、{数据库}后未找到相关博士论文"

## 引用密度

- 快速导读：≥2 个引用/句
- 博士论文节：每条论文必须有来源URL
- 站点节：每个站点必须有来源URL
- 入门建议：≥1 个引用/条建议
