# 引用验证细则 (Citation Verification Rules) ⚠️

## ⚠️ 这是整个学术导览流程中最重要的一步

**没有经过逐条验证的引用，一律不得放入最终报告。**

别人根据你的报告去查资料，每点一个链接都应该能打开对应的内容。如果链接失效、指向内容不匹配、或需要付费才能看但没有标注，就失去了导览的意义。

## 验证范围

最终报告中出现的所有URL都必须验证，包括：
- 博士论文的下载链接和预印本链接
- 专业站点的URL
- 搜索URL（验证搜索URL格式正确即可）
- 参考文献列表中的所有链接

## 验证操作流程

### 对每个URL依次执行：

```
1. 打开链接
   → 使用 webfetch 工具实际访问
   
2. 检查HTTP状态
   → 200 OK        → ✅ 进入内容验证
   → 301/302 重定向 → 跟随重定向后判断
   → 403 Forbidden → ❌ 权限不足
   → 404 Not Found → ❌ 链接失效
   → 超时          → ⚠️ 临时不可达，重试一次
   
3. 内容验证（仅对HTTP 200的链接）
   → 论文链接：页面上是否包含引用的标题和作者名
   → 站点链接：页面内容是否符合"简介"栏的描述
   → 搜索链接：URL格式是否符合搜索URL构建规范
   
4. 记录验证状态
   → ✅ 已验证可访问 — 链接正常，内容匹配
   → ⚠️ 可访问但有限制 — 需登录/付费墙/仅显示摘要/部分内容不可见
   → ❌ 不可访问 — 404/403/超时
```

## 验证状态判定细则

### ✅ 已验证可访问
- HTTP 200
- 页面内容包含引用所描述的信息
- 论文标题、作者名可在页面上找到
- 无需登录或特殊权限即可看到核心内容

### ⚠️ 可访问但有限制
特别标注限制类型：
- `⚠️ 需登录` — 页面存在但需要账号
- `⚠️ 付费墙` — 可见摘要，全文需付费
- `⚠️ 摘要仅` — 只有摘要，正文不可见
- `⚠️ 地理限制` — 从访问IP受限，但确认页面存在
- `⚠️ 内容有差异` — 页面可访问但内容与引述不完全一致

### ❌ 不可访问
- HTTP 404/410 — 页面不存在或已删除
- HTTP 403 — 访问被拒绝
- DNS解析失败 — 域名不存在或已过期
- 连接超时（重试一次后仍超时）
- 内容完全不匹配 — 页面存在但与引用描述毫无关系

## 失效链接替代方案

对于被标记为❌的链接，按以下顺序尝试替代：

1. **Wayback Machine 存档**
   ```
   https://web.archive.org/web/*/{原始URL}
   ```
   如果找到存档，标注：`✅ 已通过 Wayback Machine 验证 ([存档链接])`

2. **Google 缓存**
   在 Google 搜索中点击搜索结果旁的绿色三角 → "缓存"

3. **替代来源**
   - 论文：搜索作者个人主页、ResearchGate、学术机构库
   - 站点：搜索站点新域名（站点迁址常见）
   - 信息：搜索类似信息在别的站点

4. **实在找不到替代**
   将该条引用从最终报告中移除，在验证报告中记：
   `🔴 已移除 — 链接失效且无替代来源`

## 验证报告格式

```markdown
## 引用验证报告 / Citation Verification Report

**验证时间**: 2026-07-23T15:30:00+08:00
**总链接数**: {N}
**验证通过**: {✅ N}
**有限制但可用**: {⚠️ N}
**验证失败已移除**: {❌ N}

### 逐条验证结果

#### 博士论文链接

| # | 链接 | 状态 | 内容匹配 | 备注 |
|---|------|------|----------|------|
| 1 | [https://...](url) | ✅ | ✅ 标题、作者、学校均匹配 | |
| 2 | [https://...](url) | ⚠️ | ⚠️ 仅显示摘要 | 需ProQuest机构登录 |
| 3 | [https://...](url) | ❌ | — | 404，已用Wayback替代 [链接] |
| 4 | [https://...](url) | 🔴 | — | 失效且无替代，已从报告移除 |

#### 专业站点链接

| # | 链接 | 状态 | 内容匹配 | 备注 |
|---|------|------|----------|------|
| 1 | [https://...](url) | ✅ | ✅ 站点存在，内容与描述一致 | |
| 2 | [https://...](url) | ✅ | ✅ | |

#### 搜索链接

| # | 链接 | 状态 | 格式验证 | 备注 |
|---|------|------|----------|------|
| 1 | [https://scholar.google.com/scholar?q=...](url) | ✅ | ✅ 格式正确 | |
```

## 最终参考文献列表格式

验证完成后，只有状态为 ✅ 或 ⚠️ 的引用进入最终参考文献列表：

```markdown
## 参考文献 / References

[1] Author, A. (2024). Title of Dissertation. PhD thesis, University Name. https://example.edu/thesis/123 [✅ 已验证]

[2] Author, B. (2023). Another Title. PhD thesis, Another University. ProQuest Dissertations. https://proquest.com/... [⚠️ 需机构登录]

[3] Site Name. (2024). Description. https://example.com [✅ 已验证]

[4] Author, C. (2023). Title. arXiv preprint. https://arxiv.org/abs/... [✅ 已验证，替代官方版本]

...
```

## 引用格式规范

- 论文引用格式：APA 7th（作者, 年份, 标题, 学位类型, 机构, URL）
- 网站引用格式：站点名称. (年份). 描述. URL
- 每条引用末尾标注验证状态
- URL必须是完整可点击格式
- 中文引用使用中文标点，英文引用使用英文标点

## 验证不通过的处理

```
如果一条引用验证不通过:
→ 尝试替代来源
→ 找到替代 → ✅ 更新链接，备注"替代来源"
→ 找不到替代 → 🔴 从报告中移除该条引用和相关陈述
→ 如果移除后该节内容不足，补充搜索同方向论文

绝不保留任何未经验证的引用。
```

## 验证完整性检查清单

最终报告输出前，逐项检查：
- [ ] 报告中所有URL都已逐条验证
- [ ] 验证状态（✅/⚠️/❌）已正确标注
- [ ] ❌链接已尝试Wayback Machine替代
- [ ] ❌链接无法替代的已从报告移除
- [ ] 参考文献列表仅包含已验证的引用
- [ ] 每条引用末尾有验证状态标注
- [ ] 引用格式符合规范（APA 7th）
- [ ] 参考文献列表可脱离正文独立阅读和验证
