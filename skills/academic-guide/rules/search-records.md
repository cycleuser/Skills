# 搜索记录保全细则 (Search Record Preservation Rules)

## 记录原则

**每次搜索都必须留下可复现的记录。** 另一个研究者按照记录应该能得到近似的结果。

## 单次搜索记录格式

```markdown
### 搜索 #{N}: {简要描述}

| 字段 | 内容 |
|------|------|
| **时间** | 2026-07-23T14:30:00+08:00 (ISO 8601) |
| **搜索引擎/数据库** | {Google Scholar / ProQuest / CNKI / arXiv / 百度 / ...} |
| **搜索URL** | {可点击的搜索URL} |
| **关键词** | {实际使用的关键词，含引号、site:等操作符} |
| **过滤条件** | {时间范围、语言、排序方式等} |
| **返回结果数** | {约 N 条（搜索引擎估算值）} |
| **实际浏览页数** | {N 页} |
| **选取结果数** | {N 条} |
| **备注** | {任何值得记录的情况，如搜索被限频、需要VPN等} |
```

## 搜索URL构建规范

### Google Scholar
```
https://scholar.google.com/scholar?q={URL编码的关键词}&as_ylo={起始年}&as_yhi={结束年}
```

### Google
```
https://www.google.com/search?q={URL编码的关键词}&tbs=qdr:y3
```
（qdr:y3 = 最近3年）

### CNKI
基础搜索URL格式：
```
https://kns.cnki.net/kns8s/defaultresult/index?kwd={URL编码的关键词}
```

### arXiv
```
https://arxiv.org/search/?query={URL编码的关键词}&searchtype=all
```

## 记录保存位置

每次学术导览的所有记录保存在：
```
/tmp/academic-guide/{YYYYMMDD-HHmmss}/
├── phase3-search-log.md       # 完整搜索记录
└── raw/
    ├── search-01-response.txt # 原始搜索结果文本（可选，当结果较小时）
    ├── search-02-response.txt
    └── ...
```

## 记录完整性检查清单

在输出最终报告前，逐项确认：
- [ ] 每次搜索都有时间戳（ISO 8601）
- [ ] 每次搜索都有可点击的搜索URL
- [ ] 每次搜索列出了实际使用的关键词（含引号和操作符）
- [ ] 每次搜索标注了结果数量和选取数量
- [ ] 所有搜索的汇总表完整
- [ ] 如果使用了截图，截图文件已保存并标注路径

## 不记录的例外情况

以下情况无需记录：
- 在已知URL上直接打开页面获取特定信息（如打开某篇已知论文的详情页）
- 搜索结果全部无用时也需记录，标注"0条收录"
- 重复搜索已有URL的更新情况（标注"复查"）
