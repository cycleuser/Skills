## Section Content Guidelines

### Abstract (150-200 words)

```
Template:
[Context, 1-2 sentences]: In [domain], [problem] is important because...
[Problem, 1-2 sentences]: However, existing methods suffer from...
[Solution, 2-3 sentences]: This paper proposes [method], which...
[Results, 1-2 sentences]: Experiments on [dataset] show that...
```

### Introduction

```
Paragraph 1: Establish importance of the problem
Paragraph 2: Describe challenges and limitations of existing work
Paragraph 3: Introduce proposed approach and intuition
Paragraph 4: Summarize contributions
```

### Related Work

```
For each category:
1. Define the category
2. Describe representative methods
3. Discuss their strengths and limitations
4. Conclude with how your work differs
```

### Methodology

```
1. Formal problem statement with notation
2. High-level overview with figure
3. Detailed description of each component
4. Algorithm pseudocode or flowchart
5. Theoretical analysis (if applicable)
```

### Experiments

```
1. Implementation details
2. Dataset description
3. Baseline methods
4. Main comparison results
5. Ablation studies
6. Parameter analysis
7. Case studies or visualization
```

### Conclusion

```
1. Restate the problem and contribution
2. Summarize key findings
3. Acknowledge limitations
4. Suggest future directions
```

## Page Allocation

For an 8-page paper:

| Section | Pages |
|---------|-------|
| Abstract | 0.1 |
| Introduction | 1.0 |
| Related Work | 0.8 |
| Methodology | 2.5 |
| Experiments | 2.5 |
| Conclusion | 0.1 |
| References | 1.0 |

## Figure and Table Placement

- Place figures after first mention
- Center figures with captions below
- Tables should be compact and readable
- Number sequentially (Figure 1, Table 1)
