# 材料包目录与命名 (Packing & Naming)

## 目录组织

```
<姓名/单位>-<材料名>-<YYYYMMDD>/
├── 1-表格/           # 填好的各表格
├── 2-正文/           # 事迹/申报书/报告 docx
├── 3-证据/           # 证据图（按条目命名）
├── 4-清单.md         # 材料清单（文件名、内容、来源、状态）
└── README.md         # 打包说明
```

## 命名规范

- 表格：`<附件号>-<表名>-<姓名>.docx`
- 证据：`<年度>-<奖项/成果名>-<排名/编号>.<ext>`
- 正文：`<姓名>-<材料名>.docx`

## 收尾

- 生成材料清单 md：每份文件的来源路径、内容、校验状态。
- 最后整体过一遍 verify-deliver：全部文件可打开、命名规范、表格与正文数字一致、证据无缺漏。
