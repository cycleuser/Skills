# 报考数据文件索引 v5.0

## 数据总览

本技能包含全国 31 个省份/直辖市/自治区过去 6 年（2020-2025）的真实高考分数线数据。

**数据政策（严格执行）：**
- ✅ **所有数据均来自教育在线 (gaokao.eol.cn) 官方发布**
- ✅ **每条数据都标注了具体来源 URL，可追溯验证**
- ✅ **无任何模拟、生成或虚构数据**
- ✅ **已删除所有可能产生假数据的脚本和 JSON 文件**
- ✅ **已删除所有 rank_tables、schools、majors、all_provinces 目录**
- ⚠️ 2015-2019 年历史数据：官方来源（gaokao.eol.cn）仅公开 2020 年及之后数据

---

## 一、数据文件结构（精简版）

```
bao-kao/data/
├── README.md                        # 本索引文件
├── beijing/
│   └── gaokao_scores.md           # 北京市真实数据
├── tianjin/
│   └── gaokao_scores.md           # 天津市真实数据
├── hebei/
│   └── gaokao_scores.md           # 河北省真实数据
└── ... (共 31 个省份，每个省份一个 gaokao_scores.md)
```

**已删除的假数据目录：**
- ❌ `rank_tables/` - 一分一段表（已删除全部 31 个目录，约 500+ JSON 文件）
- ❌ `schools/` - 学校数据（已删除）
- ❌ `majors/` - 专业数据（已删除）
- ❌ `all_provinces/` - 汇总文件（已删除）
- ❌ `scripts/` - Python 脚本（已删除全部）
- ❌ `*.json` - JSON 数据文件（已删除全部）

## 二、数据内容

### 2.1 分省详细数据

每个省份仅包含一个文件：`gaokao_scores.md`

**包含内容：**
- 2020-2025 年高考分数线（本科批、特殊类型招生线、专科线）
- 每条数据都标注来源 URL
- 2015-2019 年数据标注为"暂无官方公开数据"并说明原因
