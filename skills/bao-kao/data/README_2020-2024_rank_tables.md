## 遇到的问题

### 数据以图片形式展示
以下省份的多数年份数据以图片形式展示，无法通过 webfetch 提取：
- 天津（2020、2022、2021、2024）
- 上海（2020）
- 浙江（2020、2022、2021）
- 山东（2020、2022、2021、2024）
- 海南（2020、2022、2021、2024）
- 江苏（2024）
- 辽宁（2024）
- 以及大部分省份的 2022、2021 年数据

### 页面 404 或无法访问
- 大量省份的特定年份 URL 已失效
- 尝试访问的 URL 大部分返回 404 错误

### 响应过大
- 山东 2020 年数据响应超过 5MB 限制，无法完整获取

## 建议
如需获取完整数据，建议：
1. 直接访问各省教育考试院官方网站
2. 使用 OCR 技术提取图片中的表格数据
3. 查找其他数据源（如各省教育考试院官网）
