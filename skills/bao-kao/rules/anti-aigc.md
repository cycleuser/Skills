# 报考咨询反AIGC检测规则

报考咨询回复面向的是学生和家长，他们的AIGC检测直觉很强——一看就知道这建议是不是"套话"。报考回复必须在专业性和接地气之间找到平衡。

## 核心原则

报考咨询的专业性来自数据具体性和坦诚的风险评估，不是来自书面腔或官话。反AIGC关键是：说人话、给具体数据、敢说风险、有自己的判断。

## 报考咨询AIGC高发模式

### 1. 官话套话（权重35%）

```
❌ AI报考回复典型模式：
"该专业就业前景广阔，毕业生可在多个领域发展"
"建议考生根据自身情况合理选择"
"具体录取分数线请以官方公布为准"
"该院校综合实力较强，值得考生重点关注"

✅ 专业且接地气的写法：
"这专业就业率65%，平均起薪4500，别听招生简章说的90%"
"480分在吉林省理科排名大概33000左右，冲吉林大学有风险，东北师范大学都悬"
"这学校就业率数据好看是因为把考研的也算进去了，实际签约率不到40%"
"别报，报了就后悔——除非你能接受毕业后去工厂做质检"
```

### 2. 数据空洞（权重25%）

```
❌ 无数据的空洞建议：
"录取分数线相对较高"
"就业前景不错"
"竞争较为激烈"
"该校在相关领域有一定优势"

✅ 有具体数据的建议：
"2024年吉林大学计算机在吉林省理科最低录取分548，省排名12000左右"
"这个专业全国就业率平均55%，好的学校能到70%，差的连30%都不到"
"你490分排名大概28000，211基本没戏，重点看省属重点"
"这个学校软件工程2023届平均签约薪资6800，比计算机低1200，但比信息管理高2300"
```

### 3. 风险回避（权重20%）

```
❌ AI倾向回避风险：
"考生可综合考虑各方面因素做出选择"
"建议考生多方了解后做出决定"
"具体情况因人而异"

✅ 敢说风险：
"这学校转专业成功率不到5%，别想着先进去再转"
"中外合作办学学费一年35000，是你想清楚再报的"
"这专业是红牌专业，就业率连续3年低于60%"
"这个省的专项计划你不够条件，别浪费志愿名额"
```

### 4. 格式化建议结构（权重20%）

```
❌ AI格式化输出：
**学校概况：** XX大学是...
**优势专业：** 该校在XX领域...
**录取分析：** 根据往年数据...
**报考建议：** 建议考生...

✅ 自然流畅的回复：
480分在吉林理科什么位置？2024年一分一段表告诉你，大概排在33000名左右。

这个分想冲211，只有延边大学有点希望，而且得是冷门专业。重点考虑省属重点院校——长春理工的光电、东北电力的电气，这两个学校在这个分段性价比最高。

注意两个坑：第一，别冲吉林大学的冷门专业，万一录了转专业成功率不到5%；第二，中外合作办学看着分数线低，学费35000起，想清楚再报。
```

## 报考咨询专业表达反AI策略

### 策略1：数据先行

任何建议必须有数据支撑。不写"就业前景好"，写"就业率72%，平均薪资5800"。

### 策略2：风险明说

不回避任何风险。这是学生一辈子的事，含糊其辞等于害人。

### 策略3：有立场

给出明确的优先级排序，而不是"都挺好的看你喜欢"。

### 策略4：说人话

不用"考生"、"该校"、"综合考量"之类的官话，用"你"、"这学校"、"说实话"。

### 策略5：打破对称

不要每个专业/学校都用相同篇幅分析。重要的详细说，次要的一两句带过。

## AIGC率检测清单

### 内容检测
- [ ] 每个判断是否有具体数据支撑？→无数据=AI特征
- [ ] 是否回避了风险描述？→回避风险=AI特征
- [ ] 是否有明确的优先级推荐？→面面俱到=AI特征
- [ ] 是否指出了具体的坑和陷阱？→不指出=AI特征

### 语言检测
- [ ] 是否使用了官话套话？→有则AI嫌疑大
- [ ] 是否用了"根据自身情况综合考虑"？→有则AI特征
- [ ] 数据是否具体（含数字、百分比、排名）？→不具体=AI特征
- [ ] 语气是否像真人顾问？→过于正式=AI特征

### 结构检测
- [ ] 是否每段结构雷同？→雷同=AI特征
- [ ] 是否有加粗标题+冒号+内容的模式？→有则AI特征明显
- [ ] 重要和次要内容篇幅是否有区分？→均匀=AI特征

### AIGC率评分标准

- 0-15%：像经验丰富的报考顾问，有数据有立场敢说风险
- 16-30%：基本合格，有少量官话
- 31-50%：需修改，AI痕迹明显——太空洞
- 51-70%：需重写，满篇套话
- 71-100%：完全AI生成的模板回复
