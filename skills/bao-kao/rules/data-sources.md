# 官方数据源详细清单

本文档列出所有必须搜索的官方数据源，按优先级排列。

---

## 一、教育部系统（最高优先级）

### 1. 学信网（高等教育学生信息咨询与就业指导中心）

**网址：** `https://www.chsi.com.cn`

**可用数据：**
- 高校名单（所有正规高校列表）
- 专业名单（各高校开设专业）
- 学历认证（验证学历真伪）
- 就业数据（部分高校就业统计）

**查询方式：**
```
访问学信网 -> 高校名单 -> 查询目标学校
访问学信网 -> 专业查询 -> 查询目标专业
```

### 2. 中国研究生招生信息网

**网址：** `https://yz.chsi.com.cn`

**可用数据：**
- 招生简章（所有高校研究生招生简章）
- 招生专业目录（各高校研究生专业）
- 复试分数线（各高校历年复试分数线）
- 报录比（部分高校公开）
- 考试科目（各专业考试科目）
- 参考书目（部分高校公开）

**查询方式：**
```
访问研招网 -> 招生简章 -> 查询目标学校
访问研招网 -> 专业目录 -> 查询目标专业
访问研招网 -> 复试分数线 -> 查询历年分数线
```

### 3. 全国普通高校招生信息公开平台

**网址：** `https://gaokao.chsi.com.cn`

**可用数据：**
- 高校招生计划（各高校在各省招生人数）
- 录取分数线（各高校历年录取分数线）
- 专业列表（各高校开设专业）
- 选科要求（新高考省份）

**查询方式：**
```
访问高考信息公开平台 -> 查询学校 -> 查看招生计划
访问高考信息公开平台 -> 查询学校 -> 查看录取分数线
```

### 4. 教育部官网

**网址：** `http://www.moe.gov.cn`

**可用数据：**
- 教育政策（最新教育政策文件）
- 高校名单（正规高校认证名单）
- 专业目录（本科/研究生专业目录）
- 就业统计（全国就业统计数据）

**查询方式：**
```
访问教育部官网 -> 政策文件 -> 查询最新政策
访问教育部官网 -> 数据统计 -> 查询就业数据
```

## 三、各高校官网招生栏目

### 目标高校官网招生栏目

**通用访问方式：**
- 网址：`[目标高校官网域名]/admission`（或官网首页"本科招生/招生网"入口）
- 数据：招生简章、专业列表、历年分数线、招生计划

**注意：**
- 具体高校以搜索到的**官方招生网站**为准（域名通常含 `edu.cn`，且为 `.edu.cn` 一级域名或学校官网子路径）。
- 不要凭记忆写某校的网址；现场搜索确认。
- 分档：985 / 211 / 双一流 / 省属重点 / 普通本科，各类别高校均可按同样方式查其官方招生栏目。

## 四、各高校就业质量报告

### 就业质量报告查询方式

**查询步骤：**
1. 访问目标学校官网
2. 查找"就业指导中心"或"就业信息网"
3. 查找"就业质量年度报告"
4. 下载PDF文件

**典型网址格式：**
- `[学校官网]/career-center/`
- `[学校官网]/employment/`
- `[学校官网]/jiuye/`

**报告内容：**
- 毕业生规模结构
- 就业率（总体、分专业）
- 就业去向（行业、地区、单位性质）
- 薪资水平
- 就业满意度

## 六、数据获取方法

### 方法1：直接访问官网下载

**步骤：**
1. 访问官网
2. 查找数据栏目
3. 下载PDF/Excel文件

### 方法2：使用webfetch工具搜索

**步骤：**
1. 用webfetch工具访问官网
2. 搜索关键词（如"一分一段表"、"录取分数线"）
3. 提取数据链接
4. 下载文件

### 方法3：交叉验证

**步骤：**
1. 从多个官网获取同一数据
2. 对比数据是否一致
3. 如有差异，取最新官方数据

## 十、数据更新频率

### 必须更新的数据

**每年更新：**
- 高考一分一段表（6-7月）
- 高考录取分数线（7-8月）
- 高考招生计划（5-6月）
- 考研招生简章（9-10月）
- 考研复试分数线（3-4月）
- 就业质量报告（12月）

**定期更新：**
- 专业列表（教育部调整时）
- 学校名单（教育部调整时）
- 政策文件（政策变化时）

## 十一、数据验证方法

### 验证原则

**多源验证：**
- 从至少2个官网获取同一数据
- 对比数据是否一致
- 如有差异，查明原因

**时效验证：**
- 检查数据年份
- 检查数据发布日期
- 检查数据更新日期

**完整性验证：**
- 检查数据是否完整
- 检查数据是否有缺失
- 检查数据是否有异常

---

## 十二、数据使用原则

### 只用官方数据

**禁止使用：**
- 第三方平台数据
- 培训机构数据
- 不明来源数据

**只用官网：**
- 教育部系统数据
- 省教育考试院数据
- 高校官网数据

### 必须标注来源

**标注格式：**
- "数据来源：学信网，年份2024"
- "数据来源：北京教育考试院，年份2024"
- "数据来源：某高校官网，年份2024"

### 必须检查时效

**时效检查：**
- 检查数据年份
- 检查数据是否最新
- 标注数据年份
