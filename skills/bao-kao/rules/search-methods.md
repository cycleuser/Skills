## 官方网站搜索技巧/Official Site Search Tips

### 学信网搜索方法

```
1. 直接访问 https://www.chsi.com.cn
2. 导航路径：高校名单 → 输入学校名称 → 查看详情
3. 导航路径：专业查询 → 选择专业类别 → 查看专业列表
4. 使用 site:chsi.com.cn 在搜索引擎辅助定位具体页面
5. 高考数据：访问 https://gaokao.chsi.com.cn → 招生计划/分数线
```

### 研招网搜索方法

```
1. 直接访问 https://yz.chsi.com.cn
2. 导航路径：硕士 → 招生简章 → 输入学校名称
3. 导航路径：硕士 → 专业目录 → 选择学科门类 → 查询
4. 导航路径：硕士 → 复试分数线 → 选择学校/地区
5. 使用 site:yz.chsi.com.cn 在搜索引擎辅助定位
```

## 数据交叉验证方法/Cross-Reference Techniques

### 双源验证规则

```
规则1：同一数据必须从至少 2 个独立官方来源获取
规则2：两个来源数据差值 ≤ 5% 视为一致
规则3：差值 > 5% 需查找原因，取更新来源数据
规则4：无法找到第二来源时，标注"单源数据，待验证"
```

### 分数线交叉验证

```
来源A：学信网高考信息公开平台
来源B：省教育考试院官网
来源C：学校官网招生栏目

验证步骤：
1. 从来源A获取某校某年在某省的录取分数线
2. 从来源B获取同校同年同省的录取分数线
3. 从来源C获取同校同年的录取分数线
4. 对比三者是否一致
5. 如不一致，取最新发布者数据并标注差异
```

### 一分一段表验证

```
来源A：省教育考试院官网
来源B：教育部高考信息公开平台

验证步骤：
1. 下载同省同年的一分一段表
2. 对比总分人数和各分段人数
3. 检查累计人数是否连续递增
4. 抽查若干分数段人数是否合理
5. 如有差异，以省考试院数据为准
```

### 就业数据验证

```
来源A：学校官网就业质量报告
来源B：教育部就业统计
来源C：行业薪资统计报告

验证步骤：
1. 对比学校报告就业率与同行业平均水平
2. 就业率异常高（>95%）需仔细审查是否含灵活就业
3. 薪资数据与行业平均对比，偏差>30%需标注
4. 标注数据年份和来源
```

## 搜索结果评估/Search Result Evaluation

### 时效性评级

| 标记 | 含义 | 使用规则 |
|------|------|---------|
| ✅ 当前 | 当年或上一年数据 | 直接使用 |
| ⚠️ 近期 | 2-3 年内数据 | 可使用，标注年份 |
| ❌ 过期 | 3 年以上数据 | 仅作趋势参考，不用于决策 |

### 可信度评级

| 来源 | 可信度 | 说明 |
|------|--------|------|
| 教育部系统 | ★★★★★ | 最高优先级 |
| 省教育考试院 | ★★★★★ | 官方权威数据 |
| 高校官网 | ★★★★☆ | 官方但可能有宣传倾向 |
| 国家统计局 | ★★★★★ | 行业权威数据 |
| 第三方平台 | ★☆☆☆☆ | 禁止使用 |

## 搜索流程/Search Workflow

```
1. 确定查询目标（学校/专业/分数线/就业数据）
      ↓
2. 构造查询语句（使用对应查询模板）
      ↓
3. P0 搜索教育部系统（学信网/研招网/高考平台）
      ↓
4. P1 搜索省教育考试院
      ↓
5. P2 搜索高校官网
      ↓
6. 提取数据并标注来源
      ↓
7. 交叉验证（至少双源）
      ↓
8. 时效性检查（标注年份）
      ↓
9. 输出数据 + 来源标注 + 时效标注
```
