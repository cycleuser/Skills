# 命名规范与重命名安全 (Naming & Safe Rename)

## 命名规范模板

常见形如：

```
<年度>-<赛事/主题>-<归属主体，顿号分隔>-<奖项/级别>-<类型后缀>.<ext>
例: 2026-全国大学生XX大赛-学生甲、学生乙、学生丙-指导教师甲、指导教师乙-国赛三等奖-获奖证书.jpeg
```

或媒体类：`<来源>-<序号>-<名称>.<ext>`（如 `UP主_歌曲名.mp3`）。

命名要素按批次内容定，先与用户确认模板，再批量执行。

## 重命名安全流程

1. 生成 `old -> new` 映射表（CSV）。
2. 展示映射表给用户确认。
3. 确认后逐项重命名：
   - 目标已存在 → 跳过并报告（不覆盖）。
   - 源不存在 → 跳过并报告。
4. 重命名后校验：无丢失、无冲突、符合正则。

## 校验正则

- 全部文件应匹配 `re.search(命名正则, basename)`。
- 不匹配的列出来，逐个处理。

## 禁止事项

- 不直接对原文件批量改名而无映射表（无法回退）。
- 不覆盖已存在目标。
- 重命名与旋转/转换分开做，避免一步坏全批。
