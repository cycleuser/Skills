# OCR 旋转检测与校正 (Orientation via OCR)

扫描件/照片方向判断的核心技巧。

## 原理

正常横向文字的文字框：宽≥高。旋转 90° 后，横向文字在图像里变成竖排，OCR 检出的框变成**高>宽**（宽仅数像素、高几百上千像素）。因此统计文字框的"竖排比例"即可判断是否需要旋转。

## 判定算法

```
vertical = 计数(h > 1.5 * w) / 样本数
if vertical > 0.6:  需旋转 90°
```

## CW / CCW 判定（关键）

对同一串竖排文字（比如"在……大赛中荣获"）：

- 竖列中文字按从上到下排列，首字符 y 小、尾字符 y 大。
- **顺时针旋转 90°**（PIL `rotate(-90, expand=True)`）后：
  竖列变为横排，且首字符在**左**、文字左→右读 → 正确方向。
- 逆时针旋转 90° 后首字符在右、文字右→左读 → 错误（镜像倒读）。

所以统一策略：竖排比例高时用 `rotate(-90, expand=True)`，OCR 复核横向可读即可。

## 180° 颠倒

- 现象：OCR 完全读不出、或读出的字是倒的。
- 处理：`rotate(180)` 后重试 OCR；能读出正常横向文字即为正确。

## 特殊情况

- 证书本身设计为竖排文字（传统中式证书）：竖排比例高但**不需要旋转**。
  判断依据：整页文字都是竖排且阅读方向自洽 → 保持原样；仅部分竖排（题词竖排、正文横排）→ 正常。
- 无文字图片（照片/纯图）：OCR 无结果，无法自动判断，报告人工确认。
