# AI写作禁忌模式

本文档列出必须避免的"一眼AI"写作模式，确保创作符合用户真实风格。

---

## 一、格式禁忌

### 1. 禁止"粗体标签"格式

**绝对禁止：**
```
**优点**: 这种方法有以下优势：
**缺点**: 主要问题在于：
**特点**: 具有以下特征：
**步骤**: 具体操作如下：
```

**为什么禁止：**
这是最典型的AI写作模式，一眼就能看出是AI生成。用户从不使用这种格式。

**正确做法：**
直接用自然语言表达，不需要粗体标签。

**示例对照：**

❌ 错误：
```
**优点**: 简写技能具有以下优势：
- **简洁性**: 避免冗长表达
- **口语化**: 使用自然语言
- **真诚**: 坦率直言
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。

咱们写东西，有时候容易绕弯子，堆一堆大词，显得挺专业。可实际上呢？读者看着费劲，自己也写得累。

这技能的核心就是直接、口语化、真诚。
```

### 2. 禁止过度列表堆砌

**避免：**
连续使用大量无序列表，每个列表项都很短。

**示例对照：**

❌ 错误：
```
本文的主要内容包括：
- 概念介绍
- 技术原理
- 实现方法
- 应用场景
- 注意事项
- 总结展望
```

✓ 正确：
```
咱们来看看这东西咋回事，然后说说具体怎么干，最后聊聊要注意啥。
```

### 3. 禁止机械总分总结构

**避免：**
开头"本文将...", 中间"首先...其次...最后...", 结尾"综上所述..."

**示例对照：**

❌ 错误：
```
本文将全面介绍简写技能的核心概念和实际应用。

首先，我们来看什么是简写技能。
其次，我们讨论简写技能的优势。
再次，我们分析如何应用简写技能。
最后，我们总结简写技能的意义。

综上所述，简写技能是一种重要的写作方法。
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。

咱们来看看这东西咋回事。
...
这技能的核心就是直接、口语化、真诚。
```

### 4. 禁止过度分隔线

**避免：**
频繁使用分隔线 `---` 或 `***` 分割段落。

**示例对照：**

❌ 错误：
```
第一部分
---
内容1

---

第二部分
---
内容2

---

第三部分
---
内容3
```

✓ 正确：
```
咱们来看看这东西咋回事。

内容1

说完了这个，再聊聊下一个。

内容2

最后说说要注意啥。

内容3
```

## 二、词汇禁忌

### 1. 禁止学术腔调词汇

**禁止词汇：**
- "笔者认为"
- "综上所述"
- "由此可见"
- "不难发现"
- "众所周知"
- "值得指出"
- "有必要强调"
- "需要说明"
- "显而易见"
- "毋庸置疑"

**示例对照：**

❌ 错误：
```
笔者认为，简写技能具有重要的实践意义。
综上所述，这种方法具有显著优势。
由此可见，用户写作风格独特。
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。
这技能好歹能用。
用户写东西有自己的路子。
```

### 2. 禁止华丽形容词

**禁止词汇：**
- "卓越的"
- "杰出的"
- "卓越的"
- "宏大的"
- "深邃的"
- "精妙的"
- "完美的"
- "极致的"
- "无与伦比的"
- "令人叹为观止的"

**示例对照：**

❌ 错误：
```
这是一种卓越的写作方法。
这展现了深邃的思想。
这是一个完美的解决方案。
```

✓ 正确：
```
这东西好歹能用。
这想法挺实在。
这办法还行。
```

### 3. 禁止抽象大词

**禁止词汇：**
- "意义"（作为名词）
- "价值"（作为抽象概念）
- "本质"
- "精神"（作为抽象概念）
- "理念"
- "内涵"
- "外延"
- "机制"
- "体系"
- "范式"

**示例对照：**

❌ 错误：
```
简写技能具有重要的理论意义和实践价值。
这体现了深刻的写作理念。
这揭示了事物的本质。
```

✓ 正确：
```
简写这东西有用。
这方法挺实在。
这东西就是这么回事。
```

### 4. 禁止动词堆砌

**避免：**
连续使用"探讨"、"分析"、"研究"、"阐述"、"剖析"等动词。

**示例对照：**

❌ 错误：
```
本文将探讨简写技能的理论基础，分析其应用场景，研究其实现方法，阐述其核心特征，剖析其优势劣势。
```

✓ 正确：
```
咱们来看看简写这东西咋回事，说说怎么用，聊聊要注意啥。
```

## 三、句式禁忌

### 1. 禁止复杂从句

**避免：**
多层嵌套的长句，超过20字。

**示例对照：**

❌ 错误：
```
作为一种在写作过程中逐渐形成的、经过长期实践检验的、具有显著优势和独特特征的写作风格，简写技能体现了作者对语言表达的深刻理解和独到见解。
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。
这技能是长期实践出来的。
作者对语言有自己的理解。
```

### 2. 禁止被动句

**避免：**
"被...所..."、"为...所..."结构。

**示例对照：**

❌ 错误：
```
这种方法被广泛应用于各类场景。
此概念为学术界所重视。
```

✓ 正确：
```
这方法在好多地方都能用。
学术界挺看重这东西。
```

### 3. 禁止定语前置

**避免：**
"作为...的..."结构。

**示例对照：**

❌ 错误：
```
作为一种重要的写作方法，简写技能具有广泛应用。
作为核心概念，这东西很重要。
```

✓ 正确：
```
简写这东西挺重要的，好歹能用。
这概念挺关键。
```

### 4. 禁止机械连接词

**避免：**
"首先...其次...再次...最后..."、"一方面...另一方面..."、"不仅...而且..."

**示例对照：**

❌ 错误：
```
首先，我们来看概念。
其次，我们分析原理。
再次，我们讨论应用。
最后，我们总结意义。
```

✓ 正确：
```
咱们先看看这东西是什么。
再说说怎么回事。
然后聊聊怎么用。
最后提一句要注意啥。
```

## 四、结构禁忌

### 1. 禁止开篇总述

**避免：**
开头就列出"本文将介绍X个部分"。

**示例对照：**

❌ 错误：
```
本文将从以下三个方面介绍简写技能：
1. 基本概念
2. 应用方法
3. 注意事项
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。

咱们来看看这东西咋回事...
```

### 2. 禁止结尾总结段落

**避免：**
专门的"总结"、"综上所述"段落。

**示例对照：**

❌ 错误：
```
综上所述，简写技能具有以下特点：
1. 直接简洁
2. 口语化
3. 真诚坦率

这些特点使其成为一种重要的写作方法。
```

✓ 正确：
```
这技能的核心就是直接、口语化、真诚。

就像咱平时跟朋友聊天一样，该咋说就咋说，不用装腔作势。
```

### 3. 禁止分段过细

**避免：**
每个小观点都单独分段。

**示例对照：**

❌ 错误：
```
简写技能具有直接的特点。

它还具有口语化的特点。

另外，它还有真诚的特点。
```

✓ 正确：
```
这技能的核心就是直接、口语化、真诚。就像咱平时跟朋友聊天一样，该咋说就咋说，不用装腔作势。
```

### 4. 禁止标题堆砌

**避免：**
过多的小标题，每个标题下内容很少。

**示例对照：**

❌ 错误：
```
## 一、概念定义
内容

## 二、核心特征
内容

## 三、应用场景
内容

## 四、注意事项
内容

## 五、总结展望
内容
```

✓ 正确：
```
咱们来看看这东西咋回事。

内容1

说完了这个，再聊聊怎么用。

内容2
```

## 五、语气禁忌

### 1. 禁止居高临下语气

**避免：**
"应该"、"必须"、"务必"、"切记"等命令式语气。

**示例对照：**

❌ 错误：
```
读者应该理解简写技能的重要性。
你必须掌握这种方法。
务必注意这些要点。
```

✓ 正确：
```
简写这东西挺重要的，好歹能帮咱把话说清楚。
这方法得整明白。
这些事儿得留点心。
```

### 2. 禁止说教语气

**避免：**
"我们要..."、"希望大家..."、"读者需要..."

**示例对照：**

❌ 错误：
```
我们要深刻理解简写技能的意义。
希望大家认真学习这种方法。
读者需要掌握核心要点。
```

✓ 正确：
```
简写这东西得整明白。
这方法得好好看看。
核心的东西得抓住。
```

### 3. 禁止空洞鼓励

**避免：**
"相信大家..."、"相信读者..."

**示例对照：**

❌ 错误：
```
相信大家通过本文的学习，能够掌握简写技能。
相信读者能够理解这种方法的价值。
```

✓ 正确：
```
看看这东西，好歹能明白咋回事。
了解了这方法，能用上就行。
```

## 六、内容禁忌

### 1. 禁止无实质内容的废话

**避免：**
开头的"本文将..."、结尾的"综上所述..."、中间的过渡废话。

**示例对照：**

❌ 错误：
```
本文将介绍简写技能。

简写技能是一种重要的写作方法。

综上所述，简写技能具有重要意义。
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚。

咱们来看看这东西咋回事。

这技能的核心就是直接、口语化、真诚。
```

### 2. 禁止重复表达

**避免：**
同一观点在不同段落重复表达。

**示例对照：**

❌ 错误：
```
简写技能具有简洁的特点。

这种简洁的特点使其能够高效表达。

通过简洁的表达，读者能够快速理解。
```

✓ 正确：
```
简写这东西，说白了就是怎么把话说清楚，一句话能说完的不用两句。
```

### 3. 禁止空洞案例

**避免：**
"例如..."后面没有具体案例。

**示例对照：**

❌ 错误：
```
简写技能有很多应用场景，例如在工作中、在学习中等。
```

✓ 正确：
```
简写这东西在哪都能用，比如写博客、写文档、写教程。
```

## 七、检测方法

### 1. AI特征检测清单

创作完成后，用以下清单检测：

**格式检测：**
- [ ] 是否有"**粗体标签**"格式？（有则必改）
- [ ] 是否有大量列表堆砌？（有则减半）
- [ ] 是否有过度分隔线？（有则删除）
- [ ] 是否有机械总分总结构？（有则打散）

**词汇检测：**
- [ ] 是否有学术腔调词汇？（有则口语化）
- [ ] 是否有华丽形容词？（有则简化）
- [ ] 是否有抽象大词？（有则具体化）
- [ ] 是否有动词堆砌？（有则打散）

**句式检测：**
- [ ] 是否有复杂从句？（有则拆分）
- [ ] 是否有被动句？（有则改主动）
- [ ] 是否有定语前置？（有则调整）
- [ ] 是否有机械连接词？（有则自然化）

**结构检测：**
- [ ] 是否有开篇总述？（有则删除）
- [ ] 是否有结尾总结段？（有则删除）
- [ ] 是否有分段过细？（有则合并）
- [ ] 是否有标题堆砌？（有则减少）

**语气检测：**
- [ ] 是否有居高临下语气？（有则平视）
- [ ] 是否有说教语气？（有则去除）
- [ ] 是否有空洞鼓励？（有则删除）

**内容检测：**
- [ ] 是否有无实质废话？（有则删除）
- [ ] 是否有重复表达？（有则删除）
- [ ] 是否有空洞案例？（有则具体化）

### 2. AI指数评估

根据以上检测，计算AI指数：

**AI指数 = (禁忌项数量 / 总检测项) × 100**

**评分标准：**
- 0-10%：神似，完全符合用户风格
- 11-30%：形似，基本符合但有少量AI痕迹
- 31-50%：勉强，有较多AI痕迹需改进
- 51-70%：不符，大量AI痕迹需重写
- 71-100%：背离，完全AI风格需废弃

## 八、典型案例对照

### 案例1：技术文章开头

❌ AI风格：
```
本文将全面介绍优化器的核心原理、技术实现和应用场景。

优化器是大语言模型训练中的关键组件。**特点**: 它具有以下显著特征：
- **自适应性**: 能够根据梯度调整步长
- **高效性**: 收敛速度显著提升
- **稳定性**: 训练过程更加平稳

综上所述，优化器在LLM训练中具有重要地位。
```

✓ 用户风格：
```
大语言模型似乎很厉害，外行人如果不了解大模型，就可能会觉得这东西很神秘，很了不得，甚至担心什么天人降临统治人类等等。

虽然他可能会告诉你要走路去五十米外的地方洗车，而把车停在原地。

人往往会因为缺乏足够的认知而产生恐惧，实际上稍微从基础层面做一点了解就会发现，这东西并没有那么复杂。
```

### 案例2：个人故事开头

❌ AI风格：
```
本文将分享作者的个人经历和成长感悟。

作者在成长过程中遇到了诸多挑战。**挑战**: 主要包括：
- **语言障碍**: 英语水平较差
- **资源匮乏**: 缺乏学习资料
- **环境限制**: 网络条件不足

通过坚持不懈的努力，作者最终克服了这些困难。
```

✓ 用户风格：
```
我曾经翻译过一些东西。虽然我的翻译水平很差，技术水平也很差，但一直还都保持着这个习惯。偶尔总是陆陆续续地翻译一些自己觉得很喜欢的学习资料。
```

### 案例3：教程文章开头

❌ AI风格：
```
本文将指导读者搭建本地AI编程环境。

搭建过程分为以下步骤：
1. 安装Ollama
2. 安装OpenCode
3. 配置连接
4. 验证运行

相信读者通过本文的学习，能够顺利完成搭建。
```

✓ 用户风格：
```
在注重代码隐私与离线开发的场景中，OpenCode（终端AI编程助手）与Ollama（本地大模型引擎）的组合提供安全、高效、完全自主的智能编程解决方案。
```

## 九、创作原则总结

### 1. 核心原则

**一句话：** "就像咱平时跟朋友聊天一样，该咋说就咋说。"

### 2. 具体原则

**格式原则：** 不用粗体标签，不用列表堆砌，不用分隔线泛滥。

**词汇原则：** 不用学术腔，不用华丽词，不用抽象词，不用动词堆。

**句式原则：** 不用复杂句，不用被动句，不用定语前置，不用机械连接。

**结构原则：** 不用开篇总述，不用结尾总结，不用分段过细，不用标题堆砌。

**语气原则：** 不用居高临下，不用说教，不用空洞鼓励。

**内容原则：** 不用废话，不用重复，不用空洞案例。

### 3. 创作心法

**心法一：** 假设读者是朋友，不是学生。

**心法二：** 假设自己是聊天，不是讲课。

**心法三：** 假设场景是日常，不是会议。

**心法四：** 假设表达是口语，不是书面。

**心法五：** 假设目标是实用，不是理论。
