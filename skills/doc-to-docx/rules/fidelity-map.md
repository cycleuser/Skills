# 保真度地图 / Fidelity Map

诚实列出转换器“能还原什么、尽力还原什么、暂不还原什么”，
让用户对 `原样` 的边界有准确预期。

## Tier 1 — 高保真（默认完整还原）

| 内容 | 说明 |
|------|------|
| 全部正文文本 | 含中文/西文混合，多分片、压缩/未压缩分片都正确处理 |
| 字符格式 | 粗体、斜体、下划线、删除线、双删除线、小型大写、全大写、隐藏、
  字体（ASCII/远东/其他三轨）、字号、颜色、高亮、上下标、字符缩放、字距、
  字偶距 |
| 段落格式 | 对齐（左/中/右/两端/分散）、左右缩进、首行缩进（含悬挂）、段前段后、
  行距（固定值/最小值/多倍）、与下段同页、段中不分页、段前分页、
  孤行控制、大纲级别、制表位 |
| 页面设置 | 页宽/页高、四边距、装订线、页眉页脚距离、横/竖版、起始页码、分栏数 |
| 样式默认 | Normal（正文）样式默认字体/字号写入 docx 样式；标题 1/2 等样式
  的字体/字号/颜色经样式链解析后应用到段落 |
| 表格 | 单元格文本、行/列结构、列宽（TDefTable）、单线边框（TTableBorders） |
| 域代码 | PAGE / NUMPAGES 等保留为 OOXML `fldChar` 域（Word 打开后自动更新） |
| 特殊字符 | 制表符→`w:tab`、软回车→`w:br`、手动分页→`w:br type=page`、
  不间断空格、不间断连字符 |

实测（自建样本 + 3 个真实教务 .doc）：正文字符逐字符 100% 保留，
字体表、分节、表格结构完整。

## Tier 2 — 尽力而为

| 内容 | 说明 |
|------|------|
| 表格合并 | 行内少于网格列数时，最后一个单元格以 `gridSpan` 吞并剩余列；
  复杂的不规则合并（跨行列网格）位置可能与原文件不完全一致 |
| 表格底纹/边框细分 | 只还原整体单线边框；逐格自定义边框/底纹暂不细分 |
| 编号/项目符号 | 多级列表（LFO/LSTF + PNumRM）暂不还原为 Word 自动编号 |
| 样式名映射 | 自定义样式名保留在 docx 中，但段落以“解析后的完整格式”直接写入，
  不依赖 docx 命名样式链 |

## Tier 3 — 暂不还原（输出时跳过）

| 内容 | 说明 |
|------|------|
| 页眉/页脚 | WPS 文件的 PlcfHdd 结构不标准，无法可靠定位页眉文本；
  输出不写页眉页脚（页面距离仍保留） |
| 图片/绘图对象 | 内嵌图片（PICF/OfficeArt）不提取；`\x01`/`\x08` 占位符跳过 |
| 脚注/尾注 | 正文内脚注引用保留为普通字符，脚注内容不生成 |
| 文本框/批注/修订 | 跳过 |
| 宏/VBA | 不保留 |
| 加密文档 | fEncrypted=1 时拒绝转换并报错 |

## 如何自测保真度

```bash
# 结构信息
python scripts/doc2docx.py inspect in.doc
# 转换
python scripts/doc2docx.py convert in.doc -o out.docx
# 逐字符比对（输出文本 vs 原文件）
python scripts/doc2docx.py check out.docx --against in.doc
```

`check` 会给出正文+表格字符总数与原文件的比值，接近 1.000 即文本完整。
字体、字号、粗斜体、对齐、页面设置请在 Word/WPS 里目检，或解包对照
`word/document.xml`。
