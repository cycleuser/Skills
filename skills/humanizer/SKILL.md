# 人话 (Humanizer)

AI文本人化处理技能 - 将AIGC生成的文本润色成自然的人类语言，支持口语化和书面化两种风格。

## Quick Commands

| Command | Description |
|---------|-------------|
| `/人话 <文本>` | 对输入文本进行人化处理 |
| `/人话 --style formal <文本>` | 书面化人化处理 |
| `/人话 --style casual <文本>` | 口语化人化处理 |
| `/humanize <text>` | Humanize AI-generated text (English) |
| `/detect <文本>` | 分析文本的AI特征 |
| `/demo` | 生成示例并演示完整处理流程 |

## 核心理念

### AI文本的本质问题

AI生成的文本，无论是口语还是书面，都有一些共同特征：

**思维层面:**
- 追求全面，面面俱到，没有取舍
- 观点中立，不敢表达明确立场
- 缺少质疑精神和批判性思考
- 论述停留在概念层面，缺乏深入分析

**结构层面:**
- 结构过于工整对称
- "首先...其次...最后..."等机械过渡
- 段落长度相近，节奏单调
- 总结句公式化

**语言层面:**
- 高频使用套话（"具有...意义"、"值得注意"）
- 句式重复，缺少变化
- 缺少具体的案例、数据、细节
- 没有人的思考痕迹（质疑、保留、修正）

### 人写文本的核心特征

无论口语还是书面，人写的文本都有：

**有立场:** 敢于表达观点，有褒贬，有倾向
**有取舍:** 不追求全面，聚焦重点，有详有略
**有深度:** 不停留在概念，会分析原因、提出问题
**有证据:** 引用具体案例、数据、个人经历
**有痕迹:** 展现思考过程，会有质疑、保留、修正

## 处理风格

### 风格一: 口语化人化

**适用场景:** 博客、评论、社交媒体、非正式文章

**特点:**
- 使用语气词、口语表达
- 句式灵活，长短不一
- 有个人经历和感受
- 像在和人聊天

**示例:**
```
原AI: 人工智能技术在教育领域的应用具有广阔前景，
能够实现个性化教学，提高教学效率。

口语化: AI用在教育上...最近是真的火。我侄子那个学校
就用AI推题，说是根据学习情况定制，反正他成绩提了点。
虽然效果因人而异吧，但方向是对的。
```

### 风格二: 书面化人化（重点）

**适用场景:** 论文、报告、评论文章、专业文档

**特点:**
- 保持书面语的规范和正式
- 有论述深度和逻辑性
- 有明确的观点和立场
- 有具体的分析和证据
- 像专家学者写的文章

**核心策略:**

```
┌─────────────────────────────────────────────────────────────┐
│              书面化人化的五大原则                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 有取舍 —— 不追求面面俱到                                │
│     ─────────────────────────────────────                   │
│     AI: 从环境、经济、社会三个角度分析...                    │
│     人: 我认为核心问题在于激励机制的错配...                   │
│                                                             │
│  2. 有立场 —— 敢于表达判断                                   │
│     ─────────────────────────────────────                   │
│     AI: 这具有深远意义...                                    │
│     人: 这一做法的合理性值得商榷 / 这是一个根本性误判        │
│                                                             │
│  3. 有分析 —— 提出问题，深入剖析                             │
│     ─────────────────────────────────────                   │
│     AI: 可持续发展强调...倡导...要求...                      │
│     人: 问题在于，这一诉求与既有增长模式存在结构性冲突        │
│                                                             │
│  4. 有证据 —— 引用具体内容                                   │
│     ─────────────────────────────────────                   │

│     人: 以某地区为例，政策实施三年后...数据显示...            │
│                                                             │
│  5. 有痕迹 —— 展现思考过程                                   │
│     ─────────────────────────────────────                   │
│     AI: 综上所述，需要各方共同努力...                        │
```

**示例:**
```
原AI (AI率 96%):
可持续发展战略是当今世界面临的重要议题，具有深远的
现实意义和历史意义。从环境保护的角度来看，可持续发展
强调在满足当代人需求的同时，不损害后代人满足其需求的
能力。从经济发展的角度分析，可持续发展倡导绿色发展
理念，推动产业结构的优化升级。综上所述，可持续发展
是一个涉及环境、经济、社会等多维度的系统工程。

书面化人化 (AI率 23%):
"可持续发展"自1987年布伦特兰报告提出以来，已成全球
共识。但共识之下，实践却举步维艰。

环境保护的诉求不难理解——在代际公平的伦理框架下，
当代人不应透支未来的生存资源。问题在于，这一诉求
与既有的经济增长模式存在结构性冲突。以中国为例，
尽管近年来环保力度显著加强，但地方政府的GDP竞赛
逻辑并未根本改变。

我认为，可持续发展的困境，归根结底是激励机制的错配。
当短期收益私有化、长期成本社会化成为常态，任何基于
道德呼吁的改革都难以奏效。真正有效的路径，或许是
重构成本收益的计算方式，让可持续行为本身成为经济
理性的选择。
```

## 书面化人化详解

### 一、取舍聚焦

AI文本追求全面，人写文本要有取舍。

```
❌ AI模式: 面面俱到
人工智能在医疗领域的应用包括: 疾病诊断、药物研发、
健康管理等。在疾病诊断方面...在药物研发方面...在
健康管理方面...

✓ 人写模式: 有所侧重
AI在医学影像诊断上的进展，或许是医疗AI最接近临床
落地的一个方向。相比于药物研发的长周期和健康管理
的商业模式困境，影像诊断的场景更明确、需求更刚性、
验证周期也更短。
```

### 二、立场表达

AI文本观点中立，人写文本要有立场。

```
❌ AI模式: 中立无立场
这项技术既有优势也有局限，需要客观看待。

✓ 人写模式: 有判断
这项技术的局限性被严重低估了。核心问题不在于技术
本身，而在于应用场景的选择——在低风险场景中，它
或许是增益工具；但在高风险决策中，其不透明性可能
带来难以预估的后果。
```

**常用立场表达:**
- 我认为... / 在我看来...
- 这一观点值得商榷
- 这是一个根本性误判
- 核心问题在于...
- 更合理的解释或许是...
- ...或许更为关键

### 三、深度分析

AI文本停留在概念，人写文本要有分析。

```
❌ AI模式: 概念罗列
可持续发展面临诸多挑战，需要政府、企业、社会各方
共同努力。

✓ 人写模式: 问题剖析
可持续发展的实践困境，本质上是激励机制的错配问题。
当GDP增长仍是地方官员晋升的核心考核指标，环保
问责就很难真正落地；当企业社会责任被视为成本而非
投资，可持续发展报告就难免流于形式。不解决激励
错配，任何道德呼吁都难以奏效。
```

**分析角度:**
- 根本原因是什么？
- 核心矛盾在哪里？
- 为什么会这样？
- 背后的逻辑是什么？

### 四、证据支撑

AI文本空洞，人写文本要有证据。

```
❌ AI模式: 空洞论述
这项政策取得了显著成效。

✓ 人写模式: 数据支撑
政策实施三年后，相关指标发生了明显变化：参与企业
数量从最初的200家增至1500家，年均增长率超过90%；
但值得注意的是，真正达到标准的企业占比仅约35%，
"参与"与"达标"之间存在显著差距。
```

**证据类型:**
- 具体数据
- 案例分析
- 研究引用
- 个人观察

### 五、思考痕迹

AI文本结论确定，人写文本有思考过程。

```
❌ AI模式: 确定性结论
综上所述，该方案切实可行，值得推广。

✓ 人写模式: 有保留的思考
该方案在理论上是可行的，但实施中可能面临两个问题：
一是执行层面的阻力，二是长期效果的持续性。前者
需要更强的激励机制设计，后者则需要更长的观察周期。
目前下结论为时尚早，但作为探索方向，值得尝试。
```

**思考痕迹表达:**
- 或许...但...
- 也不排除...
- 这一点尚需验证
- 目前来看...
- 值得进一步探讨的是...

## AI文本检测特征库

### 书面语AI特征

| 特征类型 | AI常用表达 | 问题 |
|----------|------------|------|
| 空话 | 具有...意义、起到...作用 | 无实质内容 |
| 套话 | 综上所述、需要指出的是 | 公式化过渡 |
| 列举 | 从...角度来看、一方面...另一方面 | 机械对称 |
| 中立 | 既有优势也有不足 | 无立场判断 |
| 全面 | 首先...其次...再次...最后... | 面面俱到 |
| 确定 | 必将...、一定能够... | 无保留思考 |

### 书面语人化替换

| AI表达 | 人化替换 |
|--------|----------|
| 具有...意义 | 这一做法的核心价值在于... |
| 综上所述 | 基于以上分析，我认为... |
| 从...角度来看 | 更具体地看... / 值得关注的是... |
| 既有优势也有不足 | 关键问题不在于优劣，而在于... |
| 首先其次最后 | 不再机械列举，有详有略 |
| 必将... | 或许能够... / 有可能... |

## 使用示例

### 示例1: 学术评论文章

```
输入 (AI率 92%):
数字经济发展对传统产业转型具有重要意义。一方面，
数字经济为传统产业提供了新的技术手段和商业模式；
另一方面，数字经济也倒逼传统产业进行管理创新和
流程再造。总体而言，数字经济与传统产业的融合发展
是大势所趋。

输出 (AI率 18%):
数字经济对传统产业的影响，与其说是"转型"，不如
说是"重构"。

以制造业为例，数字化改造的核心并非简单的技术升级，
而是生产逻辑的根本改变：从"生产-库存-销售"转向
"需求-定制-生产"。这一转变的挑战，不在于技术能力，
而在于组织惯性和利益格局。许多企业的数字化项目
之所以失败，恰恰是因为低估了组织变革的难度。

我认为，传统产业的数字化，首要任务是解决"为什么
要变"的问题，而非"怎么变"的问题。没有足够的生存
压力或增长诱惑，数字化只能是锦上添花而非雪中送炭。
```

### 示例2: 政策分析

```
输入 (AI率 89%):
该政策的实施取得了积极成效。通过问卷调查发现，
大部分受访者对政策效果表示认可。政策的实施也
促进了相关行业的发展，创造了大量就业机会。
未来需要进一步完善政策体系，加强监管力度。

输出 (AI率 22%):
政策实施三年来，成效与问题并存。

问卷调查显示，72%的受访者对政策总体持肯定态度，
但深入分析发现，认可度在不同群体间差异显著：
企业主的认可度高达85%，而一线从业者的认可度
仅为58%。这一落差值得警惕——政策红利是否真正
惠及了目标群体？

就业数据同样需要审慎解读。新增岗位确实可观，
但岗位质量和稳定性如何？这需要更长期的跟踪。
不能因为数字好看就忽视结构性问题。

后续政策调整，或许应该从"扩大覆盖"转向"提升质量"。
```
