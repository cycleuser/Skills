## 概述

本规则定义了如何识别AI生成文本的典型特征，用于指导人化处理策略的选择。支持口语化和书面化两种文本类型的检测。

## 一、结构特征检测

### 1.1 段落结构

#### 检测指标

```
段落均匀度:
- 计算各段落长度方差
- 方差小 → AI特征高
- 正常人类写作方差较大

段落结构模式:
- 检测是否每段都有主题句
- 检测段落间是否对称工整
- 检测是否有固定开头模式
```

#### AI典型模式

```
模式1: 总分总结构
┌─────────────────────────────────────┐
│ 总起段: ...有以下几个方面           │
│ 分述段1: (长度200字)                │
│ 分述段2: (长度200字)                │
│ 分述段3: (长度200字)                │
│ 总结段: 综上所述...                 │
└─────────────────────────────────────┘

模式2: 对称并列
┌─────────────────────────────────────┐
│ 第一段: 从A角度来看... (150字)      │
│ 第二段: 从B角度来看... (150字)      │
│ 第三段: 从C角度来看... (150字)      │
└─────────────────────────────────────┘
```

#### 人写结构特征

```
- 段落长度差异明显
- 有重点段落和过渡段落
- 结构服务于内容，而非对称
- 可能有跳跃、补充、纠正
```

### 1.2 列表模式

#### 检测指标

```
列表使用频率:
- 列表占段落比例 > 30% → AI特征高

列表项特征:
- 每项长度相近 → AI特征高
- 每项句式相似 → AI特征高
- 完整无遗漏 → AI特征高
```

#### AI典型模式

```
模式1: 机械列举
具有以下特点：
1. 特点一：...（30字）
2. 特点二：...（30字）
3. 特点三：...（30字）

模式2: 分点论述
首先，...（50字）
其次，...（50字）
再次，...（50字）
最后，...（50字）
```

### 1.3 过渡模式

#### AI典型过渡词

```
中文:
- 首先、其次、再次、最后
- 一方面、另一方面
- 综上所述、总而言之
- 从...角度来看
- 值得注意的是、需要指出的是
- 由此可见

英文:
- Firstly, Secondly, Thirdly
- On the one hand, On the other hand
- In conclusion, To summarize
- It is worth noting that
- As can be seen
```

#### 过渡模式检测

```
检测方法:
1. 统计过渡词出现频率
2. 检测过渡词是否呈规律分布
3. 判断过渡是否过于正式/工整

AI特征:
- 过渡词频率 > 5次/千字
- 过渡词分布规律（每隔N段出现）
- 过渡句格式相似
```

## 二、语言特征检测

### 2.1 AI高频词汇

#### 中文AI高频词表

| 类别 | 词汇 | 权重 |
|------|------|------|
| 空话 | 具有...意义、起到...作用、产生...影响 | 高 |
| 套话 | 综上所述、需要指出的是、值得注意 | 高 |
| 连接 | 首先、其次、再次、最后、此外 | 高 |
| 模糊 | 一般来说、通常情况下、某种程度上 | 中 |
| 程度 | 显著、极大、相当、一定程度上 | 中 |
| 陈述 | 这表明、这说明、这意味着 | 中 |

#### 英文AI高频词表

| Category | Words | Weight |
|----------|-------|--------|
| Vague | It is worth noting, It should be noted | High |
| Connectors | Firstly, Secondly, Moreover, Furthermore | High |
| Summary | In conclusion, To summarize, Overall | High |
| Generic | significantly, substantially, considerable | Medium |

#### 检测方法

```
1. 分词后匹配AI词表
2. 计算AI词汇占比
3. 阈值判断:
   - AI词汇占比 > 8% → 高AI特征
   - AI词汇占比 4-8% → 中等AI特征
   - AI词汇占比 < 4% → 低AI特征
```

### 2.2 句式模式

#### AI典型句式

```
中文:
- "在...方面，...起到了重要作用"
- "从...的角度来看"
- "...是...的关键因素"
- "这对...产生了深远影响"
- "...具有...的特征"
- "需要...的同时，也要..."

英文:
- "It is important to note that..."
- "In terms of..., ..."
- "This demonstrates that..."
- "It is clear that..."
- "There is no doubt that..."
```

#### 句式检测

```
检测方法:
1. 提取句式模板
2. 计算句式重复度
3. 判断句式多样性

指标:
- 句式重复度 > 40% → 高AI特征
- 句式重复度 20-40% → 中等
- 句式重复度 < 20% → 低AI特征
```

### 2.3 句长分布

#### 检测方法

```
1. 统计所有句子长度
2. 计算句子长度方差
3. 分析句长分布图

AI特征:
- 方差小（句子长度接近）
- 分布集中，呈正态分布
- 缺少极短句和极长句

人写特征:
- 方差大（长短句穿插）
- 分布分散
- 有明显的短句和长句
```

### 2.4 表达空洞度

#### 空洞表达检测

```
空洞表达类型:
1. 无实质内容
   - "具有重要意义"
   - "产生深远影响"
   - "发挥着重要作用"

2. 模糊表达
   - "有一定的作用"
   - "某种程度上"
   - "在...方面"

3. 循环表达
   - "因为重要所以重要"
   - "由于A导致了A"

检测方法:
- 计算空洞表达占比
- 检测是否有具体数据、案例
- 判断信息密度
```

## 三、内容特征检测

### 3.1 观点立场

#### 检测指标

```
立场词汇检测:
- "我认为"、"在我看来"、"我觉得" → 有人立场
- "或许"、"可能"、"也许" → 有保留态度
- "这是一个误判"、"问题在于" → 有批判性

立场强度:
- 完全中立 → AI特征高
- 有明确立场 → 人写特征
- 有保留判断 → 思考痕迹
```

#### AI典型表现

```
特征1: 伪中立
"这一做法既有优势也有不足，需要辩证看待。"
→ 看似全面，实则无观点

特征2: 回避判断
"这是一个值得探讨的问题。"
→ 没有任何实质性观点

特征3: 道德正确
"需要各方共同努力..."
→ 正确但空洞
```

### 3.2 分析深度

#### 检测维度

```
深度层次:
1. 表层: 只描述是什么
2. 浅层: 简单归因
3. 中层: 多因素分析
4. 深层: 追问为什么、挖掘本质

AI特征:
- 停留在概念层面
- 缺少因果分析
- 没有"为什么"的追问
- 没有"本质是"的判断
```

#### 深度检测方法

```
1. 检测分析词汇:
   - "根本原因"、"核心问题"、"本质是" → 深度分析
   - "问题在于"、"关键在于" → 有分析

2. 检测分析层次:
   - 是否只罗列现象
   - 是否有原因分析
   - 是否有本质判断

3. 检测问题意识:
   - 是否提出问题
   - 是否有质疑
   - 是否有批判
```

### 3.3 证据支撑

#### 证据类型

```
具体证据:
- 具体数字（不是"大幅增长"）
- 具体案例（有细节）
- 具体引用（有来源）

模糊表达:
- "取得了显著成效"
- "具有重要作用"
- "存在一些问题"
```

#### 检测方法

```
1. 数据检测:
   - 是否有具体数字
   - 数字是否有单位
   - 是否有对比数据

2. 案例检测:
   - 是否有具体案例
   - 案例是否有细节
   - 案例是否支撑论点

3. 引用检测:
   - 是否有引用来源
   - 引用是否具体

评分:
- 有具体证据 → 人写特征
- 只有模糊表达 → AI特征
```

### 3.4 思考痕迹

#### 检测指标

```
思考痕迹词汇:
- 推理过程: "为什么这样说"、"逻辑是这样的"
- 不确定性: "目前还难以判断"、"存在争议"
- 保留意见: "或许...但..."、"不排除"
- 自我质疑: "这可能导致"、"潜在问题"
- 待解决问题: "还有几个问题"

AI特征:
- 结论直接给出
- 无推理过程
- 无不确定性表达
- 无自我质疑
```

## 四、综合评分

### 评分公式

```
综合AI率 = Σ(维度得分 × 权重)

维度权重:
- 结构特征: 30%
- 语言特征: 40%
- 内容特征: 30%

单项得分: 0-100
- 0-30: 低AI特征（人写特征明显）
- 30-60: 中等AI特征
- 60-100: 高AI特征
```

### 风格适配

```
书面化文本:
- 降低结构特征的权重（人类学术写作也较工整）
- 提高内容特征的权重（关键是分析深度）
- 关注立场表达和思考痕迹

口语化文本:
- 提高语言特征的权重（口语化程度）
- 关注个人经历和情感表达
- 检测语气词使用
```

## 六、检测注意事项

### 1. 上下文敏感

```
不同文体有不同特征基线:
- 学术论文: 结构工整是正常的，重点看分析深度
- 技术文档: 列举是必要的，重点看是否有个人视角
- 新闻报道: 客观是要求，重点看是否有空洞表达
- 评论文章: 要有立场，中立即是AI特征
```

### 2. 语言差异

```
中英文检测差异:
- 中文: 重点关注套话、空话
- 英文: 重点关注It is...句式、被动语态
```

### 3. 领域特征

```
不同领域文本:
- 科研论文: 允许更多规范表达
- 商业文案: 营销语言有自身特点
- 法律文档: 格式化是必要的
- 文学创作: 创意表达难以AI化
```

### 4. 检测局限

```
检测的边界:
- 高质量AI文本可能难以检测
- 规范的人工写作可能被误判
- 需要结合多种方法综合判断
- 检测结果是概率性的，非绝对
```
