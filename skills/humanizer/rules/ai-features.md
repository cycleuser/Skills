# AI 特征检测模型与评分

本文件是检测层的总纲：怎么分维度、怎么加权、报告长什么样。**具体模式不在这里**——中文见 `zh-patterns.md`（Z01–Z29），英文见 `en-patterns.md`（E01–E25），阈值见 `metrics.md`。

---

## 一、五维检测模型

早期版本用"结构/语言/内容"三维。2.0 拆成五维，因为版面痕迹与叙事特征在实测里独立性强、处理手法也不同。

```
┌──────────────────────────────────────────────────────────────┐
│                      五维检测模型                             │
├──────────────┬──────────────┬──────────────┬─────────────────┤
│ 结构 25%      │ 词汇 25%      │ 句式 20%      │ 版面 10%        │
│ 段长方差      │ AI 词密度     │ 三项并列      │ 加粗/列表/表格  │
│ 句长方差      │ 空话/官腔     │ 否定平行      │ emoji/符号      │
│ 信息分布      │ 名词化        │ 连接词开场    │ markdown 残留   │
│              │ 四字格/成语   │ 句式同构      │ 弯引号          │
├──────────────┴──────────────┴──────────────┴─────────────────┤
│                     叙事 20%（只能人读）                       │
│ 说教 / 线性 / 回避取舍 / 无读者意识 / 故事趋同                  │
└──────────────────────────────────────────────────────────────┘
```

叙事维不进入脚本分数，因为无法可靠自动化。但它是最终判断"像不像人"的关键一层：即便前四维全部达标，一段处处正确、句句有结论、没有任何取舍的文字，读者仍会觉得假。

## 二、各维度的主要指标

### 结构

- 段落长度变异系数（CV）：段段等长是最直观的机器痕迹。
- 句长 CV：AI 常集中在 15–25 字（中文）/12–20 词（英文）的窄带。
- 详略分布：AI 倾向于每点等量展开，人会有详有略。
- 总分总骨架：开头预告"以下几个方面"，结尾复述。

### 词汇

- AI 高频词密度（中文官腔词、英文 AI 词表）。
- 空话率：删掉后信息量不变的短语占比。
- 名词化：中文"进行/开展 + 动词"，英文 `-tion/-ment` 比例。
- 四字格/成语密度（中文特有）。
- 词汇多样性：TTR 只作参考，短文本不可靠。

### 句式

- 三项并列、否定平行、对称并列的密度。
- 连接词开场句比例。
- 句式同构：连续三句以上主谓宾同构、长度相近。
- 段首短判断句（中文）、-ing 尾巴（英文）。
- 重复 n-gram 占比（论元复用的代理指标）。

### 版面

- 加粗、项目符号、表格、emoji、markdown 标记密度。
- 破折号、引号、非常规 Unicode。
- 这一维倍数最高（粗体 43×、markdown 12×），也最容易机械清除，所以权重最低——清干净不代表改好了。

### 叙事

- 是否直接点明主题（说教）。
- 是否单线推进、每个问题都有答案。
- 是否回避取舍与道德模糊。
- 是否预设读者的已知信息。
- 与同题材料的相似度（趋同）。

## 三、权重表（2.0）

| 特征 | 权重 | 置信度 | 说明 |
|------|------|--------|------|
| 助手残留（Certainly/Here's/I hope this helps） | 95 | 极高 | 无例外，整段删 |
| 模糊归属（专家认为/业界普遍认为） | 90 | 高 | 内容层最硬 |
| 公式化展望段（Despite these challenges） | 88 | 高 | 结构+内容双特征 |
| 中文空话拔高（具有重要意义） | 88 | 高 | 删后信息不变即坐实 |
| 加粗编号 + 冒号 + 等长句式 | 92 | 高 | 版面+结构复合 |
| 机械三段论 | 85 | 高 | 需与"有序列举"区分 |
| 否定平行 | 80 | 中高 | 单处可能是正常修辞 |
| 三项并列 | 78 | 中 | 看密度不看单次 |
| AI 词表簇 | 85 | 高 | 单词不算，成簇才算 |
| 名词化/参与式从句密度 | 80 | 高 | 英文主力信号，2.1×/5.3× |
| 句式同构（≥3 句） | 75 | 中 | 需排除有意排比 |
| 段首短判断句 | 82 | 中高 | 中文典型段落起手 |
| 口播/带货腔 | 88 | 高 | 中文特有语料污染 |
| 拟人/动作隐喻 | 85 | 中高 | 技术文表面特征 |
| 版面痕迹（加粗/列表/emoji） | 80 | 高 | 倍数最高但最易清 |
| 破折号 | 45 | 低 | Gemini 反而 0.7×，不可单用 |
| 弯引号 | 40 | 低 | 取决于输入法/排版规范 |

置信度是"这个特征单独出现时有多可信"，不是"命中就必须改"。判据始终是上下文。

## 四、评分

脚本用加权分项 + 信号数，输出 0–100：

```
score = 0.20×结构 + 0.22×词汇 + 0.20×句式 + 0.08×版面 + 0.30×信号
信号 = 命中的独立检测项数（高置信 1.0，中置信 0.5），在 4 项处饱和
```

加"信号数"一项的原因：实测中，踩了四五个不同坑的短文，比只在一个指标上超线的长文更像 AI。单看密度会把短文判轻。

锚点（实测，见 `tests/samples/`）：

| 样本 | 分数 | 档位 |
|------|------|------|
| 典型 AI 中文（三段论+报告体） | 74 | 高 |
| 典型 AI 英文（助手腔+展望公式） | 70 | 高 |
| 人写技术说明被错用 prose 档 | 18 | 轻 |
| 人写技术说明用 tech 档 | 14 | 低 |
| 轻微 AI 味中文（三句话，含两处套话） | 11 | 低 |
| 人写公文（中文，两段两页） | 9 | 低 |
| 人写个人叙述（中文/英文） | 5–6 | 低 |
| 人写学术摘要（中文） | 5 | 低 |

分数与档位：<15 低；15–40 轻；40–62 中；>62 高。以上锚点全部由 `tests/samples/` 里的样本实测得出，改动权重后需重跑 `tests/test_lint.py` 并同步本表。

## 五、报告格式

脚本输出（`check`）长这样：

```
语言 zh   字符 558   计量单位 442
AI 味 81.9/100   高（一眼 AI）

分项：结构 94  词汇 46  句式 47  残留 17  信号 100

指标：
  句数 20  平均句长 22.1  句长CV 0.36  段长CV 0.42
  加粗 13.6/千  破折号 2.3/千  列表行占比 21%
  AI词 6.8/千  名词化 15.8/千  三项并列 2.26/千  否定平行 2.26/千
  连接词开场句 20%  段首短句 1 处  重复n-gram 0.01  TTR 0.58

命中（按严重度，最多 5 类）：
  [Z01] 空话/拔高/官腔词 ×3  权重3/高  行 1,5
        → 换成具体动作与结果；官腔词一个不留
        例：综上所述，我们需要在推动技术创新的同…
```

`--json` 输出同结构字段，便于写进流程。改写前后各跑一次，取差值作为交付证据。

## 六、文体适配

| 文体 | 调整 |
|------|------|
| 学术论文 | 结构与版面权重下调；词汇（空话）与叙事（是否有判断）权重上调；允许工整的并列 |
| 技术文档 | 列表与表格正常；重点看-词表与"-ing 尾巴"（英文）、名词化（中文） |
| 新闻报道 | 客观是要求；重点看空话、拔高、模糊归属 |
| 评论/随笔 | 中立即是 AI 特征；重点看立场与取舍 |
| 公文 | 后缀与四字格是文体惯例；重点看空转段落与公式化收尾 |
| 文学 | 前四维几乎失效；看叙事层与细节的可信度 |

---

## 七、检测局限

1. 高质量 AI 文本可能得分很低，规范的人工写作可能得分偏高。
2. 分数不跨语言可比。
3. 词表有保质期（delve 已退场，2026 年换成另一批）。
4. 改写会让检测器结果剧烈波动，说明这些工具测的是表层。
5. 人类肉眼判断接近随机（普通人），专家也只在特定语料上达到较高准确率。
6. 任何分数都不能作为学术不端或内容真伪的证据。

结论：把它当体检，不当判决。
