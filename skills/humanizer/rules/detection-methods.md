# AIGC检测方法总结

## 主流检测器的技术原理

基于GPTZero、Turnitin等主流检测器的公开资料，总结AIGC检测的核心方法。

---

## 一、统计特征检测

### 1. 困惑度 (Perplexity)

**原理**: 
- LLM生成文本时倾向于选择概率最高的词
- 困惑度 = 预测下一个词的不确定性
- AI文本困惑度低，人类文本困惑度高

**计算方式**:
```
Perplexity = exp(-1/N * Σlog P(w_i|w_<i))
```

**特征**:
- AI文本：困惑度低，用词"安全"、"正确"
- 人类文本：困惑度高，用词"意外"、"个性化"

**反检测策略**:
- 使用低频词、生僻词
- 使用口语词、方言词
- 使用意外表达而非"正确"表达

### 2. 突发性 (Burstiness)

**原理**:
- 人类写作的句子长度和复杂度变化大
- AI生成的句子长度分布均匀

**检测指标**:
- 句子长度方差
- 句子复杂度变化
- 段落长度分布

**特征**:
- AI文本：方差小，节奏平稳
- 人类文本：方差大，节奏跳跃

**反检测策略**:
- 长短句穿插
- 加入极短判断句
- 制造节奏变化

### 3. 词汇分布 (Token Distribution)

**原理**:
- AI偏好常见词，词汇分布集中在高频区
- 人类词汇分布更均匀

**检测方法**:
- 词频分析
- 词汇多样性指数
- Type-Token Ratio (TTR)

**特征**:
- AI文本：高频词占比高
- 人类文本：词汇丰富，有生僻词

## 二、结构特征检测

### 1. 句式模式识别

**AI典型句式**:
```
中文:
- "在...方面，...起到了重要作用"
- "从...的角度来看"
- "...是...的关键因素"
- "这对...产生了深远影响"

英文:
- "It is important to note that..."
- "In terms of..., ..."
- "This demonstrates that..."
- "There is no doubt that..."
```

**检测方法**:
- 句式模板匹配
- 句式重复度计算
- 句法树分析

### 2. 过渡词频率

**AI高频过渡词**:
```
中文:
- 首先、其次、再次、最后
- 一方面、另一方面
- 综上所述、总而言之
- 需要指出的是、值得注意的是

英文:
- Firstly, Secondly, Thirdly
- On the one hand, On the other hand
- In conclusion, To summarize
- It is worth noting that
```

**检测方法**:
- 过渡词频率统计
- 过渡词分布分析
- 过渡句格式相似度

### 3. 段落结构分析

**AI典型结构**:
```
总分总结构:
- 总起段: ...有以下几个方面
- 分述段1: (长度相近)
- 分述段2: (长度相近)
- 分述段3: (长度相近)
- 总结段: 综上所述...

对称并列结构:
- 从A角度来看... (150字)
- 从B角度来看... (150字)
- 从C角度来看... (150字)
```

**检测方法**:
- 段落长度方差
- 结构对称性分析
- 模式识别

## 三、深度学习检测

### 1. 句子级分类器

**原理**:
- 使用神经网络对每个句子进行分类
- 计算AI概率和置信度

**典型方法**:
- BERT/RoBERTa微调
- 多层Transformer编码器
- Hidden Markov Model (HMM)

**输出**:
- 句子级AI概率
- 置信度类别 (高/中/低)
- 混合内容识别

### 2. 端到端深度学习

**训练数据**:
- 人类文本：网页、教育、创意写作
- AI文本：多种LLM生成的文本

**模型特点**:
- 持续更新适应新模型
- 防止paraphrase攻击
- 防止homoglyph攻击

### 3. 三分类输出

**分类类型**:
1. HUMAN_ONLY - 纯人类撰写
2. AI_ONLY - 纯AI生成
3. MIXED - 人机混合

**优势**:
- 更细粒度的判断
- 识别部分AI内容

## 四、检测器的局限性

### 1. 误报问题

**易误报的情况**:
- ESL写作者（非母语者）
- 规范性文本（技术文档、法律文档）
- 格式化文本（学术写作）
- 简洁文本

**解决方案**:
- 教育领域特殊调优
- ESL数据增强
- 置信度校准

### 2. 漏报问题

**易漏报的情况**:
- 高质量AI文本
- 经过人工修改的AI文本
- 经过paraphrase的AI文本
- 混合AI和人类内容

### 3. 对抗攻击

**常见攻击方式**:
- Paraphrase改写
- 同义词替换
- 句式重构
- Homoglyph替换

## 五、反检测策略总结

### 策略矩阵

| 检测维度 | 检测方法 | AI特征 | 反检测策略 |
|---------|---------|-------|-----------|
| 困惑度 | PPL计算 | 低 | 用意外词汇、口语词 |
| 突发性 | 方差分析 | 低 | 长短句穿插 |
| 词汇分布 | TTR分析 | 集中 | 引入低频词 |
| 句式模式 | 模板匹配 | 规整 | 打破对称、用倒装 |
| 过渡词 | 频率统计 | 高频 | 删除或自然化 |
| 段落结构 | 结构分析 | 对称 | 有详有略 |
| 内容深度 | 语义分析 | 空洞 | 加入具体细节 |

### 具体操作清单

**提高困惑度**:
- [ ] 替换高频词为低频词
- [ ] 加入口语表达
- [ ] 使用意外表述
- [ ] 加入个人判断

**增加突发性**:
- [ ] 合并短句
- [ ] 拆分长句
- [ ] 加入极短判断句
- [ ] 制造节奏变化

**丰富词汇**:
- [ ] 引入专业术语
- [ ] 引入口语词
- [ ] 避免重复用词
- [ ] 使用同义替换

**打破结构**:
- [ ] 删除"其一其二其三"
- [ ] 删除"首先其次最后"
- [ ] 删除加粗编号
- [ ] 有详有略

**替换过渡词**:
- [ ] 删除"综上所述"
- [ ] 替换"一方面另一方面"
- [ ] 用自然过渡替代公式过渡

**增加深度**:
- [ ] 加入具体数字
- [ ] 加入具体案例
- [ ] 加入个人观察
- [ ] 加入反面观点

## 七、检测器的置信度

**置信度分类**:
- High: 错误率 < 1%
- Medium: 错误率 1-5%
- Low: 错误率 > 5%

**影响置信度的因素**:
- 文本长度（越长越准确）
- 文本风格（创意写作更难检测）
- 语言（英文检测更成熟）
- 领域（专业领域更难检测）
