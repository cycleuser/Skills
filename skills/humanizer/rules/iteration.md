# 迭代优化流程

## 概述

本规则定义了人化处理的迭代优化流程，通过多轮检测-改写-评估，逐步降低AIGC检测率。支持口语化和书面化两种处理风格。

## 一、风格识别

### 自动判断

```
判断依据:
1. 词汇正式度
   - 正式词汇占比高 → 书面化
   - 口语词汇占比高 → 口语化

2. 句式复杂度
   - 复杂句式多 → 书面化
   - 短句为主 → 口语化

3. 场景标记
   - 论文、报告 → 书面化
   - 博客、评论 → 口语化

默认规则:
- 用户指定风格 → 使用指定风格
- 自动识别 → 根据文本特征判断
- 无法判断 → 默认书面化
```

### 风格适配

```
书面化处理:
- 保持语言规范性
- 重点提升分析深度
- 加入立场表达
- 增加证据支撑

口语化处理:
- 允许语言松散
- 重点增强互动感
- 加入个人经历
- 使用语气词
```

## 二、检测分析

### 检测流程

```
Step 1: 结构特征检测
├── 段落均匀度分析
├── 列表模式识别
├── 过渡词统计
└── 生成结构得分

Step 2: 语言特征检测
├── AI高频词匹配
├── 句式模式分析
├── 句长分布计算
├── 空洞表达识别
└── 生成语言得分

Step 3: 内容特征检测
├── 观点立场分析
├── 分析深度判断
├── 证据支撑检测
├── 思考痕迹识别
└── 生成内容得分

Step 4: 综合评分
└── 加权计算综合AI率
```

### 问题定位

```
根据得分定位主要问题:

结构得分 > 70:
- 问题: 结构过于工整
- 策略: 打散结构、调整信息组织

语言得分 > 70:
- 问题: 语言空洞、句式重复
- 策略: 替换AI词汇、变化句式

内容得分 > 70:
- 问题: 无立场、无深度、无证据
- 策略: 加入观点、深入分析、补充证据

三项得分都高:
- 问题: 典型AI文本
- 策略: 全面改写
```

## 四、迭代执行

### 迭代轮次

```
迭代1: 结构层改写
- 书面化: 取舍聚焦、问题导向
- 口语化: 打散结构、删除套话

迭代2: 内容层改写
- 书面化: 立场表达、深度分析、证据补充
- 口语化: 个人经历、情绪态度

迭代3: 语言层改写
- 书面化: 空洞表达替换、思考痕迹
- 口语化: 口语词汇、语气词

迭代4+: 细节打磨
- 句式优化
- 节奏调整
- 最终润色
```

### 每轮流程

```
┌─────────────────────────────────────────────────────────────┐
│                     单轮迭代流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 应用策略                                                │
│     ├── 选择当前轮次的策略                                  │
│     ├── 对原文进行改写                                      │
│     └── 生成改写后文本                                      │
│                                                             │
│  2. 效果检测                                                │
│     ├── 重新计算AI率                                        │
│     ├── 对比前后变化                                        │
│     └── 记录改进幅度                                        │
│                                                             │
│  3. 质量检查                                                │
│     ├── 语义保留度检查                                      │
│     ├── 风格一致性检查                                      │
│     └── 可读性检查                                          │
│                                                             │
│  4. 收敛判断                                                │
│     ├── 是否达到目标AI率？                                  │
│     ├── 是否连续无改进？                                    │
│     ├── 是否达到最大轮次？                                  │
│     └── 质量是否下降？                                      │
│                                                             │
│  5. 策略调整                                                │
│     ├── 根据效果调整下一轮策略                              │
│     └── 更新检测报告                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、收敛判断

### 停止条件

```
必须停止:
┌─────────────────────────────────────────────────────────────┐
│ 1. 达到目标AI率                                             │
│    条件: AI率 ≤ target_rate                                 │
│    消息: "已达到目标AIGC率"                                 │
│                                                             │
│ 2. 连续无改进                                               │
│    条件: 连续3轮改进 < 1%                                   │
│    消息: "已收敛，无法进一步降低"                           │
│                                                             │
│ 3. 最大迭代次数                                             │
│    条件: 迭代次数 ≥ max_iterations                          │
│    消息: "已达到最大迭代次数"                               │
│                                                             │
│ 4. 质量下降                                                 │
│    条件: 语义保留度 < 70%                                   │
│    消息: "语义保留度过低，停止迭代"                         │
└─────────────────────────────────────────────────────────────┘
```

### 质量边界

```
语义保留:
- 原文核心意思不能丢失
- 关键信息不能扭曲
- 逻辑关系不能错乱

风格一致:
- 全文风格统一
- 不出现风格混杂
- 符合目标风格定位

可读性:
- 语句通顺
- 表达清晰
- 无语法错误
```

## 八、注意事项

### 迭代原则

```
1. 渐进式改写
   - 每轮改动不宜过大
   - 保持语义连贯
   - 避免风格突变

2. 质量优先
   - AI率不是唯一指标
   - 不能牺牲可读性
   - 不能扭曲原意

3. 边际效应
   - 后期改进幅度递减
   - 适时停止迭代
   - 不是越低越好

4. 人工判断
   - 最终需要人工审核
   - 检测结果仅供参考
   - 结合具体场景判断
```

### 常见问题

```
问题1: AI率下降但质量变差
原因: 过度改写
解决: 回滚到上一轮，降低改写强度

问题2: AI率停滞不降
原因: 已收敛或策略不对
解决: 更换策略或接受当前结果

问题3: 风格不统一
原因: 改写过程中风格偏移
解决: 重新定位风格，统一改写

问题4: 语义偏移
原因: 改写过度
解决: 回滚，降低改动幅度
```
