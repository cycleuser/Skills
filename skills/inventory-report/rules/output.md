# 输出规范 (Output)

## xlsx 分类汇总表

- 主 sheet「成果汇总」：`序号|年度|类别|名称|具体信息|级别|时间`
  - 类别列加底色（浅蓝），标题合并居中、加粗，冻结首行。
  - 微软雅黑，表头深蓝底白字。
- 副 sheet「分类统计」：类别×年度数量矩阵（或类别计数）。
- 用 `scripts/gen_summary.py` 的 `build_xlsx` 直接生成，条目来自核验结果。

## 一段话总结

固定句式，单一自然段，全阿拉伯数字：

```
<对象>共<N>项：论文X篇（中文核心X篇、EI会议X篇，其中一作X/通讯X/参与X）；
软件著作权X项（第一完成人X项）；教材X部（主编X/参编X）；
获国家级奖项X项、省级X项、校级X项；主持立项课题X项；
指导学生竞赛获奖X项（国家级X、省级X），指导学生获批大创X项。
```

细分口径不齐时，按可用口径给，缺的项可省略，但**不要编数**。

## docx 报告（可选）

分类章节 + 数据，标题黑体小三、正文宋体小四，与用户单位文档规范一致。

## 数字口径铁律

1. 以用户最后确认的数字为准。
2. 一作/通讯/参与、第一完成人/参与、国家级/省级/校级、已授权/受理中，必须分项统计。
3. 校级不并入省级以上；申请中/交底书不算获批。
