# 文学创作反AIGC检测规则

文学模仿类作品面临的AIGC检测最为严格——读者对文笔的敏感度极高，且文学作品的AI痕迹远比技术文档更容易被感知。

## 核心原则

文学模仿的神似要求：不是模仿作家的词汇表，而是像他一样思考。AIGC检测器在文学文本上尤其敏感，因为AI生成的文学文本缺乏"文学性挣扎"——矛盾、犹豫、跳跃、意外——这些恰是人类写作的指纹。

## 文学创作AIGC高发模式

### 1. 笔调过于均匀（权重30%）

AI文学文本最致命的特征是句式和节奏过于均匀。

```
❌ AI文学模式：
- 所有段落长度接近（AI倾向生成均匀的段落）
- 句子节奏一致（主谓宾、主谓宾、主谓宾）
- 情绪曲线平稳（没有突兀的转折或断裂）
- 感官描写均匀分布（每种感官各来一点）
```

```
✅ 人类文学特征：
- 长段落之后跟一个三字短句，制造节奏断裂
- 有些句子故意不完整，留下悬空
- 情绪有骤变而非平滑过渡
- 感官描写有偏重——鲁迅偏听觉和老舍偏嗅觉，而非均匀分配
```

### 2. 意象堆砌而非意象服务（权重25%）

AI倾向堆砌与作家风格相关的意象，而非让意象服务于叙事和主题。

```
❌ AI鲁迅模仿（形似）：
"夜色深沉，如同铁屋子般压抑。街上的行人寥寥无几，如同鬼魅般飘过。月光冷冷地照在青石板上，仿佛在审视着这个古老的民族。"

问题：意象堆砌（铁屋子、鬼魅、月光、审视），没有一个真正推动叙事或表达矛盾。
```

```
✅ 深层鲁迅模仿（神似）：
"他翻了几页，看到的是一个又一个熟悉的名字——曾经意气风发的改革者，如今都在体制里找到了安稳的位置。他没有说话，只是把书放回去，走了。

这沉默里有什么？失望？理解？还是习惯了？他说不上来。"

关键：不堆砌意象，而是在具体的动作和沉默中让矛盾自然浮现。
```

### 3. 情感直接宣泄（权重20%）

AI习惯直接说出情感，而人类作家通过细节、矛盾和留白传达。

```
❌ AI模式：
"他感到深深的悲凉"
"她心中充满了绝望"
"一股愤怒涌上心头"

✅ 人类模式：
鲁迅：不写"悲凉"，写"他走出门去，街上的风很冷"——悲凉在环境里
老舍：不写"绝望"，写"祥子看着车，车还是那辆车"——绝望在重复里
古龙：不写"愤怒"，写"酒杯碎了。他没再要。"——愤怒在动作里
金庸：不写"热血"，写"郭靖一把握住枪杆，手心全是汗"——热血在细节里
```

### 4. 结构对称性过强（权重15%）

```
❌ AI模式：
开头铺垫 → 发展 → 高潮 → 反思 → 结尾收束
每段"首先...然后...接着...最后..."

✅ 人类模式：
鲁迅：短句+长句交替，中间插入议论，结尾可能沉默
古龙：极短句+突然长句，大量留白，叙事可以突然中断
茨维格：一个核心矛盾反复缠绕，螺旋上升而非直线推进
卡尔维诺：结构本身就是内容的表达，可能突然转到完全不同的叙事层
```

### 5. 过渡词过多（权重10%）

```
❌ AI高频过渡词：
中文：然而、因此、此外、与此同时、不可否认、值得一提的是
英文：However, Therefore, Moreover, Meanwhile, It is worth noting that

✅ 文学自然过渡：
- 直接开始新段落（鲁迅、老舍）
- 用动作过渡："他站起来，走到窗边"
- 用对话过渡："'走吧。'他说。"
- 意识流动：不加过渡，像思维自然跳跃（茨维格）
- 完全不过渡：场景直接切换（古龙）
```

## 各作家反AIGC特定策略

### 鲁迅

```
核心反AI策略：
- 用冷峻白描替代热情议论
- 用反语替代正面批判
- 用省略替代解释
- 用具体场景替代抽象概念
- 绝不在一段里同时使用多个比喻
```

### 老舍

```
核心反AI策略：
- 用京味儿口语替代书面叙述
- 用幽默化解替代严肃控诉
- 用小人物的具体困境替代抽象阶级分析
- 对话推动叙事而非旁白推动
- 议论必须穿插在叙事中，而非单独成段
```

### 金庸

```
核心反AI策略：
- 武功描写必须服务于人物性格（非AI式的"他使出了XX剑法第X式"）
- 四字词语用于意境而非堆砌
- 文白交替制造距离感，但白话部分必须有血有肉
- 家国情怀通过具体选择体现，而非口号式表白
```

### 古龙

```
核心反AI策略：
- 短句制造节奏而非AI式的"短句+短句+短句"机械三连
- 留白要留在对的位置——在情感转折处，而非每段结尾
- 不写武功过程只写结果≠不写任何过程，关键动作必须有画面
- 孤独的书写需要具体情境，而非抽象陈述
```

### 莎士比亚

```
核心反AI策略：
- 独白必须展现内在矛盾，不是陈述结论
- 诗意语言用于触及真相而非装饰
- 五步抑扬格节奏需要自然流畅，不是每个词都完美对位
- 悲剧感来自选择及其代价，不是命运本身的宏大描述
```

### 茨维格

```
核心反AI策略：
- 心理描写要像显微镜，不是广角镜
- 长句的积累必须有情感爆发点作为出口
- 克制表达时用外在平静掩盖内在翻涌，而非两者都激烈
- 命运的偶然性要用具体细节呈现，不是用"命运的转折"这种词
```

### 卡尔维诺

```
核心反AI策略：
- 精确描述不等于AI式的面面俱到
- 数学逻辑与想象的结合需要真正的意外，而非可预测的奇幻
- 结构实验必须服务于叙事，而非为了实验而实验
- 轻盈感来自对世界的超越性观察，不是来自忽略重力
```

## 文学创作AIGC率检测清单

### 笔调检测
- [ ] 段落长度是否变化明显（方差>0.3倍均值）？→若均匀则AIGC率高
- [ ] 句子节奏是否有突兀的断裂？→缺乏断裂则AI嫌疑大
- [ ] 情绪是否有骤变？→平滑曲线暗示AI

### 意象检测
- [ ] 意象是否服务于叙事/主题？→堆砌意象是AI特征
- [ ] 是否有具体场景而非抽象描述？→抽象=AI
- [ ] 比喻是否自然而非刻意？→刻意比喻是AI

### 情感检测
- [ ] 情感是否通过细节和动作传达？→直接宣泄=AI
- [ ] 是否有留白和省略？→AI倾向填满所有空间
- [ ] 是否有矛盾和犹豫？→AI倾向平滑过渡

### 结构检测
- [ ] 结构是否打破线性对称？→对称结构=AI
- [ ] 过渡是否自然？→机械过渡词=AI
- [ ] 结尾是否有意外或沉默？→圆满收束=AI

### AIGC率评分标准（文学专用）

- 0-10%：神似，读起来像该作家写的
- 11-25%：形似，风格像但有AI痕迹
- 26-40%：勉强，能看出模仿意图但AI感明显
- 41-60%：不符，风格不对且AI感很强
- 61-100%：背离，完全没有模仿到
