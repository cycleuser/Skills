# 长篇人物一致性指南 / Character Consistency

长篇最大的风险不是文笔，是人物在多章节里慢慢走样。本文件规定「锚点、追踪、检测、回退」四件事。

---

## 一、人物卡是锚点

续写前必须回顾相关人物卡。人物的一切言行，都要能在卡上找到依据。
若卡上没有，先补卡，再动笔。

四块必须一致的：

1. **性格**：核心特质与内在矛盾，全书稳定。
2. **声线**：对话的词汇、句长、称呼方式，全书稳定。
3. **能力**：技能与局限，不能这章做不到、下章突然做到。
4. **关系**：人际的亲疏变化必须有因果，不能跳跃。

---

## 二、声线一致性

最容易失控的一点。每个主要人物都要有可辨识的说话方式。

记录项：
口头禅、句长偏好、爱用的虚词、生气时说什么、害怕时的动作、对上级与对下属的不同语气。

自检问法：把对话里的人名遮住，能不能靠语气认出是谁在说？认不出，声线就失败。

---

## 三、弧线追踪

人物成长要有触发事件，且触发事件要写在正文里，不能只写在卡上。

```
弧线阶段：天真 → 受挫 → 觉醒 → 成熟
当前阶段：受挫（第12章，触发事件：遭朋友背叛）
下次转折条件：第18章（计划：发现真相后重新选择）
```

规则：

1. 每个阶段至少跨三章，避免一章一个大转变。
2. 转变前的铺垫不能省，读者要能回看找到伏笔。
3. 转变后的人物卡要更新「当前阶段」，旧版归档到回收站或版本记录。

---

## 四、关系演变

关系变化必须有连续的互动积累。判断标准：

- 从陌生到信任，至少三次有效互动。
- 从信任到决裂，至少一次不可逆的伤害事件。
- 爱情线不要在五章之内从相识走到生死相许。

关系图（`/文豪 关系图`）用于快速检查是否有对不上的地方。

---

## 五、漂移检测

每次审稿，逐角色做一遍对照。

| 检查 | 方法 |
|------|------|
| 性格漂移 | 本章行为能否在人物卡上找到依据 |
| 声线漂移 | 遮名测试，能否认出说话人 |
| 能力漂移 | 有无超出设定的能力展示 |
| 关系漂移 | 亲疏变化是否有前置事件 |
| 立场漂移 | 核心价值观有无无理由反转 |

发现问题时的处理顺序：
先回看人物卡，再回看相关章节，能改本章就不回退，改不动才回退章节。

---

## 六、多视角长篇

人物超过五位时，为每人建立「声线卡」，并在 project.yaml 的 `style_map` 里标注视角分配。
审稿时优先检查核心角色，核心角色数量建议控制在五以内。

---

## 七、负面清单

以下都算一致性事故：

- 前文怕血的角色，后文面不改色地处理尸体。
- 前文口舌笨拙的角色，突然长篇大论。
- 前文势同水火的两人，中间无事件就称兄道弟。
- 前文明确不会武功的角色，关键时刻突然出手。
