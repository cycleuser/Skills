# 风格迁移 / Style Transfer

把一段已有的文本，改写成另一位作家的声部。只换语言，不动情节、人物、场景。
本文件是 `/文豪 迁移` 的核心依据，也是「作者间验证 → 再上 AI 与人」这条研究路线的第一段执行规范。

---

## 一、定位：迁移不是重写

| 维度 | 单次创作 `/文豪 <作家> <选题>` | 风格迁移 `/文豪 迁移 <源→目标> <文本>` |
|------|------------------------------|----------------------------------------|
| 输入 | 一个题目或一句起兴 | 一段成文 |
| 约束 | 自由发挥 | 保情节、保人物、保信息量 |
| 难点 | 找到神似 | 换声部而故事不走样 |
| 产物 | 新作品 | 同一段事，换一副嗓子说 |

迁移的本质是**换嗓子**：说的是同一件事，说话的人换了。
一旦情节被改动、信息被增删，迁移就失败了，哪怕文风再像。

---

## 二、边界：什么必须留下，什么必须换掉

**必须保留（硬约束）**

1. 事件与因果：谁做了什么、先后顺序、结果如何。
2. 人物与关系：身份、动作、情绪的走向。
3. 场景与信息：时间、地点、关键物件、关键数字。
4. 篇幅量级：目标文本与原文长度相当，允许上下浮动三成。

**必须换掉（风格层）**

1. 声部：谁在说、离得远不远、冷不冷。
2. 句法：长句还是短句、虚词怎么用、标点怎么打。
3. 意象：拿什么打比方、比喻从哪个生活领域来。
4. 结构：段落怎么切、开场怎么起、收尾怎么收、议论文如何安放。

## 三、四层迁移法

按「声部 → 句法 → 结构 → 标记」四层依次施工。上一层没定，下一层不动笔。

### 第一层：声部迁移

先回答四个问题，给目标作家定坐标。

| 维度 | 取值 | 例 |
|------|------|-----|
| 叙述距离 | 贴身 / 旁观 / 介入 | 茨威格贴身，鲁迅旁观，老舍介入 |
| 温度 | 热（抒情）/ 温（幽默）/ 冷（白描） | 茨威格热，老舍温，鲁迅冷 |
| 语体 | 口语 / 书面 / 文白夹杂 | 老舍口语，鲁迅文白夹杂 |
| 介入度 | 叙述者会不会跳出来议论 | 老舍常跳出来，古龙几乎不 |

### 第二层：句法迁移

这是决定「像不像」的一层。逐项对照施工。

1. **句长分布**。目标作家是均匀还是参差。古龙极短，老舍长短交错，鲁迅短而硬，茨维格长句累积。
2. **虚词替换**。同一句意思，换一套语气词与连接词。京味用「倒是、就是、横竖、偏偏、罢了」；冷峻用「大抵、确乎、便是、也、却」。
3. **标点密度**。破折号、顿号、句号、省略号各家用得多少不同。迁移时先定标点基调再动字。
4. **排比必打断**。排比是最容易露 AI 尾巴的地方。原文若有对仗排比，迁移时按目标作家的习惯拆散。
5. **句子完整性**。有些作家故意留不完整的句子悬空，不要替他把话补圆。

### 第三层：结构迁移

1. **段落长度方差**。人类文学的段落长度参差不齐。若迁移后各段长短接近，回炉。
2. **开场方式**。老舍拉家常（「要说这事儿」），鲁迅冷起，古龙留白，金庸铺陈。
3. **收尾方式**。老舍自嘲，鲁迅沉默或回望，古龙留悬念，茨维格留余味。
4. **议论的位置**。老舍的议论穿插在叙事里，鲁迅的议论可独立收束，古龙的议论几乎不用。

### 第四层：标记迁移

1. **意象域**。老舍用生活物件（车、雪、貂皮、哈欠），鲁迅用冷色与处境，古龙用刀剑风雪酒，金庸用山河家国。
2. **比喻来源**。比喻要从目标作家熟悉的生活里取，不要从「文学评论」里取。
3. **感官偏好**。老舍偏嗅觉与触觉，鲁迅偏听觉，古龙偏视觉留白。同一场景，各家抓的感官不同。
4. **禁用词表**。每位作家都有一批「写出来就不像他」的词，迁移前先列出来。

## 四、作者间迁移矩阵

中文四家互相迁移时，要拆掉什么、要装上什么。

| 源 → 目标 | 拆掉 | 装上 |
|-----------|------|------|
| 古龙 → 老舍 | 排比、留白式短句、诗化意象、宏大时空 | 京味口语、拉家常开场、带苦味的幽默、生活物件 |
| 古龙 → 鲁迅 | 抒情、华丽比喻、连贯画面 | 冷峻白描、短硬句、反语、克制 |
| 老舍 → 鲁迅 | 儿化、亲昵、说话人插科打诨 | 文白夹杂、旁观冷评、「大抵/确乎」 |
| 老舍 → 古龙 | 长句、解释性议论、生活琐细 | 极短句、留白、单线动作、悬念 |
| 鲁迅 → 老舍 | 冷评、文白腔、锋利收束 | 口语温度、自嘲、日常细节 |
| 鲁迅 → 古龙 | 议论、社会切片、群像 | 孤独个体、动作与沉默、回合式对话 |
| 金庸 → 古龙 | 招式铺陈、四字词组、章回腔 | 只写结果、极简、孤独氛围 |
| 金庸 → 老舍 | 文白、豪迈、宏大叙事 | 市井视角、小人物、口语 |

西方三家（莎士比亚 / 茨维格 / 卡尔维诺）与中文作家互迁时，保留语言的逻辑结构，把典故与俗语换成目标语言里对等的东西。

## 五、分阶段工作流

这条路线来自「先作者间验证、再上 AI 与人」的实验设计，迁移可以分三段做。

**阶段一：作者间迁移（可复核）**
在两个人类作家之间来回迁移，比如古龙 → 老舍、老舍 → 鲁迅。原文与改写都在，任何人可以逐句核对情节有没有走样、文风有没有到位。这一段的目的是把「迁移能力」本身先验证清楚。

**阶段二：AI 文本 → 人风格 / 人文本 → AI 风格**
把机器生成的文本迁成某位作家的声部，或把人写的文本迁成「AI 腔」，观察哪一侧更难伪装。这一段才是检测研究的正题。

**阶段三：检测评估对照**
同一批文本，分「原件 / 迁移件 / 混合件」三组，交给检测器与真人读者，记录检出率与误判。评估三端：机器检测、专家读者、普通读者。

## 六、反 AIGC（迁移版）

迁移比原创更容易露 AI 尾巴，因为模型会不自觉地「保持原节奏」。几条硬要求：

1. 迁移完成后，段落长度方差必须比原文更大或相当，绝不能更均匀。
2. 至少有一处情绪骤变或节奏断裂（长段之后来个三字短句）。
3. 不许为了「像某作家」而堆意象。一位作家在一段里通常只用一两个核心意象。
4. 情感靠动作和细节带出，不靠形容词直说。愤怒写在动作里，悲凉写在环境里。
5. 过渡词能删就删，段落直接起，动作直接接。

详见 [anti-aigc.md](anti-aigc.md)。

## 七、自检清单与评分

**清单**

- [ ] 情节、人物、场景、关键数字是否与原文一一对应，无增无删？
- [ ] 段落长度是否有明显参差？
- [ ] 句长是否有断裂，还是通篇一个节奏？
- [ ] 是否有对仗排比残留？
- [ ] 意象是否服务于叙事，还是为了贴标签而堆？
- [ ] 情感是否通过细节传达，而非直接宣告？
- [ ] 开场与收尾是否符合目标作家的习惯？
- [ ] 目标作家的禁用词是否清干净？

**评分（文学迁移专用）**

| 分数 | 判定 |
|------|------|
| 90 以上 | 神似：读者会觉得像本人写的，情节零走样 |
| 75 至 89 | 良好：风格到位，个别句子还带原作家的调子 |
| 60 至 74 | 合格：能看出迁移意图，但 AI 感或原腔残留明显 |
| 60 以下 | 不合格：情节走样，或只是换了几个词 |

## 八、常见失败模式

**失败一：照抄原文**
模型判断「这已经是中文了」，于是原样吐回。对策：在指令里明确要求「措辞与句式都要换掉，绝不照抄」。

**失败二：语法破碎、重复词**
多见于小参数量的模型。出现「寒风像一把一样锋利的」「白银白银」这类，说明生成能力不足，不是提示词问题。对策：换更大或更擅长中文的模型，或改由人来执笔。

**失败三：意象堆砌**
一写鲁迅就「铁屋子」，一写老舍就「京片子」。这是形似，不是神似。对策：删到只剩一两个真正推动叙事的意象。

**失败四：情节被改**
迁移时顺手把人物的动作或结局改了。对策：迁移完成后逐句回对原文，列出信息对照表。

**失败五：节奏被拉平**
模型倾向把长短句抹成一个节奏。对策：迁移后单独做一遍节奏检查，必要时手工打断长句。

## 九、可复现样例

### 样例 A：古龙 → 老舍

**原文（古龙《多情剑客无情剑》开篇）**

冷风如刀，以大地为砧板，视众生为鱼肉。万里飞雪，将穹苍作洪炉，溶万物为白银。雪将住，风未定，一辆马车自北而来，滚动的车轮辗碎了地上的冰雪，却辗不碎天地间的寂寞。李寻欢打了个呵欠，将两条长腿在柔软的貂皮上尽量伸直，车厢里虽然很温暖、很舒服，但这段旅途实在太长、太寂寞，他不但已觉得疲倦，而且觉得很厌恶。他平生最厌恶的就是寂寞，但他却偏偏时常与寂寞为伍。

**改写（老舍）**

要说这两天儿，老天爷可真没给人留脸面。

风刮在脸上，跟小刀子拉似的。雪下起来还没完，天和地白花花的，分不出哪儿是哪儿。赶上这种日子，人的骨头再硬，也硬不过天去。

雪刚落小了些，风还没歇。一辆车打北边过来，轮子从雪地上轧过去，把底下的冰碾得咯吱咯吱响。可天地间那股子空落落的劲儿，它碾不散。

李寻欢打了个哈欠，把两条长腿往貂皮上伸，伸了又伸，横竖不舒坦。车里倒是暖和，坐着也软和，就是这条道太长，太闷，闷得他心口发慌。

他这辈子最怕的就是个闷字。偏偏走到哪儿，这闷字都跟着，甩也甩不开。

**工艺**：拆掉古龙的四字排比与宏大时空，换上拉家常开场与京味口语；把「天地寂寞」降成小人物「心口发慌」；长句后嵌短句，四段长度不齐。

### 样例 B：老舍 → 鲁迅

**原文（老舍《不成问题的问题》开篇）**

任何人来到这里，他必定会感觉到世界上并没有什么战争，和战争所带来的轰炸、屠杀，与死亡。专凭风景来说，这里真值得被呼为乱世的桃源。前面是刚由一个小小的峡口转过来的江，江水在冬天与春天总是使人愿意跳进去的那么澄清碧绿。背后是一带小山。山上没有什么，除了一丛丛的绿竹和矮树，在竹树的空处往往露出赭色的块块儿，像是画家给点染上的。小山的半腰里，那青青的一片，在青色当中露出一两块白墙和二三屋脊的，便是树华农场。

**改写（鲁迅）**

到树华农场来的人，大抵会起一种错觉，以为这世上本没有战争，也没有轰炸、屠杀和死。

单看风景，这里是很配叫作「乱世的桃源」的。

前面是一条江，从一个不大的峡口里拐过来。那水在冬春两季绿得发亮，绿得叫人想跳下去。背后一带小山。山上没有别的，只有丛丛的绿竹和矮树，竹树的空处露出赭色的土，像是画家随手点上的。

山腰里一片青，青里透出白墙一两块、屋脊两三道，那便是树华农场。

**工艺**：拆掉老舍的儿化与亲昵，换成文白夹杂的冷调；「大抵、很配叫作、便是」立住旁观的距离；不写「美丽」，只让水自己说话；末句用一段回望收束，不议论。

> 提示：古龙 1985 年逝世，作品尚未进入公有领域，样例中仅作风格对照的短摘。商用或成篇发表前请确认授权。

## 十、命令用法

```bash
/文豪 迁移 古龙→老舍 "冷风如刀，以大地为砧板，视众生为鱼肉。"
/文豪 迁移 老舍→鲁迅 src.md
/文豪 迁移 鲁迅 "他说这话的时候，脸上没什么表情。"
/literary transfer gulong->laoshe "The cold wind cut like a blade."
```

参数说明：

| 参数 | 说明 |
|------|------|
| `<源→目标>` | 用箭头指定源与目标作家；省略源时，由系统判断并声明 |
| `<文本\|文件>` | 直接给一段文字，或给一个文件路径，也接受 `目录/`.md 批量 |
| `--keep-length` | 强制目标文本与原文长度相当（默认开启） |
| `--matrix` | 只输出迁移矩阵与工艺档案，不动笔改写，供人工校对用 |
| `--check` | 只对已有迁移件做校核，输出评分与问题清单 |

配套命令：

```bash
/文豪 迁移 校核 out.md 以鲁迅 原文 src.md   # 逐句回对原文，检查情节是否走样
/文豪 迁移 矩阵                              # 查看中文四家的互相迁移要点
```
