## 西方作家词汇库

### 莎士比亚

**语言特征**:
- 隐喻、明喻、双关语丰富
- 古英语词汇（thee, thou, hath）
- 排比、对偶结构

**典型意象**:
```
自然: sun, moon, stars, roses, lilies
时间: time, age, decay, eternal
情感: love, death, passion, fate
舞台: stage, play, actor, mask
光影: light, darkness, shadow, flame
```

**中文表达**:
```
称呼: 阁下、殿下、陛下、卿、汝、吾
时间: 昔日、今朝、来日、永恒
命运: 命运、劫数、天意、宿命
情感: 悲欢离合、爱恨情仇
```

---

### 茨维格

**语言特征**:
- 优雅流畅的长句
- 细腻的心理描写
- 克制的情感表达

**典型意象**:
```
时间: 傍晚、黄昏、暮色
空间: 咖啡馆、火车站、轮船
天气: 雨、雾、雪
物品: 信件、照片、旧书
状态: 沉默、等待、凝视
```

**中文表达**:
```
时间流逝: 岁月、往昔、一去不返
情感状态: 迷惘、惆怅、怅然、黯然
命运感: 宿命、偶然、际遇、邂逅
怀旧: 旧日、往日、昨日、逝去的
心理: 隐秘、压抑、涌动、无法言说
```

---

### 卡尔维诺

**语言特征**:
- 精确而轻盈
- 奇幻意象的精确描述
- 数学般的逻辑结构

**典型意象**:
```
几何: 圆形、三角形、螺旋
数字: 七、五十五、无限
元素: 空气、水、蜘蛛网
空间: 城市、塔、镜子、迷宫
时间: 时间零、循环、静止
```

**中文表达**:
```
轻盈: 轻逸、悬浮、漂浮
精确: 精确、恰好、丝毫不差
几何: 螺旋、圆形、对称、无限
可能: 可能性、或许、另一条路
结构: 迷宫、网络、交织、折叠
```

## 中国作家词汇库

### 鲁迅

**语言特征**:
- 简洁有力的短句
- 白话文的典范
- 讽刺与反语

**典型意象**:
```
黑暗: 铁屋子、黑暗、无物之阵
食物: 人血馒头、药
人物: 狂人、阿Q、看客
自然: 野草、枣树、荒原
状态: 麻木、冷漠、沉默
```

**句式特征**:
```
判断句: "……是……的。"
反问句: "然而……能……么？"
转折句: "然而……"、"但是……"、"不过……"
讽刺句: "我向来……"、"中国的……"
```

**常用词汇**:
```
动词: 翻开、看、说、想、觉得
形容词: 沉重、黑暗、麻木、冷漠
名词: 看客、国民性、礼教、吃人
语气词: 罢、么、呢
```

---

### 老舍

**语言特征**:
- 京味儿语言
- 幽默讽刺
- 口语化叙事

**京味儿词汇**:
```
敬语: 您、您老、您吉祥
应答: 敢情、得嘞、甭、别介
疑问: 怎么着、干嘛、这一下
形容词: 麻利、利索、爽快、地道
动词: 折腾、闹腾、折腾、凑合
语气词: 呢、呗、不是
```

**句式特征**:
```
陈述句: "……呢，……"
感叹句: "好家伙！"、"得嘞！"
反问句: "您说是不是？"、"这叫什么事儿呢？"
闲聊式: "要说……"、"咱们……"
```

**常用表达**:
```
开场: "咱们说的是……"、"要说……"
过渡: "话说回来……"、"说起来……"
结尾: "就这么回事"、"就是这么着"
评价: "这事儿……"、"怎么说呢……"
```

### 金庸

**语言特征**:
- 文白相间
- 章回体结构
- 四字词语

**四字词语**:
```
景物: 青山绿水、白云苍狗、长河落日、孤烟直上
动作: 剑光一闪、身形如风、飞身而起、凌空翻跃
武功: 刀光剑影、内力深厚、武功盖世、出神入化
人物: 侠肝义胆、武功高强、风流倜傥、玉树临风
```

**句式特征**:
```
动作描写: "只见……"、"那人身形一闪……"
心理描写: "心中不禁……"、"暗想：'……'"
武功描写: "使出……招，……"、"内力运转，……"
景物描写: "但见……"、"只见……，不禁……"
```

**章回标题格式**:
```
数字+动词/形容词+名词
例: "风雪惊变"、"冤家聚头"、"突如其来的"
```

---

### 古龙

**语言特征**:
- 极简主义
- 诗化语言
- 一行一段

**典型意象**:
```
自然: 风、冷风、冷风吹
武器: 刀、剑、飞刀、快剑
人物: 浪子、杀手、孤独者
物品: 酒、女人、寂寞
状态: 孤独、寂寞、快
```

**句式特征**:
```
断句:
"风。冷风。冷风吹过他的脸。"

反问:
"为什么？他不知道。"

重复:
"剑是好剑。很快的剑。"

对比:
"他可以走。但他没有走。"

留白:
"没有人知道。也许连他自己也不知道。"
```

**典型表达**:
```
开场: "风吹过。"、"夜已深。"
动作: "刀出鞘。"、"人已倒下。"
结果: "没有人看清他怎么出手的。"
结尾: "他走了。没有人知道他去哪里。"
```

## 创作选择指南

### 选择莎士比亚，当:
- 需要戏剧性冲突
- 要表达激情与命运
- 人物需要内心独白
- 主题涉及爱情、权力、生死

### 选择茨维格，当:
- 需要细腻的心理描写
- 要表达怀旧与失落
- 关注命运的偶然
- 希望叙事优雅克制

### 选择卡尔维诺，当:
- 创作奇幻/寓言故事
- 需要精确的描述
- 进行结构实验
- 探讨存在与可能性

### 选择鲁迅，当:
- 需要社会批判
- 要表达冷峻的观察
- 关注国民性、人性
- 语言要简洁有力

### 选择老舍，当:
- 写北京/市井生活
- 需要幽默讽刺
- 语言要接地气
- 关注底层小人物

### 选择金庸，当:
- 创作武侠/传奇故事
- 要表达侠义精神
- 需要宏大的历史背景
- 人物要有成长弧线

### 选择古龙，当:
- 创作武侠/悬疑故事
- 需要极简的语言
- 要营造孤独冷冽的氛围
- 情节需要悬念反转
