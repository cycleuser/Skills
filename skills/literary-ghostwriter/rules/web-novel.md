# 网文创作专项规则 / Web-Novel

`/文豪 网文` 的执行标准。网文的第一原则是留人，文学性是第二位的。

---

## 一、黄金三章

前三章决定读者留不留。

| 章 | 任务 |
|----|------|
| 第一章 | 三百字内给出主角处境与一个钩子；章内至少一个爽点或悬念 |
| 第二章 | 立住主角的核心欲望与外部压力；对手登场 |
| 第三章 | 第一次小高潮，让读者尝到甜头，章尾埋大钩子 |

前三章不要铺世界观，不要把设定当故事讲。设定随情节掉出来。

---

## 二、爽点节奏

爽点是读者情绪的兑现。要求：

1. 每章至少一个情绪兑现点，可大可小。
2. 连续两章没有兑现点，读者会掉。
3. 大爽点前要有小憋屈，落差越大兑现越强。
4. 兑现要具体，让主角当场拿到东西（赢、得、解开、打脸）。

爽点密度分布：

```
小爽 - 小爽 - 憋屈 - 大爽 - 小爽 - 小爽 - 憋屈 - 更大爽
```

---

## 三、断章钩子

章尾不留钩子，读者不会点下一章。

常用钩子类型：

| 类型 | 例 |
|------|-----|
| 悬念 | 门推开了，里面站着的人让他愣住 |
| 反转 | 他以为赢定了，抬头却看见 |
| 危机 | 刀已经架在脖子上 |
| 信息 | 那封信上只写了一行字 |
| 情绪 | 他忽然笑了，笑得比哭还难看 |

钩子要短，一两句收住，不要解释。

---

## 四、节奏与篇幅

1. 单章两千到三千字为宜，长章要拆。
2. 场景切换要快，不写无冲突的过渡。
3. 环境描写一次不超过三句，除非是刻意营造氛围的高潮章。
4. 对话推进情节，不写没有功能的寒暄。

---

## 五、爽文与文学性的取舍

网文优先追读，但不能因此丢掉人物。
「爽」要靠主角的选择兑现，不能靠降智的对手。
对手越强，赢下来的爽感越真。

---

## 六、常见病症

| 症状 | 处方 |
|------|------|
| 黄金三章信息量不足 | 把设定后移，先给冲突 |
| 爽点密度不够 | 检查每章是否有兑现点 |
| 断章没钩子 | 章尾加悬念或反转，一句收住 |
| 主角讨嫌 | 检查主角有无主动选择，别让他一直被推着走 |
| 节奏拖沓 | 删掉无冲突的过渡段落 |
