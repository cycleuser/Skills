# 文学反 AIGC 规则

文学是 AIGC 检测最敏感的文类。核心认知：**真实作家的句法不规则、结构不对称、情绪不均一、意象不工整——恰恰是他们的指纹**。四层工艺（声部/人物/结构/标记）本身就是反 AI 的结构性武器。

## 一、AI 的十大"统一场"症状（必须逐一消除）

1. **均匀句长**：AI 倾向所有句子等长。反制：刻意制造长短落差（狄金森的断句 vs 托尔斯泰的长累积句）。
2. **排比三段式**：AI 爱用三个并列结构。反制：两个并列后突然换成单句；或四个并列破坏对称（果戈理的离题）。
3. **过渡词依赖**："与此同时""另一方面""值得注意的是"。反制：动作过渡/场景切换/对话引入/完全不过渡，各章换策略。
4. **机械总分总**：开头论点-中间展开-结尾总结。反制：用契诃夫式悬置结尾（一切正要开始）或意象收束（川端的银河）。
5. **情绪弧度均一**：每章起伏曲线相同。反制：设计"平静章"穿插"高潮章"（鲍勃·迪伦式低语段落混在轰鸣段落间）。
6. **人物行为模式化**：每次冲突用同一模式解决。反制：引入"没想到但合理"的选择。
7. **伏笔过于工整**：伏笔在"恰好"的时机均匀回收。反制：部分提前回收（读者意外）、部分延后（读者等待）。
8. **词汇浮夸而空泛**："卓越的""深邃的""宏大的"。反制：具体名词、精确数字（莫泊桑的"和所有真正的诺曼人一样节俭"式讽刺藏在名词里）。
9. **形容词泛滥**：AI 爱贴形容词而非动词。反制：动词驱动（杰克·伦敦的血/牙/棍棒）、一个多余形容词都不要（莫泊桑）。
10. **对话均为"说明式"**：人物说对方已知之事，解释剧情。反制：潜台词（契诃夫）、试探（詹姆斯）、省略（海明威）。

## 二、分声部反 AI（每个声部有自己的"不规则指纹"）

| 声部 | 该模仿的不规则处 |
|---|---|
| 托尔斯泰式 | 破折号自我反驳、长句内突然的短句判决 |
| 陀思妥耶夫斯基式 | "忽然"突转、斜体关键思想、临床心理词 |
| 契诃夫式 | 省略、景物的情绪泄露、话不对题 |
| 福楼拜式 | 自由间接引语三层回声、imparfait 的无终点动作 |
| 卡夫卡式 | 办事腔、账目精确、被动式 |
| 伍尔夫式 | 分号抒情、句子的未完成感 |
| 海明威式 | 短句、重复、对话留白 |
| 川端式 | 留白、季节词、意象收束 |
| 莫言式 | 感官泛滥、民间说书腔、狂欢化 |
| 萨拉马戈式 | 无句读、无人名 |
| 埃尔诺式 | 平白、无人称、物件对照 |
| 克拉斯诺霍尔卡伊式 | 数页一句的无标点泥沼 |

## 三、结构性反 AI

- **段落长度不均**：一个 400 字长段后紧跟一个单句段。
- **章节长度不均**：一章 2000 字，下一章 800 字。
- **不完美的结尾**：不强行升华、不点题。留白（契诃夫）、意象（川端）、提问（萧伯纳）、语言死亡（贝克特）。
- **作者介入的不确定性**：使用自由间接引语让人物与叙述者声音混叠——AI 很少这样做，因为难。
- **语言的时代/地域杂质**：方言（哈代 t'ee、吐温 hain't）、行业语（卡夫卡的保险单）、金钱账目（巴尔扎克）——AI 倾向纯净语言，杂质是反 AI 重器。

## 四、去 AI 味检查清单

- [ ] 有无三连排比？有则破坏对称。
- [ ] 有无"与此同时/值得注意的是/综上所述"？有则删。
- [ ] 每章开头是否都用相同句式？换装置。
- [ ] 人物是否每次都理性回应？让他偶尔沉默、回避、答非所问。
- [ ] 是否每段都有句号收束的完整句？加入碎句、破折号、省略。
- [ ] 是否所有比喻都合理工整？加入一个"歪"的比喻（果戈理式离题）。
- [ ] 情感是否被直白宣告？改成让动作、意象、潜台词承担。
- [ ] 是否过度使用强调词（非常、极其、无比）？删去九成。

## 五、与 humanizer 技能协作

`/人话` 负责通用文本 AIGC 检测。文宗负责让文学文本从**结构层**就反 AI——不是改词，而是让句法、结构、情绪都不均匀。
