# 人物建构机制（Character Building）

大师人物不是"名字+性格+外貌"的堆砌，而是由**驱动引擎 + 弧线类型 + 镜像对位 + 外部细节**共同运转的机器。

## 一、原型库（从语料库提取的 20 种可复用原型）

### A 被命运碾压者
1. **被现实碾碎的理想主义者**：彭托皮丹《幸运的皮尔》、马丁·杜伽尔、法朗士《诸神渴了》的加默兰（真诚的恐怖者——"正因真诚才更可怕"）。
2. **上进者/失败者**：于连·索雷尔（进取型英雄）、拉斯蒂涅（野心与幻灭）、巴比特（反叛后缩回）。
3. **被礼法摧毁的农人**：苔丝（"纯"而非"罪"）、维尔加的马沃利亚家。
4. **气质与环境错位者**：包法利夫人（bovarysme——人渴望活成另一本小说里的人）。

### B 执念者
5. **财产执念者**：高老头（父爱如破产固定资产）、福尔赛（把妻子纳入产权清单）、王龙（把房产证换成田契）。
6. **复仇/偏执狂**：亚哈（把怨愤升维成反神学宣言："我若受辱，连太阳也敢击"）、基督山伯爵。
7. **秘密背负者**：吉勒鲁普的斯库勒（借洪水杀弟，水声=审判）、黛莱达的埃菲克斯（每天放一块石头，石堆成为罪孽的纪念碑）、温塞特的克里斯汀（终生背着害死父亲的十字架）。

### C 荒谬与异化
8. **荒谬英雄**：默尔索（情感疏离的诚实者）、里厄（非英雄的诚实者）。
9. **傻瓜原型**（20 世纪独创的道德装置）：吉姆佩尔（在骗局世界中选择相信以保全灵魂）、舒霍夫（一天未生病未挨打多喝一碗粥即好日子）、格朗（夜夜写同一句话的公务员）、莱尼（力大而无知的慈悲与毁灭同体）。
10. **科层受害者**：格里高尔、约瑟夫·K（与程序共谋）。
11. **异化边缘人**：侏儒（拉格奎斯特）、小丑（伯尔）、被贴上"堕落"标签者（莱尼）。

### D 激情与浪漫
12. **拜伦式英雄**：希斯克利夫、恰尔德·哈罗德、戈斯泰·贝林。
13. **感官放纵者/浪子**：曼家克里斯蒂安、奥尼尔家杰米、温塞特家埃兰德。
14. **反抗的女性**：诺拉（归还婚戒、宣布陌生人）、奈拉/苔蕾丝（自由逃亡）、凯蒂（结构性缺席的中心）、驹子与叶子（灵肉双生）。

### E 圣者与见证者
15. **圣者/愚者一体**：罗哈斯（圣洁被社会判为疯狂）、图什喇嘛。
16. **沉默的守护者/见证者**：磨坊老仆、玛格丽特（死后秘密才现形）。
17. **道德十字军**：贞德、克利斯朵夫、斯瓦瓦。

### F 历史与记忆
18. **历史撕裂者**：格里高利·梅列霍夫（红白之间四次摇摆）、日瓦戈（革命中保持精神独立的个体）。
19. **记忆型身份**：石黑史蒂文斯（人格溶解于职业制服）、莫迪亚诺居伊·罗朗（档案碎片拼装的人）。
20. **怪诞边缘视角**：奥斯卡（3 岁停止生长、尖叫碎玻璃）、西门闹（转世驴牛猪狗猴）、英惠（想成为树）。

## 二、驱动引擎（人物的燃料）

给人物装一个**核心驱动**，每次出场都被它反复刺激：

| 驱动类型 | 定义 | 例子 |
|---|---|---|
| 秘密/罪 | 一次隐秘的罪，压舱石 | 吉勒鲁普、黛莱达、温塞特、莫里亚克 |
| 执念 | 一个对象被神化 | 高老头、福尔赛、王龙、亚哈 |
| 气质错位 | 内在渴望 vs 外在环境 | 包法利、安娜 |
| 历史撕裂 | 时代在人物体内开战 | 梅列霍夫、日瓦戈、奈拉 |
| 记忆身份 | 我是我所记得的 | 石黑、莫迪亚诺、韩江 |
| 拒绝 | 以"不"为动力学 | 巴托比（prefer not to）、英惠（不吃肉） |
| 信仰/怀疑 | 在与神或意义的角力 | 巴拉巴、悉达多、塞特姆布里尼 |

**三处压迫点**：给人物设计 3 个会反复触发驱动的场景（一个物件、一个地点、一句口头禅），每次出场用它加深或考验人物。

## 三、弧线类型（弧线决定故事节奏）

1. **成长弧**（教育小说）：天真 → 受挫 → 觉醒 → 成熟（克利斯朵夫、悉达多、哈克）。
2. **堕落弧**：上升 → 幻灭 → 缩回/沉沦（巴比特、埃莱塞乌斯、盖尔瓦丝）。
3. **撕裂弧**（现代主义）：不"发展"而"撕裂"——二元自我（荒原狼的人性/狼性、悉达多分裂成无数自我）、历史受害者（梅列霍夫）。
4. **静默见证弧**：人物不行动，只承受，秘密在死后才现形（玛格丽特、老仆、格朗）。
5. **赎罪弧**：以"替他人死"为终点（贝林浪子回头、埃菲克斯死于石堆旁、克里斯汀死于照顾疫病、基隆皈依殉道）。
6. **老年弧**（罕见但有力）：从怨恨到崩溃忏悔（《蝮蛇结》67 岁吝啬鬼路易）。

## 四、镜像对位（高密度人物的构造法）

用一对相反相补的人物制造论辩场，代替单线性格塑造：
- 塞特姆布里尼/纳夫塔：理性与极权
- 托马斯/克里斯蒂安：清醒与放纵
- 艾萨克/吉斯勒：扎根与追逐
- 安托万/雅克：秩序与激情
- 驹子/叶子：肉体与精神
- 苔蕾丝/阿莉莎：自由逃亡与自我殉道
- 奥利维/克利斯朵夫：温婉与刚烈
- 天才/成功者：洪堡/西特林

对位轴可以是：欲望/需求、理性/疯狂、物质/精神、服从/反叛、记忆/遗忘。

## 五、外部细节即心灵（物质书写法）

- **环境即灵魂**：伏盖公寓、福尔赛的家具、曼家的账本餐具、王龙的田契、奈保尔的房子。
- **物即命运**：高老头的银器、银烛台、红字A、怀表（陀思妥耶夫斯基）、水轮、风中的芦苇、桥。
- **动作即性格**：巴托比的"prefer not to"、苔丝咬着草莓、格里高尔爬墙。

## 六、人物卡输出格式（`/文宗 人物`）

```
## <角色名> 人物卡
- 原型：<来自原型库>
- 核心驱动：<秘密/执念/气质错位/历史撕裂/记忆身份/拒绝/信仰>
- 欲望 vs 需求：<表面欲望> / <深层需求>
- 弧线类型：<成长/堕落/撕裂/静默见证/赎罪/老年>
- 镜像对位：<与谁成对，对位轴>
- 声线：<词汇域/句式/口头禅/沉默方式>
- 外部细节：<环境即心灵的 3 个具体物>
- 三处压迫点：<每次出场被什么反复刺激>
- 秘密：<读者何时得知，怎么得知>
```

## 七、人物验证清单

- [ ] 换一个人物把人物卡重写一遍，若性格自动改变 → 人物成立
- [ ] 把他放进三个任意场景，行为是否由同一驱动推出
- [ ] 对话声线是否能不看名字就辨认
- [ ] 弧线转折是否有明确的触发事件（不能跳跃）
- [ ] 是否有"没想到但合理"的选择（反模式化，见 anti-aigc.md）
