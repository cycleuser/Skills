# 时代文法 Eras

每个时代 = 一套世界观语法 + 声部倾向 + 人物模型 + 故事容器 + 语言禁忌。
写"X 年代的故事"不是写"发生在 X 年的故事"，而是用 X 时代的方式讲述。

## 1. 古典时代（古希腊罗马）

- **世界观语法**：命运与神意主宰；人反抗必遭惩罚（hybris→nemesis）；荣誉/美德/公民责任是核心价值。
- **声部**：庄严、程式化；史诗呼告（"女神，请歌唱"）；歌队抒情；格言警句。
- **人物模型**：类型化英雄 + 致命缺陷；等待者（守夜人）；殉道者（安提戈涅）。
- **故事容器**：史诗（in medias res）、悲剧（五幕/反讽）、喜剧（parabasis 打破第四面墙）、箴言（马可·奥勒留）、对话体（柏拉图）、轶事史（希罗多德）。
- **语言禁忌**：无"个人心理内省"概念——用行动、预言、命运陈述代替；避免现代心理学词汇。

## 2. 中世纪·文艺复兴（但丁→乔叟→薄伽丘→塞万提斯→莎士比亚）

- **世界观语法**：神/罪/赎；教会与骑士双重秩序；寓言思维——万事皆可象征。
- **声部**：说书人口吻；框架叙事（朝圣/避疫/讲故事）；双声戏仿（塞万提斯：骑士腔与打趣腔叠印）。
- **人物模型**：朝圣者/香客、骑士、局外人；"被文本创造的人物"（堂吉诃德——身份由阅读史生成）。
- **故事容器**：三韵体（但丁）、框架故事（十日谈/坎特伯雷）、骑士罗曼司戏仿（堂吉诃德嵌套三层叙事）、诗剧（莎士比亚五幕+独白追问）。
- **语言禁忌**：不用心理分析术语；用行动、独白、命运来表达内心。

## 3. 17-18 世纪（古典主义→启蒙→感伤）

- **世界观语法**：理性秩序 vs 激情冲动；社会契约；人性论；"人天然是自私的吗"。
- **声部**：讽刺解剖（斯威夫特/伏尔泰）；格言（拉罗什富科）；书信体自白（维特：情绪即句法）。
- **人物模型**：理性人/激情人；浪荡子；感伤青年（维特=过度感受者）；宗教怀疑者。
- **故事容器**：书信体小说、讽刺寓言（格列佛/老实人）、戏剧三一律、警句集、启蒙对话录。
- **语言禁忌**：避免宏大形容词堆砌；用讽刺、反语、对称句；不写上帝视角的内心全景。

## 4. 19 世纪（浪漫主义→现实主义→自然主义）

- **世界观语法**：进步叙事；阶级与金钱；民族与历史意识；"环境决定人"渐成主流。
- **声部**：浪漫——抒情主体、崇高、排比；现实——客观全知、道德而克制；自然——档案式记录。
- **人物模型**：拜伦式英雄 → 上进者/失败者（于连/拉斯蒂涅）→ 被环境碾压的可怜人（高老头、包法利）→ 遗传决定论的标本（左拉）。
- **故事容器**：家族编年史、成长小说、多卷本大河小说、连载章回+章末悬念、风俗研究（巴尔扎克人间喜剧）、短篇反转（莫泊桑）。
- **语言禁忌**：避免现代心理学术语、避免意识流（19 世纪内心用自由间接引语雏形 + 独白）；浪漫派禁用冷峻解剖，现实派禁用煽情。

## 5. 20 世纪上半叶（现代主义）

- **世界观语法**：时间相对性；记忆即真实；自我碎裂；"文明病了"（曼、艾略特）。
- **声部**：意识流；自由间接引语成主声；神话平行；碎片拼贴；冷静荒诞（卡夫卡办事腔）。
- **人物模型**：自我撕裂者（二元自我）；荒谬英雄；异化边缘人；傻瓜原型（吉姆佩尔、舒霍夫）；历史撕裂者（梅列霍夫、日瓦戈）。
- **故事容器**：一日之书；多视角拼贴；单日决胜（奥尼尔）；魔山式时间膨胀；审判/法庭结构。
- **语言禁忌**：禁止线性的、有秩序的因果叙事；禁止无歧义、无留白的结尾；语言可实验。

## 6. 20 世纪下半叶（后现代/魔幻/见证）

- **世界观语法**：宏大叙事失效；记忆不可靠；视角即政治；语言即意识形态（句法=世界观）。
- **声部**：元叙事自反；复调众声（作者隐身）；平白写作（无人称）；无句读长流（萨拉马戈）。
- **人物模型**：记忆型身份；受害者/见证者；怪诞边缘人（侏儒、动物视角）；系统压迫的受害者（库切身体作为承重墙）。
- **故事容器**：微型史诗（百年孤独）；证词口述史；档案寻根（莫迪亚诺）；寓言提纯（失明症漫记）；星座式组合（托卡尔丘克）。
- **语言禁忌**：禁止全知权威叙事；禁止单一视角垄断真相；可取消人名、取消标点、取消线性时间。

## 7. 21 世纪

- **世界观语法**：记忆与创伤互文；身份流动性；气候/生态/技术阴影；地方性重估。
- **声部**：极简留白（福瑟无句号长句）；身体意象重复变奏（韩江）；物件化哀悼。
- **人物模型**：镜像自我（福瑟两个同名画家）；沉默者；以拒绝为动力学的人（素食者）。
- **故事容器**：极简慢叙事；重复变奏；对象/意象小说（白、呼吸秋千）。
- **语言禁忌**：禁止戏剧化高潮堆砌；向留白与重复学习。

## 时代写法速查

| 你要写 | 时代 | 招牌手法 |
|---|---|---|
| 命运压迫个人 | 古典 | 悲剧反讽 + 歌队评述 |
| 罪与赎的长篇 | 中世纪/文艺复兴 | 寓言 + 朝圣结构 + 独白 |
| 社会体制的荒谬 | 17-18世纪 | 讽刺寓言 + 格言 + 书信体 |
| 个人与阶级的搏斗 | 19世纪 | 编年 + 全知道德 + 细节账簿 |
| 意识与时间的迷宫 | 20世纪上半 | 意识流 + 一日之书 + 多视角 |
| 历史创伤的众声 | 20世纪下半 | 复调证词 + 记忆不可靠 + 寓言 |
| 极简与留白 | 21世纪 | 省略 + 重复变奏 + 身体意象 |
