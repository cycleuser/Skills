# 流派工艺 Movements（20+ 流派）

每个流派：**工艺标记（craft markers）**——即该流派区别于他者的可操作特征。写某个流派，就是落实这些标记。

## 1. 古典主义（古典 Greek/Roman 与 17 世纪法式古典主义）

- **叙事**：清晰、节制、秩序；崇尚"合式"（decorum）——叙述者庄重理性，避免粗俗与无度。
- **人物**：类型化（典型而非个性），被命运/神意驱动；悲剧英雄有"致命缺陷"（hamartia）。
- **结构**：五幕/三一律（单一地点、单一日、单一情节）；俄狄浦斯式悲剧反讽（观众知、人物不知）。
- **标记**：庄严对称句、神话/历史典故、格言警句（拉罗什富科：悖论浓缩）。
- **参照**：索福克勒斯《俄狄浦斯王》、埃斯库罗斯《阿伽门农》、欧里庇得斯《特洛伊妇女》、拉辛、高乃依。

## 2. 浪漫主义（Romanticism）

- **叙事**：抒情主体强烈在场；叙述者介入、热情、崇高（sublime）；自我即宇宙。
- **人物**：拜伦式英雄（孤独、反叛、背负罪孽、魅力四射）；被放逐者；艺术家/诗人作为世界立法者（雪莱）。
- **结构**：激情主导，事件服务于情绪的涨落；流浪/追寻；自然作为灵魂的对应物。
- **标记**：通感与感官密集（济慈夜莺颂）；自由地抒情、感叹、排比（雨果、拜伦）；自然=心灵的镜子（华兹华斯"from these forms of beauty"）。
- **参照**：拜伦《恰尔德·哈罗德》、雪莱、济慈、雨果《悲惨世界》、夏多布里昂、拉马丁。

## 3. 现实主义（Realism）

- **叙事**：冷静客观的第三人称，全知但克制；莫泊桑式干净；叙述者透明或道德但不下场（比昂松、刘易斯、赛珍珠）。
- **人物**：社会坐标 + 道德档案定义；人被环境塑造；生活细节精确（金钱、衣服、菜单）。
- **结构**：编年体/因果链；日常时间的节律；反高潮（契诃夫式"什么都没发生却天翻地覆"）。
- **标记**：具体名词、精确数字、对话承担阶级与社会信息；避免夸张与巧合。
- **参照**：托尔斯泰、巴尔扎克、福楼拜（其"现实"是显微镜下的）、莫泊桑、比昂松、刘易斯《大街》。

## 4. 自然主义（Naturalism）

- **叙事**：医生/实验员式的记录声（左拉：登记症状、酒精浓度、当票颜色）；"条件"代替"命运"。
- **人物**：遗传 + 环境 + 时代三重决定论，自由意志极弱（盖尔瓦丝、库波）；阶级与生物性即宿命。
- **结构**：研究式展开——家族病史、堕落的阶段、医学判定；冷酷实证的结局。
- **标记**：行业术语、档案式罗列、以"样本"眼光写人。
- **参照**：左拉《小酒店》、霍普特曼《织工》（方言写真实）、吉勒鲁普。

## 5. 象征主义（Symbolism）

- **叙事**：暗示而非直说；音乐性优先（魏尔伦"音乐先于一切"）；"感应"（correspondances）系统。
- **人物**：诗人/通灵者（voyant）；象征物（天鹅、青鸟、水轮）代替性格。
- **结构**：非叙事，意象的冥想螺旋；情绪弧线而非情节弧线（泰戈尔《吉檀迦利》）。
- **标记**：跨感官联觉（元音-颜色：兰波）；模糊性与"微差"（nuance）；物象承载灵魂（梅特林克）。
- **参照**：波德莱尔《恶之花》、兰波《醉舟》、魏尔伦、梅特林克《青鸟》、泰戈尔、叶芝、里尔克。

## 6. 心理小说（Psychological Novel）

- **叙事**：意识为舞台；叙述者像心理显微镜（茨维格）；曼的"冷"是解剖台式的仁慈。
- **人物**：由内在矛盾、压抑、秘密构成；道德困境即人物（埃切加赖、莫里亚克、温塞特）。
- **结构**：情感浪潮式推进（积累→爆发→退潮）；转折点是心理事件而非外部事件。
- **标记**：内心独白、心理动词、长句累积到情感释放。
- **参照**：茨维格、托马斯·曼、莫里亚克《蝮蛇结》、温塞特、奥尼尔《长日入夜行》。

## 7. 现代主义 / 意识流（Modernism / Stream of Consciousness）

- **叙事**：意识流——班吉的纯感官层（时间在触觉气味中混叠）、昆丁的意象编码（钟表=时间暴力）、伍尔夫的分号抒情、乔伊斯的无标点流。
- **人物**：自我撕裂与身份危机；记忆岩层而非性格剖面；傻瓜/天才/异化边缘人。
- **结构**：一日之书（尤利西斯/达洛卫夫人）；碎片拼贴；神话平行（提瑞西阿斯、奥德赛、教堂式结构）；时间本体论改造（"过去与未来都存在于现在"）。
- **标记**：自由间接引语成主声；句法实验；多视角；典故网络（艾略特）。
- **参照**：乔伊斯《尤利西斯》、伍尔夫《达洛卫夫人》、福克纳《喧哗与骚动》、艾略特《荒原》、普鲁斯特。

## 8. 表现主义（Expressionism）

- **叙事**：扭曲现实以表达内心；梦魇、变形、碎片；形式对口主题（独裁的梦魇感）。
- **人物**：不是人而是情绪的载体（尖叫、面具、侏儒视角）。
- **结构**：压迫-爆发-崩塌的单一强烈轨迹。
- **标记**：夸张、噩梦逻辑、光影暴力。
- **参照**：阿斯图里亚斯《总统先生》、斯特林堡《朱莉小姐》（厨房爆炸）、奥尼尔（独白的抒情密度）。

## 9. 荒诞派（Absurdism / Theatre of the Absurd）

- **叙事**：重复、停滞、语言失效；物的持存（帽子、萝卜、垃圾桶）。
- **人物**：物化的人；等待者（戈多）。
- **结构**：第二幕复制第一幕；"决定了离开却没有动"；结尾不是结局。
- **标记**：空洞对话打转、无意义重复、"结局已定只是未完成"。
- **参照**：贝克特《等待戈多》《终局》、品特（停顿与不可知威胁）、汉德克《骂观众》。

## 10. 存在主义（Existentialism）

- **叙事**：哲学独白；荒谬语法（加缪开篇"今天，妈妈死了。也许是昨天"——句法即荒谬）。
- **人物**：荒谬英雄（默尔索：情感疏离的诚实者；里厄：非英雄的诚实者）；处境中的选择者（萨特）。
- **结构**：处境机器（《禁闭》密室）；审判结构重写罪行定义；叙述者最后自曝。
- **标记**：生理性白描、冷漠句法、"宇宙温柔的冷漠"。
- **参照**：加缪《局外人》《鼠疫》、萨特《恶心》《禁闭》、帕斯《孤独的迷宫》。

## 11. 魔幻现实主义（Magic Realism）

- **叙事**：神话世界观与现实暴力叠进同一平面（阿斯图里亚斯《玉米人》）；循环时间。
- **人物**：家族史承载文明史；超自然被当作家常（鬼魂、转世、预写羊皮卷）。
- **结构**：微型史诗；家族七代；"预先写就的破译"（百年孤独羊皮卷）；轮回框架消化阶级斗争（莫言）。
- **标记**：民间生命力语言、狂欢化感官（莫言：气味/血腥/高粱/乳汁）、民间说书人腔调。
- **参照**：马尔克斯《百年孤独》、莫言《生死疲劳》、莫里森《宠儿》（鬼魂=创伤）。

## 12. 新小说 / 立体主义叙事（Nouveau Roman）

- **叙事**：感官流句子、无情节；感知即结构（西蒙《弗兰德公路》立体主义叠印战前/溃败/战后）。
- **人物**：退场或物化；叙述者冷。
- **结构**：句法随感知涨落；时间碎片。
- **参照**：克劳德·西蒙、罗伯-格里耶（库内未收，以西蒙为准）。

## 13. 极简主义（Minimalism）

- **叙事**：删尽装饰；短句；日常暗流（门罗：细节即命运）。
- **人物**：普通人；情绪在时间断层中翻转。
- **结构**：短篇的时间断层与"未遂逃离"；单意象贯穿（韩江《白》）。
- **标记**：克制、留白、省略即暴力。
- **参照**：门罗、福瑟（无句号长句的"慢文学"——其"极简"是形式的）、辛波斯卡（诗）、海明威。

## 14. 后现代 / 元叙事（Postmodern / Metafiction）

- **叙事**：叙述者自反、打破第四面墙；人称哲学化（高行健 我/你/他切换）；笔记分裂自我（莱辛四色笔记）。
- **人物**：记忆型身份；版本化自我（福瑟两个同名画家）。
- **结构**：多视角独白旋转（帕慕克《我的名字叫红》：死者/凶手/画/狗轮流独白）；无秩序之书（纪德）；环形诗（帕斯《太阳石》584 行首尾相接）。
- **标记**：元小说机关、互文、戏仿、档案化。
- **参照**：帕慕克、莱辛《金色笔记》、高行健《灵山》、纪德《伪币制造者》、博尔赫斯（库未收）、卡尔维诺。

## 15. 纪实 / 见证文学（Testimony Literature）

- **叙事**：复调众声，作者隐身（阿列克谢耶维奇：数百人自说自话，不调解不裁决）；诗化隐喻收纳档案（赫塔·米勒：饥饿天使）。
- **人物**：受害者/见证者；"一天=一生"的局部放大（索尔仁尼琴：稀粥/金属片/没挨打即尊严）。
- **结构**：口述拼接、证词档案、集体灵魂史。
- **标记**：零度拼贴、具体名字与面孔对抗抽象统计、拒绝意义化（凯尔泰斯）或鬼魂化（莫里森）。
- **参照**：阿列克谢耶维奇、索尔仁尼琴《古拉格群岛》、凯尔泰斯、赫塔·米勒、奈莉·萨克斯。

## 16. 后殖民（Postcolonial）

- **叙事**：权力关系倒置（戈迪默《七月的人民》主仆颠倒）；仪式冲突（索因卡）；古典史诗的加勒比重写（沃尔科特）。
- **人物**：殖民/迁移中的身份悬置者（奈保尔：房子=尊严）；身体作为历史承重墙（库切《耻》）。
- **结构**：逃离=投靠的反讽闭环（古尔纳《天堂》）；寻根之旅（莫里森《所罗门之歌》）。
- **参照**：奈保尔、库切、古尔纳、戈迪默、索因卡、沃尔科特、马哈福兹。

## 17. 自传体平白写作（Autofiction / écriture plate）

- **叙事**：无人称/集合人称（"我们""她"）；私人即时代（埃尔诺：超市/电视/商品目录作分期工具）。
- **人物**：以物件对照写阶级（父亲读连环画 vs 女儿读普鲁斯特）。
- **结构**：记忆切片；时间分期；非虚构-虚构边界取消。
- **参照**：埃尔诺《悠悠岁月》《位置》、安妮·卡森（库未收）。

## 18. 教育小说（Bildungsroman）

- **叙事**：第三人称但贴着主角内在成长（歌德《威廉·迈斯特》的教养距离）。
- **人物**：学徒/朝圣者；导师与象征塑造人格（黑塞：河流/Om/沉默导师）。
- **结构**：内在成长经线 × 外部社会纬线；出走-试炼-领悟。
- **参照**：歌德、黑塞《悉达多》、罗曼·罗兰《约翰·克利斯朵夫》、乔伊斯《青年艺术家画像》。

## 19. 地域小说（Regional Novel）

- **叙事**：方言/地理即身份（哈代：经纬度精确 + 方言对照）；集体记忆叙述（维尔加：合唱式民间叙述）。
- **人物**：人与土地的关系定义人（黛莱达：撒丁岛；西兰帕：芬兰白夜；莱蒙特：波兰四季）。
- **结构**：四季循环作脊椎；仪式（葬礼/春祭/圣诞）作节点；个人激情被集体节律冲刷。
- **标记**：农事/节气/人情世故的精确掌握；大地拟人。
- **参照**：哈代、黛莱达、莱蒙特《农民》、西兰帕、维尔加、凯瑟、莫言（高密东北乡）。

## 20. 家族编年史（Family Chronicle）

- **叙事**：全知但有距离；时间跨度数代人；以家族败亡承载文明史（曼、高尔斯华绥、福克纳、马尔克斯）。
- **人物**：世代类型反复（财产意识、天才与凡子对位）；物质清单即灵魂（曼的账本）。
- **结构**：兴衰四代；开头-瓜分-终结；"不要卖地"式首尾对置（赛珍珠《大地》）。
- **参照**：托马斯·曼《布登勃洛克一家》、高尔斯华绥《福尔赛世家》、赛珍珠《大地》、马哈福兹《开罗三部曲》、马尔克斯。

## 21. 讽刺 / 讥诮小说（Satire / Irony）

- **叙事**：反讽是标尺（奥斯汀平衡句）；观念即冲突（萧伯纳：对话即行动）；讥诮（斯威夫特、伏尔泰、法朗士）。
- **人物**：类型化的荒谬（企鹅=人类；笨蛋/伪君子/势利者）。
- **结构**：伪史学/寓言外壳（《企鹅岛》）；赌局/赌约结构（《卖花女》）；观念剧终场向观众提问。
- **标记**：假正经与戏仿（塞万提斯双声）；夸张到荒诞的细节。
- **参照**：奥斯汀、萧伯纳、法朗士、塞万提斯、斯威夫特、马克·吐温、果戈理。

## 22. 童话与寓言（Fairy Tale / Fable）

- **叙事**："很久很久以前"程式 + 成人讥诮藏在平实里（安徒生：皇帝在更衣室）；面向读者的直接称呼。
- **人物**：局外儿童/被放逐者；傻瓜与觉醒者。
- **结构**：得而复失的追寻循环（青鸟）；三次重复（大臣-官员-人群递增）；"然后、然后"平推节奏 + 意外收束。
- **标记**：物件拟人、元素道德、儿童能懂的话说成人残酷。
- **参照**：安徒生、格林兄弟、伊索、拉封丹、梅特林克《青鸟》。

## 23. 历史小说（Historical Novel）

- **叙事**：以物为叙事轴（安德里奇《德里纳河上的桥》：桥见证 400 年，炸桥即时代终结）；宏观历史为微观命运提供框架（曼佐尼）。
- **人物**：时代洪流中的个体；历史压力下的道德选择（显克微支、温塞特）。
- **结构**：编年体；亲历者+文献双轨（丘吉尔）。
- **参照**：安德里奇、曼佐尼、显克微支、温塞特、托尔斯泰（历史层）。

## 24. 侦探/悬疑（Mystery / Suspense）

- **叙事**：翻页冲动机器（大仲马：每章留钩）；延迟解码（康拉德：先印象后解释）。
- **人物**：骗局与误认；复仇者分期付款。
- **结构**：章末悬念、错认、意外身世；开篇即"船、死者、年轻主人"三件事一句对白。
- **参照**：大仲马、柯南·道尔、爱伦·坡（效果统一）、莫泊桑（欧·亨利式反转）。

## 流派选择速查

| 想要的效果 | 选流派 |
|---|---|
| 道德审判 + 内心自审 | 现实主义/心理小说（托尔斯泰） |
| 思想交锋 + 神经张力 | 心理小说/存在主义（陀思妥耶夫斯基） |
| 什么都没发生却天翻地覆 | 现实主义反高潮（契诃夫） |
| 梦魇与变形 | 表现主义 |
| 循环时间 + 神话家庭史 | 魔幻现实主义 |
| 记忆即本体 | 现代主义/后现代 |
| 复调口述史诗 | 纪实见证文学 |
| 哲学对话替代情节 | 古典主义/存在主义 |
| 感官与情绪密林 | 浪漫主义/象征主义 |
| 阶级解剖 | 自然主义/讽刺 |
| 极简留白 | 极简主义 |
