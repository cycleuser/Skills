# 场景与对话技艺（Scene & Dialogue）

## 一、场景建构（Scene Craft）

### 场景的四种功能
1. **推进**：事件改变人物状态/关系。
2. **揭示**：深层秘密逐层露出。
3. **变调**：同一情境反复出现，情绪升级（变奏）。
4. **暂停**：抒情/意象/离题（雨果的历史章、托尔斯泰的风景）——给读者呼吸，为主题存档。

### 场景的解剖学（每场都有）
- **空间即心情**：环境的细节承载人物心理（伏盖公寓=命运的廉价；厨房=阶级爆炸点）。
- **时间压力**：一个真实/心理的时间锚（钟、马车、关门声）让场景有重力。
- **在场者的凝视**：谁在看？看的人带着什么偏见？被看者如何表演？（Hester 的刑台=社会审判第一景）
- **权力的现场化**：一场戏就是一个权力关系的显微镜（驯鞭/夺鞭、审讯室哲学决斗、评奖会情话被市声打断）。
- **一个动作/物件定调**：诺拉偷吃杏仁饼又擦嘴（撒谎的甜蜜）、格里高尔爬墙（异化的开始）。

### 场景开场技术（从语料库学的装置）
- **锚定统计再拉近**（巴尔扎克）：先簿记式数字，再镜头推向人物。
- **一句话引爆**（斯特林堡）："今晚朱莉小姐又疯了，彻底疯了。"
- **景观=叙事轴**（安德里奇）：从桥看河、看时代、看人。
- **物件开镜**（韩江/普鲁斯特）：从白布/玛德莱娜开始，进入记忆。

### 场景收束技术
- **无声动作收束**（易卜生）：摔门声替台词发言。
- **意象收束**（川端）：银河倾泻=一切归白。
- **延迟解码**（康拉德）：先给印象，后给解释。
- **悬置**（契诃夫）：一切都正要开始，故事却结束了。

## 二、对话技艺（Dialogue Craft）

### 五种对话功能
1. **潜台词**（契诃夫/易卜生）：说的不是心里想的。"非洲现在该热得冒烟吧"掩盖离别之痛。
2. **意识形态交锋**（陀思妥耶夫斯基）：一开口就抛命题，思想即行动。
3. **道德论证**（托尔斯泰/萧伯纳）：伦理立场摊牌，恶人也有真诚逻辑。
4. **社会表演/阶级标识**（巴尔扎克/狄更斯/哈代）：话语即身份表格；方言对照展示社会落差。
5. **心理试探**（詹姆斯）：几乎不说事，只说"反应"——"为了纯粹的恐惧？""为了可怖——可怖！"

### 对话三律
1. **人物声线不可混淆**：每人有词汇域/句式/口头禅/沉默方式。不看名字能辨认。
2. **对话推进关系**：每次对话结束，关系状态比开始时有变化（哪怕微小）。
3. **对话承担信息**：信息藏在省略与顾左右中，而非直接供述（麦高芬法则）。

### 对话中的人物不变量
- 契诃夫式：人物回避真正的议题，用天气/无关话题掩护。
- 陀思妥耶夫斯基式：人物无视寒暄，直接互掷命题。
- 奥斯汀式：反讽——班纳特先生"你想告诉我，我不反对听"，对话即拆台。
- 福楼拜式：自由间接混入对话——人物话外之想滑进叙述。

### 叙事/对话的边界技术
- 乔伊斯：破折号仿法文印刷 + 叙述切入打断对话（一个词即内心联想）。
- 伍尔夫：引号内外混融，对话被括号与自由间接环绕，视角在说话人之间跳切。
- 福克纳：同一事件由不同感官系统各自重放（钟/水/忍冬花香）。

## 三、经典场景类型（母题）

- **法庭/审判场景**：Hester 刑台、圣女贞德审判、罪与罚忏悔、K 的审判——把个人良知变成公共辩论。
- **忏悔场景**：冉·阿让对主教（"你怎么知道我不是杀人犯？"——"那是上帝操心的事"）。
- **死亡场景**：高老头之死（认错人、被市侩催促"汤要凉了"）、艾玛之死（器官逐一点名的圣油礼）。
- **求婚场景**：达西两次求婚——戏剧性反讽的顶点。
- **摔门场景**：玩偶之家结尾。
- **决斗/对峙场景**：斯特林堡的驯鞭；审讯室哲学决斗（罪与罚）。
- **群体集会场景**：织工的《血腥法庭》之歌传递；评奖会的情话与公告并置蒙太奇。
- **顿悟场景**：都柏林人《死者》结尾雪景；悉达多河边沉默。

## 四、场景/对话验证清单

- [ ] 每场有明确功能（推进/揭示/变调/暂停）
- [ ] 对话符合人物声线且推进关系
- [ ] 至少有一处"言外之意"（潜台词）
- [ ] 场景收束用了无声动作/意象/悬置/延迟解码之一
- [ ] 避免"解释性对话"（人物说对方已知之事）
