# 故事工程（Story Engineering）

故事骨架 = 可复用的叙事结构母型。写作时：**选骨架 → 定时间容器 → 嵌入主题 → 埋收伏笔**。

## 一、骨架目录（18 种经过验证的叙事骨架）

### 1. 成长小说（Bildungsroman）
示例：克利斯朵夫、悉达多、青年艺术家画像、幸运的皮尔（幻灭版）、魔山（反写：成长是向下的）。
结构：出走 → 试炼 → 领悟；内在成长经线 × 外部社会纬线。

### 2. 兴衰四代（Family Chronicle）
示例：布登勃洛克、福尔赛世家、大地、蒂博一家、开罗三部曲、百年孤独。
结构：创始人崛起 → 二代守成 → 三代瓜分/衰败 → 终结；"不要卖地"式首尾对置。

### 3. 旧秩序衰亡
示例：黛莱达的没落贵族、契诃夫的俄国庄园、织工的集体反抗、乡村的俄国。
结构：以颓败庄园/宅邸为空间轴心；个人悲剧 = 时代判决。

### 4. 单日/单夜决胜
示例：奥尼尔《长日入夜行》（三代旧伤压缩进一个夏日）、西兰帕（一生放进一个白夜）、达洛卫夫人、尤利西斯。
结构：一天的时间锚（日出/钟声/深夜）；倒叙层层剥开秘密；光之明暗即情节推进器。

### 5. 四季循环（大地律动）
示例：莱蒙特《农民》、汉姆生《大地的成长》。
结构：以春耕/夏长/秋收/冬藏为脊椎；仪式作节点；个人激情被集体节律冲刷。

### 6. 赎罪弧
示例：贝林浪子回头、埃菲克斯死于石堆旁、复活（聂赫留朵夫）、基隆皈依。
结构：罪 → 逃 → 追（内疚）→ 替他人死/自我牺牲为终点。

### 7. 问题剧对垒（观念冲突）
示例：萧伯纳《圣女贞德》（个人良知 vs 制度权威的公开辩论）、卖花女（赌局结构）、易卜生问题剧。
结构：对垒双方各执其理；终场向观众抛出问题而非给答案。

### 8. 循环寓言（追寻-得-失）
示例：梅特林克《青鸟》、企鹅岛（文明从暴力开国到自我毁灭）。
结构：得而复失；循环重来；主题在"重复"中显形。

### 9. 荒谬非情节
示例：等待戈多（第二幕复制第一幕）、终局。
结构：停滞；语言打转；物的持存；"决定了离开却没有动"。

### 10. 复调多声部
示例：我弥留之际（15 叙述者/59 段独白）、女士及众生相（证词拼图）、古拉格群岛、二手时间。
结构：众声自组织真相；作者隐身；声音之间不调解不裁决。

### 11. 记忆小说
示例：长日将尽、暗店街、弗兰德公路、悠悠岁月。
结构：回溯为骨架，行动是记忆触媒；记忆不可靠生成悬念；开放结局。

### 12. 证词/口述史
示例：二手时间、切尔诺贝利的悲鸣、无命运的人生。
结构：独白并置；"一天=一生"的局部放大；具体名字与面孔对抗抽象统计。

### 13. 微型史诗
示例：百年孤独（七代家族史+预写羊皮卷）、红高粱家族、漫歌集、静默的顿河。
结构：家族/民族史被神话装置收纳；循环时间；开篇即终局的倒装（羊皮卷）。

### 14. 旅程/公路结构
示例：悉达多、灵山（地理行旅=精神地图）、小毛驴与我（漫游体散文诗）、哈克贝利·费恩（筏上旅程）、沙漠（古今双线对位）。
结构：河流/道路 = 情节推进；每个停靠点 = 一个主题单元；终点 = 顿悟或反讽。

### 15. 档案/侦探式寻根
示例：暗店街（旧照片/旧地址回溯身份）、我的名字叫红（谋杀案作脚手架）、毕司沃斯先生的房子。
结构：一条线索（物/人/信）牵引；层层开掘；身份始终悬置为"可能"。

### 16. 物件/意象小说
示例：韩江《白》（白色意象构筑哀悼空间）、呼吸秋千（饥饿天使拟物化存在）、桥（叙事轴=一座桥，400 年历史）、水轮（命运报幕员）。
结构：一个物件/意象贯穿；物件即结构；情感由意象收束而非议论。

### 17. 寓言/假面寓言
示例：蝇王、失明症漫记、别让我走、撒旦探戈、老人与海（写实表层叠圣经受难结构）。
结构：社会批判剥离具体政体进入宇宙级提纯；寓言外壳 + 写实内核；总安插一个清醒支点（看得见的人/观察者医生）。

### 18. 环形/重复变奏
示例：太阳石（584 行首尾相接）、荒原（碎片对抗碎片）、七部曲（两个同名画家的版本对位）、野鸢尾（诗循环）。
结构：结尾回到开头；重复不是复读而是变奏；时间被取消或循环。

## 二、时间容器（同一副骨架装进不同时间 = 不同作品）

| 容器 | 用途 | 代表 |
|---|---|---|
| 单日/单夜 | 压缩，倒叙剥层 | 奥尼尔、伍尔夫、乔伊斯 |
| 四季 | 循环，仪式节律 | 莱蒙特、汉姆生 |
| 一生 | 成长/赎罪 | 克利斯朵夫、悉达多 |
| 四代 | 家族兴衰 | 曼、高尔斯华绥、马尔克斯 |
| 循环 | 寓言、荒诞 | 百年孤独、等待戈多 |
| 一段历史 | 见证/史诗 | 桥、静默的顿河、漫歌集 |
| 一个时刻的展开 | 极简 | 门罗、福瑟 |

## 三、主题嵌入（让主题成为结构而非说教）

1. **意象即结构**：把主题压进一个反复出现的意象（风中的芦苇=被命运摆布的意志；桥=历史；银河=徒劳的美）。
2. **辩证对置**：一对相反力量在场，主题从夹缝长出（理性/疯狂、健康/疾病、艺术/商业）。
3. **母题法（leitmotif）**：一段旋律/一句歌词/一个物件反复出现随人物变调（血腥法庭之歌传给新一代）。
4. **句法即世界观**：萨拉马戈无句读=语言民主化；加缪冷漠句法=荒谬语法；卡夫卡办事腔=科层异化。
5. **首尾对置**：开头的承诺在结尾兑现或背叛（"不要卖地"→结尾儿子商议卖地）。
6. **结局装置**：叙述者最后自曝（鼠疫）、开放式提问（圣女贞德复活问"你们愿意我回来吗"）、意象收束（雪国银河倾泻）、语言死亡（戈多）。

## 四、伏笔与回收

- 每章至少埋 1 个新伏笔，回收 0-2 个旧伏笔。
- 让部分伏笔**提前**回收（读者意外）、部分**延后**（读者等待），避免均匀分布——生活的不规则感。
- 回收伏笔时回溯埋设章节。
- 连续 5 章未回收 → 标"⚠待处理"。

## 五、分幕大纲输出格式（`/文宗 结构`）

```
## 《标题》故事骨架
- 骨架：<选自骨架目录 + 参照作品>
- 时间容器：<单日/四季/一生/四代/循环/一段历史>
- 三/五幕结构：
  - 第一幕 <目标>：<开场装置 + 人物引入 + 激励事件>
  - 第二幕 <升级>：<冲突升级 + 第一次转折 + 新认知>
  - 第三幕 <转折>：<中点反转/揭示 + 人物弧线转折触发>
  - 第四幕 <下行>：<代价显现 + 旧秩序崩塌>
  - 第五幕 <收束>：<结局装置：对置/意象/提问/语言死亡>
- 主题嵌入：<意象即结构的落点 + 辩证对置轴>
- 伏笔清单：<埋设点/回收点/方式>
- 结尾钩子/哲学落点：<读者离开后的余味>
```

## 六、结构验证清单

- [ ] 骨架是否匹配题材气质（见 movements.md 速查表）
- [ ] 时间容器是否发挥到极致（压缩/膨胀/循环）
- [ ] 每幕是否有明确升级或转折（拒绝"平铺直叙"）
- [ ] 主题是否结构化嵌入（有 1 个中心意象或对置轴）
- [ ] 是否故意打破一处"工整"（反 AI，见 anti-aigc.md）
