# 专利文书反AIGC检测规则

专利交底书和权利要求书面临专利审查员的AIGC审查。专利文书本身是正式法律文件，不用口语化，但必须避免AI生成的机械模式。

## 核心原则

专利文书不是学术论文也不是博客。它的语言必须精确、有法律效力，但绝不能读起来像模板填充。每一句话都必须传达具体的技术信息，而非空洞的套话。

## 专利文书AIGC高发模式

### 1. 交底书中的AI套话（权重40%）

禁止出现的表达：

```
❌ 禁止：
"本发明的目的在于提供一种..." → 用具体技术问题替代
"综上所述，本发明具有以下有益效果..." → 直接陈述技术优势
"本领域技术人员可以理解..." → 写明具体理解内容
"不难看出..." → 直接给出结论
"需要说明的是..." → 直接写明
"优选地，..." → 写明优选理由和具体参数范围
"进一步的，..." → 用逻辑关系替代机械递进
```

替换策略：

```
✅ 正确：
- 不写"本发明旨在解决XX问题"，而是直接描述现有技术的具体缺陷：
  "现有方案在X条件下Y指标仅达到Z，无法满足W场景的实时性要求"
- 不写"具有以下有益效果"，而是逐条写明技术指标对比：
  "本方案在X条件下将Y从Z1提升至Z2，提升比例W%"
- 不写"本领域技术人员可以理解"，而是写出具体理解内容：
  "在步长α=0.01~0.1的范围内，梯度下降收敛速度提升3~7倍"
```

### 2. 权利要求中的机械排列（权重25%）

权利要求书的AIGC痕迹表现为格式过于工整、限定条件对称堆砌。

```
❌ 禁止：
权利要求1和权利要求2结构完全相同只替换关键词
所有从属权利要求用"根据权利要求X所述的..."开头
限定条件按相同维度（温度、压力、浓度）机械排列
```

```
✅ 正确：
- 不同权利要求从不同技术维度限定，各有侧重
- 从属权利要求的引用关系反映真实的技术依赖，而非机械排列
- 限定条件从核心创新出发层层递进，每层限定有独立的技术意义
```

### 3. 实施方式中的空洞描述（权重20%）

具体实施方式部分最容易出现"正确但空洞"的AI生成内容。

```
❌ 禁止：
"本领域普通技术人员可以根据实际需要进行调整"
"以上所述仅为本发明的较佳实施例"
"应当理解，本发明不限于上述实施例"
空洞罗列：温度50-200℃、压力1-10MPa（无依据范围）
```

```
✅ 正确：
- 每个参数范围必须附有依据："温度80-120℃，该范围基于实验数据确定，低于80℃反应转化率<60%，高于120℃副产物占比>15%"
- 每个实施例必须包含可操作的具体步骤和具体参数
- 替代方案必须写明技术差异而非"可根据需要选择"
```

### 4. 背景技术中的"文献综述体"（权重15%）

```
❌ 禁止：
"近年来，XX技术得到了广泛关注"
"随着XX的快速发展，XX技术成为研究热点"
"目前，XX技术在XX领域得到了广泛应用"
"然而，现有技术仍然存在不足"
```

```
✅ 正确：
- 直接指出具体现有技术的具体缺陷："方案A在X条件下Y指标为Z%，无法满足W的需求"
- 引用具体专利号和具体技术细节，而非笼统描述
- 技术问题的表述应精准到可量化的缺失
```

## 专利文书专业表达的反AI策略

### 策略1：具体参数替代抽象描述

```
AI: "该方法的处理效率较高"
专业写法: "该方法在10000条/秒的输入速率下，平均响应时间<50ms，吞吐量较基准方案提升40%"
```

### 策略2：技术逻辑替代机械递进

```
AI: "首先，进行数据采集；其次，进行数据预处理；再次，进行特征提取；最后，进行模型训练"
专业写法: "数据采集模块获取原始传感器信号（采样率≥1kHz），经预处理滤除工频干扰后，特征提取模块从时频域提取12维特征向量，输入训练好的分类模型"
```

### 策略3：对比数据替代虚泛表述

```
AI: "本发明具有突出的实质性特点和显著的进步"
专业写法: "本方案在MIT-BIH数据集上的敏感性为98.7%，较CN1156789A方案的91.2%提升7.5个百分点，误检率从8.5%降至1.3%"
```

### 策略4：限定理由替代无根范围

```
AI: "温度为50-300℃"
专业写法: "温度为120-180℃；温度降至120℃以下时催化剂活性降至初始值的42%，升至180℃以上时副产物选择性超过30%"
```

## AIGC率检测清单

### 交底书检测项

- [ ] 是否出现"本发明的目的在于..."套话？→改写为具体技术问题描述
- [ ] 是否出现"综上所述"或"总而言之"？→删除，直接陈述技术效果
- [ ] 有益效果部分是否有具体数据对比？→补充实验数据
- [ ] 参数范围是否有依据？→补充实验依据
- [ ] 实施方式每段是否传达了独特技术信息？→删除空洞段落
- [ ] 权利要求是否机械排列？→打破对称，按技术逻辑组织
- [ ] 背景技术是否引用了具体专利号？→补充具体引用

### AIGC率评分标准

- 0-15%：专业自然，无AI痕迹
- 16-30%：基本合格，有少量可优化项
- 31-50%：需修改，AI痕迹较明显
- 51-70%：需重写，大量AI模式
- 71-100%：需废弃重写，完全AI风格
