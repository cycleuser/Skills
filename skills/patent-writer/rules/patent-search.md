# Patent Search Methodology

## Overview

Patent search is critical for determining whether your patent will pass substantive examination.

### What is Patent Search?

- **Patent search**: Searching for patents, literature, and publicly available content similar to your invention
- **Patent analysis**: Comparing found materials to determine if they cover your technical points

## Search Strategy

### Step 1: Define Search Scope

```
1. Identify key technical terms
2. Define technical field
3. List competitor companies
4. Determine time range (usually last 20 years)
```

### Step 2: Choose Search Platforms

| Platform | Access | Coverage |
|----------|--------|----------|
| 国知局 (CNIPA) | Registration required | Chinese patents |
| 上海知产平台 | No login | Chinese patents |
| Google Patents | Free | Global patents |
| USPTO | Free | US patents |
| EPO Espacenet | Free | European patents |

### Step 3: Construct Search Query

```
# Example search query structure

# Keywords
(keyword1 OR keyword2) AND (keyword3 OR keyword4)

# Classification
CPC classification OR IPC classification

# Assignee
assignee:(company_name)

# Date range
publicationdate:[20000101 TO 20241231]
```

### Step 4: Filter and Analyze

```
1. Remove irrelevant results
2. Categorize by relevance
3. Identify closest prior art
4. Document key findings
```

## Analysis Framework

### Three Property Check

```
1. Novelty Check
   - Is the invention new?
   - Has it been disclosed anywhere before?
   - Check: Publications, patents, products, presentations

2. Inventiveness Check
   - Is it non-obvious?
   - Would a skilled person easily derive it?
   - What is the technical advancement?

3. Utility Check
   - Can it be manufactured?
   - Does it solve a technical problem?
   - Is it reproducible?
```

### Blocking Risk Assessment

```
Risk Level: HIGH
- Prior art covers key features
- Cannot easily design around
- Recommend: Abandon or significantly modify

Risk Level: MEDIUM
- Some overlap with prior art
- Possible design-around options
- Recommend: Modify claims, emphasize differences

Risk Level: LOW
- Minimal overlap with prior art
- Clear novelty and inventiveness
- Recommend: Proceed with filing
```

## Common Search Mistakes

1. **Too narrow** - Missing relevant prior art
2. **Too broad** - Overwhelming results
3. **Wrong keywords** - Missing key terms
4. **Ignoring foreign patents** - Missing global prior art
5. **Not checking non-patent literature** - Missing academic papers

## Tips for Effective Search

1. Use multiple platforms
2. Try multiple keyword combinations
3. Check citations of relevant patents
4. Look at assignee portfolios
5. Check inventor names
6. Review classification codes
