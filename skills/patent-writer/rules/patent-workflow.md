## Phase Details

### Phase 1: Patent Search & Analysis (1-4 weeks)

```
Tasks:
├── Define search scope
├── Conduct multi-platform search
├── Analyze prior art
├── Assess novelty and inventiveness
├── Identify blocking risks
└── Prepare search report

Deliverables:
├── Search report
├── Prior art analysis
└── Risk assessment
```

### Phase 2: Disclosure Document Writing (1-4 weeks)

```
Tasks:
├── Draft disclosure document
├── Prepare drawings
├── Write detailed embodiments
├── Outline claims
└── Review and revise

Deliverables:
├── Complete disclosure document
├── Technical drawings
└── Claims outline
```

### Phase 3: Agent Drafting (1-4 weeks)

```
Tasks:
├── Submit disclosure to agent
├── Agent reviews and clarifies
├── Agent drafts application
└── Initial review by inventor

Deliverables:
├── Draft patent application
└── Questions for clarification
```

### Phase 4: Review & Revision (0-4 weeks)

```
Tasks:
├── Review agent's draft
├── Provide feedback
├── Revise as needed
└── Final approval

Deliverables:
├── Final patent application
└── Filing authorization
```

### Phase 5: Filing & Prosecution

```
1. Application & Acceptance (< 1 week)
   ├── Agent files with CNIPA
   ├── Receive application number
   └── Get acceptance notice

2. Preliminary Review & Publication (3-18 months)
   ├── Formal examination
   ├── Early publication (optional)
   └── 18-month publication

3. Substantive Examination (6-18 months)
   ├── Request examination
   ├── Examiner review
   ├── Office actions
   └── Responses

4. Patent Grant (2 months)
   ├── Notice of allowance
   ├── Pay grant fees
   └── Receive patent certificate
```

## Critical Timing Rules

### 1. File Before Announcement

```
❌ WRONG: Announce → File patent → Rejected (not novel)

✓ RIGHT: File patent → Receive application number → Announce
```

### 2. Don't Wait for Implementation

```
❌ WRONG: Implement → Test → File patent → Competitor filed first

✓ RIGHT: Research → File patent → Implement
```

### 3. File Early in Research

```
❌ WRONG: Long research → Many improvements → File once → Limited scope

✓ RIGHT: Research milestone → File → Continue research → File improvement
```

## Filing Strategy

### Provisional vs. Non-provisional

```
Provisional Application (临时申请):
+ Quick filing (lower cost)
+ 12-month priority
- Not examined
- Expires if not converted

Non-provisional Application (正式申请):
+ Full examination
+ Can mature to patent
- Higher cost
- Longer timeline
```

### Priority Claims

```
Within 12 months of first filing:
- Can claim priority to earlier application
- Can file in multiple countries
- Can add improvements

After 12 months:
- Cannot claim priority
- May lose novelty if disclosed
```

## Document Management

### File Naming Convention

```
Disclosure document:     [专利名称].docx
Agent draft v1:         [专利名称]-v1.docx
Inventor revision:      [专利名称]-v1-修改版.docx
Agent revision:         [专利名称]-v2.docx
Final version:          [专利名称]-定稿.docx
```

### Version Control

```
Use Word Track Changes:
1. Agent sends draft (v1)
2. Inventor reviews, adds comments
3. Inventor saves as v1-修改版
4. Agent addresses comments (v2)
5. Repeat until final
```

## Communication with Agent

### What to Provide

```
Required:
├── Complete disclosure document
├── Technical drawings
├── Prior art references

Optional but Helpful:
├── Search report
├── Competitor patents
├── Technical papers
└── Product samples
```

### What to Expect from Agent

```
Within 2 weeks:
├── Initial questions
├── Clarification requests

Within 4 weeks:
├── First draft
├── Claims proposal

Ongoing:
├── Office action responses
├── Examination support
```
