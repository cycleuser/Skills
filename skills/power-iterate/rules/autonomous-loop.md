# 自主执行循环规则

## 循环状态机

```
                    ┌─────────────┐
                    │   INITIAL   │
                    └──────┬──────┘
                           │ 开始迭代
                           ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│    DONE     │◄────│   RUNNING   │────►│   BLOCKED   │
└─────────────┘     └──────┬──────┘     └─────────────┘
                           │                   │
                           │                   │ 解除阻塞
                           ▼                   │
                    ┌─────────────┐            │
                    │   IDLE      │────────────┘
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   STOPPING  │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   SAVING    │
                    └─────────────┘
```

## 状态说明

| 状态 | 说明 | 可转换状态 |
|-----|------|----------|
| `INITIAL` | 初始化 | `RUNNING` |
| `RUNNING` | 正在执行任务 | `IDLE`, `DONE`, `STOPPING` |
| `BLOCKED` | 任务被阻塞（依赖未满足） | `IDLE` |
| `IDLE` | 等待新任务 | `RUNNING`, `STOPPING` |
| `STOPPING` | 正在终止 | `SAVING` |
| `SAVING` | 正在保存 | `DONE` |
| `DONE` | 已完成 | - |

## 执行规则

### 规则1：获取任务

```
1. 从队列头部获取任务
2. 检查前置依赖是否满足
   - 依赖已满足 → 执行任务
   - 依赖未满足 → 标记[BLOCKED]，尝试其他任务
3. 如无任务可执行 → 进入STOPPING状态
```

### 规则2：执行任务

**执行前**:
- 读取相关上下文（如有）
- 确认代码风格
- 准备工具

**执行中**:
- 产生实际代码/文档/测试
- 记录关键决策
- 遇到错误按错误处理规则处理

**执行后**:
- 更新任务状态
- 执行最小验证
- 更新队列

### 规则3：验证

**最小验证清单**（每任务后执行）:

| 验证项 | 方法 | 失败处理 |
|-------|-----|---------|
| 语法正确 | `python -m py_compile` 或类似 | 立即修复 |
| 导入正确 | 尝试导入模块 | 立即修复依赖 |
| 基本功能 | 执行基本调用 | 记录，标记`[功能问题]` |

**完整验证**（每5个任务或10分钟执行一次）:

```markdown
## 完整验证

### 代码质量
- [ ] 无语法错误
- [ ] 无导入错误
- [ ] 命名规范一致

### 功能正确性
- [ ] 核心功能可执行
- [ ] 输出格式正确
- [ ] 错误处理存在

### 测试覆盖
- [ ] 新代码有测试
- [ ] 测试可通过
```

### 规则5：预算检查

**检查频率**:
- 每任务后
- 每5分钟强制检查

**检查函数**:

```
check_budget():
    time_pct = time_consumed / time_limit
    token_pct = token_consumed / token_limit
    
    if time_pct >= 0.95 or token_pct >= 0.95:
        return STOP
    
    if time_pct >= 0.85 or token_pct >= 0.85:
        return REDUCE_SCOPE  # 只做P0
    
    if time_pct >= 0.80 or token_pct >= 0.80:
        return CAUTION  # 减速
    
    return CONTINUE
```

**决策响应**:

| 状态 | 响应 |
|-----|-----|
| `CONTINUE` | 继续全速执行 |
| `CAUTION` | 详细检查每任务，预留保存时间 |
| `REDUCE_SCOPE` | 只执行P0任务，跳过P1/P2 |
| `STOP` | 立即停止，进入终止流程 |

### 规则6：错误处理

**错误分类与响应**:

| 错误类型 | 示例 | 处理方式 |
|---------|-----|---------|
| 语法错误 | `SyntaxError` | 立即修复（最多2次） |
| 导入错误 | `ImportError` | 记录依赖，尝试安装或跳过 |
| 逻辑错误 | 功能不正确 | 记录，标记`[待修复]`，继续 |
| 环境错误 | 权限、路径 | 记录，标记`[环境问题]`，继续 |
| 资源错误 | 内存、磁盘 | 记录，尝试清理或跳过 |

**错误恢复策略**:

```
on_error(error):
    if is_recoverable(error):
        try_fix(max_attempts=2)
        if fixed:
            return CONTINUE
    
    log_error(error)
    mark_task_problem(error)
    move_to_next_task()
```

## 终止流程

### 终止触发条件

满足任一即终止:
- 时间耗尽（>95%）
- Token耗尽（>95%）
- 工作队列为空
- 用户发送停止命令

### 终止执行清单

```
1. [ ] 停止获取新任务
2. [ ] 完成当前验证（如可能）
3. [ ] 保存所有修改文件
4. [ ] 生成最终报告
5. [ ] 输出待完成任务清单
6. [ ] 输出假设验证清单
7. [ ] 建议下一步
```
