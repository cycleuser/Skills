# 模板库

## 一、SKILL.md 模板

### 1.1 标准模板

```markdown
---
name: skill-name
version: "1.0.0"
description: |
  技能简要描述
  
  **触发条件:**
  - 条件1
  - 条件2
  
  **命令:**
  - `/命令1 <参数>` - 功能说明
  - `/命令2 <参数>` - 功能说明
  
  **能力:**
  - 能力1
  - 能力2
author: author-name
license: MIT
---

# 技能名称

技能详细描述。

## Quick Commands

| 命令 | 功能 |
|-----|------|
| `/命令1 <参数>` | 功能说明 |
| `/命令2 <参数>` | 功能说明 |

## 功能详解

### 功能1

功能详细说明。

### 功能2

功能详细说明。

## 使用示例

### 基础用法

```
/命令 参数
```

### 进阶用法

```
/命令 参数 --选项 值
```

## Rules

- [rules/rule1.md](rules/rule1.md) - 规则说明
- [rules/rule2.md](rules/rule2.md) - 规则说明

## 配置选项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| option1 | default1 | 说明1 |
| option2 | default2 | 说明2 |
```

## 三、命令文件模板

### 3.1 中文命令模板

```markdown
---
description: 命令功能描述
agent: build
---

Load the skill-name skill and execute: $ARGUMENTS

**用法**: `/命令 <参数>`

**示例**:
- `/命令 示例参数1`
- `/命令 示例参数2 --选项 值`

**功能**: 功能详细说明。
```

### 3.2 英文命令模板

```markdown
---
description: Command description
agent: build
---

Load the skill-name skill and execute: $ARGUMENTS

**Usage**: `/command <argument>`

**Examples**:
- `/command example1`
- `/command example2 --option value`

**Function**: Detailed function description.
```
