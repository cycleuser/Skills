# 验证方法

## 验证流程

```
改进完成 → 重新评分 → 场景测试 → 确认达标
```

---

## 一、评分验证

### 1.1 重新计算各维度评分

```python
def validate_improvement(skill_path, before_scores):
    """验证改进效果"""

    after_scores = {
        "completeness": score_completeness(skill_path),
        "readability": score_readability(skill_path),
        "practicality": score_practicality(skill_path),
        "consistency": score_consistency(skill_path),
        "extensibility": score_extensibility(skill_path)
    }

    after_scores["overall"] = calculate_overall(after_scores)

    # 计算改进幅度
    improvements = {
        key: after_scores[key] - before_scores[key]
        for key in before_scores
    }

    return {
        "before": before_scores,
        "after": after_scores,
        "improvements": improvements
    }
```

### 1.2 达标检查

```yaml
达标条件:
  - 综合评分 >= 80
  - 各维度评分 >= 70
  - 无致命缺陷

部分达标:
  - 综合评分 >= 75
  - 仅1个维度 < 70

未达标:
  - 综合评分 < 75
  - 多个维度 < 70
  - 存在致命缺陷
```

## 二、功能验证

### 2.1 语法验证

```yaml
检查项:
  - YAML frontmatter 格式正确
  - Markdown 语法正确
  - 无语法错误
```

### 2.2 加载验证

```yaml
检查项:
  - 技能可被正确加载
  - 规则文件可被正确读取
  - 命令可被正确识别
```

### 2.3 功能验证

```yaml
检查项:
  - 核心功能可正常执行
  - 示例命令可正常工作
  - 边界情况处理正确
```

## 三、场景测试

### 3.1 基础场景测试

```yaml
测试用例:
  - 场景1: 基本功能使用
  - 场景2: 参数配置
  - 场景3: 错误处理

测试方法:
  1. 根据文档描述构造测试场景
  2. 执行技能
  3. 验证输出是否符合预期
  4. 记录问题
```

### 3.2 集成测试

```yaml
测试用例:
  - 与其他技能的协作
  - 在复杂场景中的表现

测试方法:
  1. 构造涉及多个技能的场景
  2. 执行工作流
  3. 验证各技能协作正常
```

### 3.3 回归测试

```yaml
目的: 确保改进未破坏原有功能

测试方法:
  1. 对比改进前后的行为
  2. 确保核心功能一致
  3. 确认新增功能正常
```

## 四、用户验证

### 4.1 可理解性验证

```yaml
验证项:
  - 新用户能否快速理解技能用途
  - 文档是否清晰易懂
  - 示例是否直观

方法:
  - 让未接触过的用户阅读文档
  - 观察理解速度和准确度
  - 收集反馈
```

### 4.2 可用性验证

```yaml
验证项:
  - 用户能否按文档使用技能
  - 是否遇到无法解决的问题
  - 错误提示是否清晰

方法:
  - 让用户执行典型任务
  - 记录遇到的问题
  - 分析问题原因
```

## 六、迭代机制

### 6.1 迭代条件

```yaml
继续迭代:
  - 未达标
  - 有明确的改进方向
  - 迭代次数未超过上限

停止迭代:
  - 已达标
  - 无法进一步改进
  - 迭代次数超过上限
```

### 6.2 迭代流程

```
验证未达标
    ↓
分析问题
    ↓
制定改进方案
    ↓
执行改进
    ↓
重新验证
    ↓
{达标则停止，未达标则继续}
```

### 6.3 迭代限制

```yaml
最大迭代次数: 5
每次迭代时间限制: 10分钟
评分提升阈值: 5分/次（低于此阈值则停止）
```
