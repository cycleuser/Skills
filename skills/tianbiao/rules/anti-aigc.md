# 填表文字反AIGC / Anti-AIGC for Form Filling

参见 [_shared/core/anti-aigc.md](../../_shared/core/anti-aigc.md) 通用反AIGC规则。以下为填表分析类文字的补充。

表格里的分析/措施文字最容易写成"放之四海皆准"的套话。评审一眼就能看出是模板填充还是真实分析。

## 1. 分布分析要有真实数字

```
❌ AI模式：
"学生整体掌握情况良好，成绩分布合理，达到了预期教学目标。"

✅ 真实写法：
"实考74人，平均分82.5分，及格率100%，优秀率12.2%。分数段：≥90分9人(12.2%)、
80–89分45人(60.8%)、70–79分17人(23.0%)、60–69分3人(4.1%)。成绩集中于80–89区间。"
```

每个结论都要能落到具体数据。没有数据支撑的"良好/合理/达到预期"都是空话。

## 2. 改进措施要具体、可操作

```
❌ AI模式：
"进一步加强实践教学，切实提高学生动手能力，持续优化教学方法。"

✅ 真实写法：
"协调机房资源、优化申请与使用机制，保障学生在所需时段能便捷申请到合格机房；
在过程性评价中增设由易到难的上机任务，引导逐步积累实操经验。"
```

删除"进一步/持续/深入/切实/全面"等空转副词（每千字超过3处即过量）。

## 3. 打破段落同构

不要每段都以"加强/强化/做好/提高"开头。真实分析的句式是参差的：有陈述现状的、有归因的、有给措施的。

## 4. 掌握程度用关键词，不写整句

```
❌ "学生对这部分内容的掌握情况总体来说还是比较不错的"
✅ "掌握：良好"（难度：中等）
```

## 5. 归因中性、不甩锅（见 writing-analysis.md）

```
❌ AI模式（且甩锅）：
"部分学生基础薄弱、学习态度不端正，教师需进一步改进教学。"

✅ 客观写法：
"该类题目依赖上机条件，受个人设备配置有限、公共机房申请使用不便等客观因素影响；
非命题或教与学本身的问题。"
```

## 6. 避免多年不变的套话结论

评审反感"年年都写同样问题、同样措施"。措施要针对**本次**数据反映的具体情况，且体现"依学情动态调整、不僵化固定"的思路。

## 自检 / Checklist

- [ ] 每个评价性结论都有数字或事实支撑
- [ ] 无"进一步/持续/切实/全面"空转副词堆砌
- [ ] 段落开头不同构
- [ ] 无贬损教师或学生的表述
- [ ] 措施具体、可操作、针对本次数据
- [ ] 掌握程度用关键词而非长句
