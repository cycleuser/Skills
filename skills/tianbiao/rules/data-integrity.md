# 数据完整性 / Data Integrity

填表的数据必须**真实、可追溯、经校验**。宁可留空让人工补，也不编造。

## 1. 数据来源分级

| 来源 | 工具 | 说明 |
|------|------|------|
| 点名册 `.xls` | `xlrd` | 学校原始记载，含各分项与合计 |
| 成绩录入模板 `.xlsx` | `openpyxl` | 平时/期末/总评 |
| 学习通统计导出 `.xlsx` | `openpyxl` | 讨论数、作业、测验、签到 |
| 作业文件夹 | 文件名解析 | `姓名_学号_主题.docx` |

用**学号**作唯一键匹配，避免重名问题。

## 2. 公式反推 Reverse-Engineering

当模板要的项在源数据没有直接给出（如"平时成绩"由多分项加权而来），反推权重：

```python
# 已知分项 perf/hw_avg/quiz 与结果 ping，在 0.05 步长上搜索最小误差权重
best = None
steps = [i/100 for i in range(0, 105, 5)]
for a in steps:
    for c in steps:
        b = round(1 - a - c, 2)
        if b < 0: continue
        err = sum(abs(round(a*perf + b*hw + c*quiz) - ping) for ...)
        if best is None or err < best[0]:
            best = (err, a, b, c)
```

反推后必须用**全体样本**验证，并打印所有不吻合行，确认残差仅为四舍五入（±1）。不吻合过多说明公式假设错误，需换假设。

## 3. 分数段分布统计（成绩分析常用）

学校口径通常为 5 段：`≥90 / 80–89 / 70–79 / 60–69 / ≤59`。

```python
def dist(vals):
    b = [0,0,0,0,0]
    for v in vals:
        v = float(v)
        if   v >= 90: b[0] += 1
        elif v >= 80: b[1] += 1
        elif v >= 70: b[2] += 1
        elif v >= 60: b[3] += 1
        else:         b[4] += 1
    return b
```

同时算：平均分、及格率（≥60 占比）、优秀率（≥90 占比）。比例用该表口径的分母（实考人数）。

## 4. 实考人数口径

分析表的"考试总人数/学生总数"须与**教务系统实考人数**一致。旷考、缓考、取消考试资格的学生**不计入实考人数**（按学校说明）。填表时向用户确认是否有此类学生。

## 5. 多单位口径

- "以试卷为单位"的表（试卷质量分析）：每套试卷一份。
- "以教师为单位"的表（试卷成绩分析）：一位教师教多个班填一份，数据为合并全体。
- "同一教师同一课程一份"的表（考查课分析）：同上。
- 可同时产出**合并版**与**分班版**，交付时说明主交件是哪份。

## 6. 校验 Verify

- 抽查若干学生：源值 == 文档值。
- 全量计数：每张明细表的数据行数 == 该班人数；合并表 == 总人数。
- 交叉验证：文档里写的"平均分/及格率/分布"与重新统计一致。
- 占位符检查：无 `%d`/`%.1f` 残留（格式化遗漏）。

## 7. 不确定就问，不编造

- 缺失的签字、日期、盖章 → 留空并在交付说明里列为"需人工补"。
- 需人工判断的（如是否有缓考学生、分析口径选哪种）→ 用一个简洁问题确认后再继续。
- 佐证材料（学生作业原件、截图）→ 不伪造，注明"由教师另附"。
