# 分析类文字填写原则 / Writing Analysis Text

试卷质量分析、成绩分析、过程性评价等表格中的"分析/原因/改进措施"文字，必须**客观、实事求是、有建设性**。以下原则适用于任何课程、任何单位，不含任何具体信息。

## 铁律：不甩锅、不贬损

- **不得贬低教师的学识或教学水平**。分析问题时不写"教师讲解不够""教学方法陈旧"等指向教师能力的表述。
- **不得贬低学生**。不写"学生基础差""学生不努力"等否定学生的表述；高分入学不等于某项具体技能（如动手/操作基础）就强，要理解学情的客观差异。
- 把成因归于**客观条件与可改进的机制**，而非人的能力缺陷。

## 实践类课程：反对僵化固定课时

对实践性强的课程，改进措施应强调：

- 实践学时与理论学时**不能僵化、固定、截然划分**；不应机械规定"某环节必须几课时"。
- 必须**根据具体学情动态调整**——不同班级、甚至同一班级不同阶段，所需实践时长本就不同。若强行固定，反而不适应实际。
- 低年级学生的操作/实践基础参差不齐，往往需要更充分、且**不能被截然切分**的实践时间。
- 立场关键词：尊重学情、尊重现实、实事求是、"实践是检验真理的唯一标准"；反对僵化、保守、死板的固定课时管理思路。

## 客观条件优先归因

当某类需要设备/环境的题目（如上机实操）表现波动时，优先分析**客观实践条件**：

- 学生个人设备配置有限，难以流畅支撑所需环境；
- 公共机房/实验室的**申请与使用存在现实困难**：所需时段申请不到、系统中查不到或无法选择相应场地、可用时间与机会受限。
- 明确指出这些是影响该类题目表现的**主要客观因素，而非命题或教与学本身的问题**。

对应改进措施应是"协调资源、优化申请与使用机制、保障便利的实践条件"，而不是"要求学生/教师改正"。

## 结构建议

分析文字通常分两部分，问题与措施**分开写**：

1. **分布/现状分析**：用真实数据（平均分、及格率、优秀率、各分数段人数与比例、各题型掌握情况）客观描述，说明目标达成情况。
2. **原因分析 + 改进措施**：
   - 原因：命题质量、客观条件等，客观中性；
   - 措施：具体、有针对性、可操作；避免多年重复未解决的问题；避免僵化固定。

## 通用改进措施模板（可套用，措施要具体）

- 从实事求是出发，尊重学情与现实，实践与理论学时依学生真实状态灵活调整，避免截然划分、固定课时。
- 协调场地/设备资源，优化申请与使用机制，保障学生在所需时段便捷获得合格的实践条件。
- 在过程性评价与命题中循序渐进地增设由易到难的任务，引导持续积累经验。
- 加强与先修、后续课程的能力衔接与递进。

## 语气与措辞

- 用"较好、良好、熟练、一般"等关键词描述掌握程度，不写空泛长句。
- 保持中性、建设性、面向改进；不推诿、不指责。
- 遵守 [anti-aigc.md](anti-aigc.md)：避免套话堆砌、每段同构开头、"进一步/持续/深入/切实"过量。
