# 校验清单 (Checklists)

按产物类型运行的只读校验，逐项打勾，全绿才算通过。

## 文档类 (docx / xlsx / doc)

- [ ] `Document(path)` / `load_workbook(path)` 重新打开不报错
- [ ] 合并单元格：被填充的值单元格是**唯一的 tc 元素**（用 `id(cell._tc)` 去重核对，避免误以为合并区域有多个单元格）
- [ ] 签字行/尾部保留：如"负责人签字：""年 月 日""学校公章"未被覆盖或丢失
- [ ] 字体符合要求（宋体/微软雅黑/小四/小五……逐项核对）
- [ ] 正文数字与用户确认口径一致（软著一作/参与、论文一作/通讯/参与、奖项国/省/校 分别核对）

## 表格 / 图片类 (xlsx / 图)

- [ ] 用脚本统计行数与类别计数，与预期断言一致
- [ ] 图片旋转后 OCR 复核文字为横向（`verify.py img-orient`）
- [ ] 文件名符合命名规范（`verify.py unify`）
- [ ] 覆盖/删除前原文件已有备份

## 代码类

- [ ] 限定范围的测试通过（`pytest <路径> -k ...`，禁无范围全量）
- [ ] lint/格式通过（`ruff check .`）
- [ ] 关键路径真实运行过（生成真实产物）

## 批量类 (N 个文件)

- [ ] 处理后文件数 == 预期数（增删都需说明）
- [ ] 每个新文件可打开、内容正确
- [ ] 旧文件只在验证新文件后删除，或保留备份
