## 检测机制详解

### 1. 鼠标离开 iframe 检测

平台在视频播放器的 iframe 上监听 `mouseleave` / `mouseout` 事件，鼠标移出 iframe 区域就暂停。

应对：
- Python 微移：鼠标在屏幕上活动，只要不离开 iframe 区域就不会触发
- 油猴脚本：在 document 上持续触发 `mousemove`，让平台以为鼠标还在

### 2. 窗口/标签页失焦检测

平台监听 `window.blur` 或 `document.visibilitychange`，切换标签页或最小化窗口就暂停。

应对：
- 油猴脚本：拦截 `blur` 和 `visibilitychange` 事件，强制触发 `focus`
- Python 微移：无法直接解决失焦问题，需配合油猴脚本

### 3. 鼠标静止超时检测

平台检测一段时间内鼠标没有移动事件，判定为"挂机"。

应对：
- Python 微移：定时移动，重置超时计时器
- 油猴脚本：定时触发 `mousemove` 事件

## 参数调优

如果默认参数不生效，按以下顺序调整：

1. **缩短间隔**：从 30s 改到 15s，再到 10s
2. **换模式**：微移不行就换点击模式
3. **组合方案**：Python 微移 + 油猴脚本同时用
4. **全屏播放**：很多平台全屏模式下检测更宽松
5. **检查域名**：油猴脚本的 `@match` 规则要覆盖实际域名

## macOS 权限

macOS 上 pyautogui 控制鼠标需要辅助功能权限：

```
系统设置 → 隐私与安全 → 辅助功能 → 允许"终端"（或 iTerm）
```

如果用的是 VS Code 内置终端，允许 VS Code。权限授予后重启终端生效。

## 合规说明

本技能仅用于：
- 保持用户本人账号的网课视频持续播放
- 避免因短暂离开（倒水、上厕所）导致视频暂停后需重新观看

不得用于：
- 绕过考试监考系统
- 自动刷课（不观看内容只为完成学时）
- 伪造学习记录
- 代替他人完成学习任务

请遵守各平台的使用规范。
