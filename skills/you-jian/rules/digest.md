# 邮件摘要分类规则 (Digest)

`/邮箱 digest` 对每封邮件按主题+发件人+正文前 2000 字打分分类。分类顺序与关键词表
（`mailbox.py _guess_importance` 已实现，可自行增删关键词）：

| 分类 | 命中关键词（小写匹配） | 含义 |
|------|----------------------|------|
| 紧急/需处理 | 截止 / deadline / urgent / 紧急 / 尽快 / asap / 请回复 / 请确认 / 逾期 / 最后 / final / 评审 / 答辩 / 查重 / 缴费 / 逾期不候 | 有明确时间压力或需立即行动 |
| 待办 | 发票 / 报销 / 合同 / 审批 / 签到 / 投票 / 问卷 / 盖章 / 签字 / 提交 / 补交 / 材料 / 成绩 / 名单 / 成绩单 / 考核 | 需要用户处理的事务 |
| 验证码/自动 | 验证码 / verification code / security code / 验证 / 激活 | 一次性验证码，看过即可 |
| 通知 | 通知 / 公告 / 公示 / 会议 / 培训 / 讲座 / 任前公示；或发件人为 no-reply/noreply/do-not-reply/自动/系统邮件 | 群发通知，通常只需知悉 |
| 营销/可忽略 | 优惠 / 广告 / 推广 / unsubscribe / 退订 / 促销 / 秒杀 / 双十一 | 营销邮件 |
| 普通 | 其余 | — |

## 摘要输出格式

```
账号 <账号名> 近 <N> 天共 <总数> 封邮件。

  UID   日期       分类        附  发件人 / 主题
  ...（逐封列表）

分类统计: 待办 X 封、通知 Y 封、普通 Z 封
高频发件人: a@b.com 5 封、c@d.com 3 封
建议优先处理:
  uid=42  [紧急/需处理] 项目结题截止通知
  uid=43  [待办] 发票请查收
```

## 摘要口径铁律

1. 计数全用阿拉伯数字，按 `分类→数量→子明细` 顺序。
2. "建议优先处理" 只列 紧急/需处理 与 待办 两类，最多列 10 条。
3. 高频发件人默认 Top 5，数量并列时按邮箱字典序。
4. digest 是只读操作，不改变任何邮件的已读/未读状态。
