# 有据审计报告反AIGC规则

同 [_shared/core/anti-aigc.md](../../_shared/core/anti-aigc.md) 通用规则。

有据审计特有要求：

## 违规报告必须三要素齐全

```
❌ AI模式：
"检测到一些幻觉问题"
"存在与来源不符的内容"

✅ 专业写法：
"N1×1：第5句 'FP16 算力约 4 TOPS'，数字 4 TOPS 不在白名单
 （白名单来自 source_A/B/C，均无 FP16 算力值；source_C:Q4 明示未给出）。
 处理：删除猜测值，改写为'来源未提及'。复查通过。"
```

三要素：**类型+位置、白名单/来源证据、处理方式与复查结果**。缺一即为 AIGC 式空报告。

## 对照实验结论必须带数字

```
❌ "加上限制后幻觉明显减少"
❌ "效果显著提升"

✅ "T1 任务：baseline E1=2 N1=1，grounded E1=0 N1=0；
    T3 任务：baseline E1=3 R1=2（凭记忆对比竞品），
    grounded 未生成对比段，改答'来源未包含竞品信息'"
```

不写"明显/显著"，写具体计数差。泄漏为 0 时附检查命令与输出证据。

## 审计通过 ≠ 空结论

```
❌ "审计通过，内容安全可靠"
✅ "check 通过：E1=0 N1=0 C1=0（命令与输出见附录）；自审 R1=0 Q1=0；
    覆盖率 6/9 要点；未覆盖清单：FP16 算力、价格、级联方案"
```

"通过"必须展开为各项计数 + 证据 + 局限（覆盖率、未覆盖清单）。

## 高发模式检测清单

- [ ] 每条违规是否都有 类型+句位置+证据行号？
- [ ] 每个泄漏实体是否定性了触发诱因？
- [ ] 修复记录是否有轮次与复查结果？
- [ ] 实验结论是否是数字差而不是形容词？
- [ ] "审计通过"是否展开为计数+证据+局限？
- [ ] 是否避免了"内容安全可靠"这类不可验证的断言？

## AIGC 率评分标准

| AIGC 率 | 等级 | 说明 |
|---------|------|------|
| 0-15% | 专业级 | 违规三要素齐全，实验结论有计数差 |
| 16-30% | 可接受 | 位置齐全但部分证据链不完整 |
| 31-50% | 需修改 | 有"明显减少"式结论或无证据的违规描述 |
| 51-70% | 需重写 | 大量"存在幻觉风险"式套话 |
| 71-100% | 纯AI模板 | "审计通过，内容安全可靠"式空结论 |
