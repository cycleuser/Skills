# 有据规则细则 (Grounding Rules)

三类违规定义、判定边界、句级引用标记规范。

## 违规分类总表

| 编号 | 名称 | 机械可判定 | 典型触发场景 |
|------|------|-----------|--------------|
| E1 | 实体增加 | ✅ 脚本 | 补全省略的主语/机构/人名/产品名 |
| N1 | 数字增加 | ✅ 脚本 | 补全表格空缺、"典型值" |
| R1 | 关系增加 | ❌ 模型自审 | 因果化、优劣比较、时序化 |
| Q1 | 越权回答 | 半（脚本给候选） | 来源明说"未提供"仍回答 |
| C1 | 引用失配 | ✅ 脚本 | 标记行号与断言不符 |

## E1 实体增加

**定义**：输出中出现的命名实体（机构/产品/人名/地名/技术名/文档编号），在来源与白名单中均不存在。

```
源："星尘-3 采用 12nm 工艺"
❌ "星尘-3 采用台积电 12nm 工艺"        → 台积电 = E1（补出代工厂）
❌ "星尘-3 采用 12nm 工艺（类似 N 芯片）" → N 芯片 = E1（补出类比物）
✓ "星尘-3 采用 12nm 工艺"               → 有据
```

常见伪装形式（都算 E1）：
- 修饰性补全："**基于 Arm 架构的** 8 TOPS 算力"——"Arm 架构"来源未提
- 类比性补全："与手机 SoC 一样支持……"——手机 SoC 来源未提
- 归因性补全："**由技术市场部发布的**简报"——发布单位在语料里有，可以；但如果来源只写"官方简报"而输出写具体部门，就是 E1

## N1 数字增加

**定义**：输出中出现的数值（含单位换算后的等价值），不在来源数字集合中。

```
源：INT8 算力 8 TOPS；FP16 算力未给出
❌ "FP16 算力约 4 TOPS"                  → 4 TOPS = N1
❌ "INT8 算力 8 TOPS，即每秒 8 万亿次"    → 8 万亿次是等价表述，合法（归一化后相同）
✓ "FP16 算力来源未提及"                  → 合法（Q1 的正确处理）
```

规则细节：
- 单位换算合法：2.1 W = 2100 mW = 0.0021 kW，归一化后比对
- 派生计算违规：来源给 8 TOPS 与 2.1 W，输出"能效 3.81 TOPS/W"——3.81 是新数字。哪怕来源恰好给了 3.8，四舍五入成 3.81 也是 N1（改变了精度 = 改变了断言）
- 百分比、倍数、序号都算数字：输出"提升约 3 倍"而来源无"3 倍"字样 → N1
- 日期同理：来源给"2027 年 Q1"，输出"2027 年 3 月前" → N1（"3 月"是新增精度）

## R1 关系增加

**定义**：输出中的逻辑关系（因果/条件/比较/时序/递进/转折）在来源中不存在。

脚本无法判定 R1，模型自审按以下检查单：

```
对输出的每个连接词与比较结构问一句：
- "因为/由于/导致/因此" → 来源有没有明说这个因果？
- "优于/快于/高于/相比" → 来源有没有做过这个比较？
- "首先/然后/随后"      → 来源有没有给出这个顺序？
- "可以用于/适合"       → 来源有没有明说这个用途？
来源只是并列陈述两件事 → 输出禁止建立先后或因果
```

```
源：A 文档说功耗 2.1 W；B 文档说质检网关整机 5.6 W
❌ "星尘-3 功耗仅 2.1 W，因此整机功耗可控在 5.6 W" → 因果是编的，R1
✓ "整机功耗 5.6 W，其中星尘-3 贡献 2.1 W [B:L9]"   → 来源原话的转述，合法
```

## Q1 越权回答

**定义**：来源显式声明"未提供/未覆盖/未定/未给出"，输出仍然给出了实质答案。

这是**最高频**的幻觉触发点，因为：
1. FAQ 类语料天然包含大量"未提供"声明
2. 模型被训练得乐于助人，看到问题就想答
3. 补出来的答案往往"看起来很合理"（训练分布中的典型值）

处理协议：
```
来源："FP16 算力数值未在任何已交付文档中给出"
用户问：FP16 算力是多少？
✓ 回答："来源（XB-FAQ-2026-008 Q4）明确说明 FP16 算力未给出。"
✓ 可补充：检索到新来源且登记编号后，可引用新来源回答
❌ 回答："FP16 算力大约是 INT8 的一半，即 4 TOPS。" → N1 + Q1 双违规
```

## C1 引用失配

**定义**：句尾引用标记指向的来源行，不包含该句的断言内容。

```
❌ "星尘-3 算力 8 TOPS [A:L19]"，而 A 的 L19 是功耗行
   → 内容可能对，但引用失配 = C1；审计记一次，修正标记
```

标记规范：
- 格式 `[编号:行号]`，如 `[A:L12]`；连续行可用区间 `[A:L12-15]`，最多 5 行
- 多来源合并断言：`[A:L12][B:L9]`
- 引用标记是**断言级**的：每个独立断言一个标记，不允许多段共用一个标记
- "大引用刷白"是反模式：用 [A:L1-40] 覆盖整篇 → 审计按 C1 处理

## 合法操作白名单（不是幻觉）

| 操作 | 例 | 条件 |
|------|-----|------|
| 同义改写 | "功耗 2.1 W"→"典型功耗为 2.1 瓦" | 不引入新实体/数字/关系 |
| 压缩合并 | 来源三段合并成一句 | 每个成分都有出处，合并断言带双标记 |
| 换序重排 | 按用户要求先讲性能后讲功耗 | 不因重排产生时序暗示 |
| 删减 | 只挑用户关心的规格 | 无义务覆盖来源全部内容 |
| 直译换语种 | 英文源→中文输出 | 专名保留原文+译名，数字不变 |
| 等值换算 | 2.1 W ↔ 2100 mW | 归一化后相同 |

## 判定决策树

```
输出句 S 是否违规？
├─ S 含引用标记？
│   ├─ 是 → 标记行是否包含该断言？
│   │        ├─ 是 → 句中实体/数字是否都在白名单？
│   │        │        ├─ 是 → 合法
│   │        │        └─ 否 → E1/N1
│   │        └─ 否 → C1（先修标记，再查实体数字）
│   └─ 否 → S 是否为纯结构句（标题/过渡/来源未提及声明）？
│            ├─ 是 → 合法
│            └─ 否 → 无据句：删除或补标记；含新实体/数字→E1/N1
└─ 连接词/比较结构检查（模型自审）→ 有来源未含的关系 → R1
```

## 违规句的降级处理

```
第 1 轮：删除违规成分，仅用来源内容重写该句
第 2 轮：仍违规 → 整句改写为"来源未提及 X"
第 3 轮：仍违规 → 该断言降级为引号原文摘录（"……" [A:L12]）
3 轮后仍无法处理 → 整段从输出移除，计入"来源未覆盖"清单
```
