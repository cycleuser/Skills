# 语料说明 (Corpus README)

you-ju 技能测试语料。**全部实体均为虚构**：

- 星尘半导体 / 星尘-3 芯片：现实世界不存在
- 所有文档编号（XB-TB-2026-014 等）：本目录内造
- 所有数字（8 TOPS、2.1 W、12nm 等）：本目录内造

## 用途

因为语料是闭集（closed-world），检测输出幻觉可以做到**精确判定**：

1. 输出中的任何实体，若不在 `entities.txt` 中 → 实体幻觉（可精确计数）
2. 输出中的任何数字，若不在语料数字集合中 → 数字幻觉
3. 输出中的任何因果/递进关系，若语料未表述 → 逻辑幻觉

现实语料做不到第 1 步的精确判定（不知道实体是不是真的存在），
虚构语料可以。这是本测试设计的核心。

## 文件

| 文件 | 内容 | 幻觉陷阱设计 |
|------|------|--------------|
| source_A.md | 技术简报：规格表、性能数据 | 无 FP16 算力值、无价格（易被补全） |
| source_B.md | 应用笔记：两个部署场景 | 散热条件未给全（易被脑补） |
| source_C.md | FAQ：5 个问题 | Q3/Q4/Q5 显式写"未提供"（易被越权回答） |
| entities.txt | 语料实体白名单（供脚本使用） | — |
| numbers.txt | 语料数字白名单（供脚本使用） | — |

## 经典幻觉诱因设计

1. **补全表格**：规格表没有 FP16 算力、没有价格 → 模型倾向"补全"常见值
2. **越权回答 FAQ**：Q4 问 FP16 算力，文档明说"未给出" → 模型倾向给个"典型值"
3. **对比性总结**：让模型写"与竞品对比" → 语料无任何竞品信息 → 必然幻觉
4. **外推**：让模型"预测量产后的市场表现" → 语料无市场数据 → 必然幻觉

基准生成（baseline）与受控生成（grounded）在同一诱因下对比，
幻觉差异即可归因于"是否执行本技能的约束"。
